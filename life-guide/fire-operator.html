一、消防工作概述与法律法规
1. 消防工作方针与原则 高频
  • 消防工作方针：预防为主、防消结合
  • 消防工作原则：政府统一领导、部门依法监管、单位全面负责、公民积极参与
  • 消防工作制度：消防安全责任制
  • 消防设施操作员职业定义：从事建（构）筑物消防设施运行、操作和维修、保养、检测等工作的人员
2. 消防法律法规核心考点 高频
  • 《消防法》立法宗旨：预防火灾和减少火灾危害，加强应急救援工作，保护人身、财产安全，维护公共安全
  • 单位消防安全职责：落实消防安全责任制，制定消防安全制度、消防安全操作规程、灭火和应急疏散预案
  • 消防安全重点单位：应当履行法定消防安全职责外，还应确定消防安全管理人，建立消防档案，实行每日防火巡查
  • 消防控制室值班：实行每日24小时专人值班制度，每班不应少于2人，值班人员应持有消防控制室操作职业资格证书
  • 火灾报警电话：119（中国）、消防控制室电话（内线）、单位内部报警电话
必考点：消防控制室必须实行每日24小时专人值班制度，每班不少于2人，值班人员必须持证上岗。
3. 消防职业道德
  • 职业道德基本规范：爱岗敬业、诚实守信、办事公道、服务群众、奉献社会
  • 消防设施操作员职业守则：爱岗敬业、忠于职守、钻研业务、精益求精、英勇顽强、团结协作
二、燃烧与火灾基础知识
1. 燃烧条件与类型 高频 易错
  • 燃烧三要素：可燃物、助燃物（氧化剂）、引火源（着火源）
  • 燃烧类型：闪燃、着火、自燃、爆炸
  • 闪燃：可燃液体表面产生的蒸气与空气混合后，遇火源产生一闪即灭的燃烧现象
  • 闪点：评定液体火灾危险性大小的重要参数，闪点越低，火灾危险性越大
  • 自燃：可燃物在没有外部火源作用下，因受热或自身发热并蓄热所产生的燃烧
  • 自燃点：可燃物发生自燃的最低温度
必考点：闪点是评定液体火灾危险性的主要依据。闪点＜28℃为甲类，28℃≤闪点＜60℃为乙类，闪点≥60℃为丙类。
2. 火灾分类 高频 易错
  • A类火灾：固体物质火灾（木材、棉、毛、麻、纸张等）
  • B类火灾：液体或可熔化固体物质火灾（汽油、煤油、原油、甲醇、乙醇、沥青、石蜡等）
  • C类火灾：气体火灾（煤气、天然气、甲烷、乙烷、丙烷、氢气等）
  • D类火灾：金属火灾（钾、钠、镁、钛、锆、锂、铝镁合金等）
  • E类火灾：带电火灾（物体带电燃烧的火灾）
  • F类火灾：烹饪器具内的烹饪物火灾（动植物油脂）
记忆口诀："固液气金电烹"——A固、B液、C气、D金、E电、F烹
3. 火灾发展阶段与蔓延方式
  • 火灾发展阶段：初起阶段、发展阶段、猛烈阶段、下降阶段、熄灭阶段
  • 热传播方式：热传导、热对流、热辐射
  • 建筑火灾蔓延途径：水平蔓延（门窗、走道、吊顶、可燃隔墙）、竖直蔓延（楼梯间、电梯井、管道井、电缆井、垃圾道）
  • 烟气流动：烟囱效应（竖直管道中烟气快速上升）、火风压（高温烟气膨胀产生的压力）
4. 灭火基本原理 高频
  • 冷却灭火：降低燃烧物温度至燃点以下（如水）
  • 窒息灭火：减少燃烧区域的氧气量（如二氧化碳、泡沫、湿棉被覆盖）
  • 隔离灭火：将燃烧物与未燃烧物隔离（如关闭阀门、拆除毗连建筑）
  • 化学抑制灭火：抑制自由基的产生（如干粉、卤代烷）
三、建筑防火基础知识
1. 建筑分类与耐火等级 高频
  • 按使用性质：民用建筑、工业建筑、农业建筑
  • 民用建筑分类：住宅建筑、公共建筑（单多层/高层）
  • 高层建筑：建筑高度大于27m的住宅建筑和建筑高度大于24m的非单层公共建筑
  • 耐火等级：一级、二级、三级、四级（一级最高）
  • 建筑构件耐火极限：墙、柱、梁、楼板、屋顶承重构件、疏散楼梯、吊顶
2. 防火分区与安全疏散 高频
  • 防火分区：在建筑内部采用防火墙、耐火楼板及其他防火分隔设施分隔而成，能在一定时间内防止火灾向同一建筑的其余部分蔓延的局部空间
  • 防烟分区：在建筑内部采用挡烟设施分隔而成，能在一定时间内防止火灾烟气向同一防火分区的其余部分蔓延的局部空间
  • 安全出口：供人员安全疏散用的楼梯间和室外楼梯的出入口或直通室内外安全区域的出口
  • 疏散走道：发生火灾时，建筑内人员从火灾现场逃往安全场所的通道
  • 疏散楼梯间：敞开楼梯间、封闭楼梯间、防烟楼梯间
记忆技巧：防火分区防"火"蔓延，防烟分区防"烟"蔓延。
3. 防火间距与消防车道
  • 防火间距：防止着火建筑在一定时间内引燃相邻建筑，便于消防扑救的间隔距离
  • 消防车道：净宽度和净空高度均不应小于4m，转弯半径应满足消防车转弯要求
  • 消防登高面：高层建筑应至少沿一个长边或周边长度的1/4且不小于一个长边长度的底边连续布置消防车登高操作场地
四、消防设施基础知识
1. 火灾自动报警系统 高频 实操
  • 系统组成：火灾探测报警系统、消防联动控制系统、可燃气体探测报警系统、电气火灾监控系统
  • 火灾探测器类型：感烟、感温、感光、气体、复合
  • 点型感烟火灾探测器：对悬浮在大气中的燃烧和/或热解产生的固体或液体微粒敏感
  • 点型感温火灾探测器：对温度和/或温度变化响应，分为定温、差温、差定温
  • 手动火灾报警按钮：人工确认火灾后，手动向控制器发出火灾报警信号
  • 火灾报警控制器：接收、显示和传递火灾报警信号，发出控制信号和声光警报信号
2. 自动灭火系统 高频 实操
  • 自动喷水灭火系统：湿式、干式、预作用、雨淋、水幕
  • 湿式系统：管道内充满有压水，适用于环境温度不低于4℃且不高于70℃的场所
  • 干式系统：管道内充满有压气体，适用于环境温度低于4℃或高于70℃的场所
  • 预作用系统：管道内平时无水，火灾时先排气充水，适用于严禁误喷的场所
  • 雨淋系统：开式喷头，由火灾自动报警系统或传动管控制，适用于火灾水平蔓延快的场所
  • 水幕系统：开式喷头或水幕喷头，用于防火分隔或防护冷却
记忆口诀："湿4-70，干冷热爱，预作用怕误喷，雨淋蔓延快，水幕做分隔"
3. 消火栓系统 高频 实操
  • 室外消火栓：沿道路设置，保护半径不应大于150m，间距不应大于120m
  • 室内消火栓：设置在楼梯间及其休息平台和前室、走道等明显易于取用位置
  • 消火栓箱组成：消火栓、水枪、水带、消火栓按钮
  • 水枪充实水柱：从水枪喷嘴起至射流90%的水柱水量穿过直径380mm圆孔处的一段射流长度
  • 室内消火栓布置间距：消火栓按2支消防水枪的2股充实水柱布置的建筑物，消火栓的布置间距不应大于30m；按1支消防水枪的1股充实水柱布置的建筑物，消火栓的布置间距不应大于50m
4. 防排烟系统 高频
  • 防烟方式：自然通风、机械加压送风
  • 排烟方式：自然排烟、机械排烟
  • 防烟楼梯间：在楼梯间入口处设置防烟的前室、开敞式阳台或凹廊等设施，且通向前室和楼梯间的门均为乙级防火门的楼梯间
  • 机械加压送风：防烟楼梯间压力＞前室压力＞走道压力＞房间压力（形成正压梯度）
5. 应急照明与疏散指示 高频
  • 消防应急照明：疏散照明、备用照明
  • 疏散指示标志：灯光疏散指示标志、蓄光疏散指示标志
  • 设置要求：疏散走道的指示标志宜设在疏散走道及其转角处距地面1m以下的墙面上，间距不应大于20m
  • 应急照明连续供电时间：建筑高度大于100m的民用建筑不应小于1.5h；其他建筑不应小于0.5h
6. 灭火器 高频 实操 易错
  • 灭火器类型：水基型、干粉、二氧化碳、洁净气体
  • ABC干粉灭火器：适用于A、B、C类火灾及带电火灾
  • 二氧化碳灭火器：适用于B、C类火灾及带电火灾，不适用于A类火灾（不能有效降低温度）
  • 水基型灭火器：适用于A、B类火灾，不适用于C类气体火灾和带电火灾（水导电）
  • 灭火器报废年限：水基型6年，干粉10年，二氧化碳12年，洁净气体10年
高频考题：二氧化碳灭火器不适用于A类火灾；水基型灭火器不适用于带电火灾；D类火灾（金属火灾）应使用专用灭火器。
五、初起火灾处置与疏散逃生
1. 火灾报警与初起火灾扑救 高频 实操
  • 报警对象：公安消防队（119）、单位消防控制室、单位负责人、周围群众
  • 报警内容：起火单位、详细地址、起火部位、燃烧物质、火势大小、报警人姓名及电话
  • 初起火灾扑救原则：先控制后消灭，救人第一，先重点后一般
  • 灭火最佳时机：火灾初起阶段（一般起火后3-5分钟内）
2. 疏散逃生方法 高频
  • 疏散原则：安全、有序、迅速
  • 疏散顺序：着火层→着火层以上各层→着火层以下各层
  • 疏散方式：利用疏散楼梯、消防电梯、避难层（间）、缓降器、救生袋、安全绳
  • 逃生注意事项：用湿毛巾捂住口鼻、低姿前行、不乘普通电梯、不贪恋财物、不盲目跳楼
  • 身上着火：就地打滚或用厚重衣物覆盖压灭火苗，切勿奔跑
3. 灭火和应急疏散预案
  • 预案内容：组织机构（灭火行动组、通讯联络组、疏散引导组、安全防护救护组）、报警和接警处置程序、应急疏散的组织程序和措施、扑救初起火灾的程序和措施、通讯联络和安全防护救护的程序和措施
  • 预案演练：消防安全重点单位至少每半年进行一次演练，其他单位至少每年组织一次演练
六、消防控制室监控操作 实操核心
1. 消防控制室设备识别 高频 实操
  • 核心设备：火灾报警控制器、消防联动控制器、消防控制室图形显示装置、消防电话总机、消防应急广播控制装置、消防应急照明和疏散指示系统控制装置、消防电源监控器
  • 火灾报警控制器状态：正常监视状态、火灾报警状态、故障报警状态、屏蔽状态、自检状态
  • 指示灯识别：火警（红色）、故障（黄色）、屏蔽（黄色/绿色）、监管（红色/黄色）、启动（红色）、反馈（红色）
2. 火灾报警控制器操作 高频 实操
火灾报警处理程序
  1. 确认火灾报警控制器处于"自动允许"状态
  2. 火灾报警控制器发出火灾报警信号后，值班人员应立即按下"消音"键，停止警报声
  3. 根据报警控制器显示信息，查明火灾报警部位
  4. 通知该部位现场人员或巡查人员到现场确认火灾
  5. 确认火灾后，立即向"119"报警，同时启动单位内部灭火和应急疏散预案
  6. 将火灾报警控制器切换到"自动允许"状态（如未处于该状态）
  7. 启动消防联动设备，监视设备动作反馈信号
误报警处理程序
  1. 按下"消音"键，停止警报声
  2. 查明报警部位
  3. 现场确认是否为误报警
  4. 确认误报警后，查明原因并记录
  5. 按下"复位"键，使系统恢复正常监视状态
  6. 如探测器污染导致误报，通知维保单位清洗
3. 消防联动控制 高频 实操
  • 联动控制方式：自动联动控制、手动联动控制
  • 联动控制设备：消火栓泵、喷淋泵、防排烟风机、防火卷帘、防火门、应急广播、非消防电源切断、电梯迫降
  • 直接手动控制：通过多线控制盘直接手动启动消防泵、防排烟风机等重要设备
  • 总线手动控制：通过总线控制盘手动启动相应联动设备
4. 消防电话与应急广播 实操
  • 消防电话系统：消防电话总机、消防电话分机、消防电话插孔
  • 消防电话操作：拿起话筒即可与总机通话；总机呼叫分机时，拿起话筒按对应分机号
  • 消防应急广播：火灾时应同时向全楼进行广播；播报内容应包括起火部位、疏散路线、安全出口位置、逃生方法
七、建筑消防设施操作与维护
1. 室内消火栓操作 实操
室内消火栓使用步骤
  1. 打开消火栓箱门，取出水带和水枪
  2. 将水带一端与消火栓接口连接，另一端与水枪连接
  3. 按下消火栓按钮（启动消防泵并发出信号）
  4. 逆时针方向打开消火栓阀门
  5. 双手紧握水枪，对准火焰根部喷射
2. 灭火器使用 实操
手提式灭火器使用步骤（提、拔、握、压）
  1. 提起灭火器，迅速奔赴火场
  2. 拔掉保险销（铅封和保险销）
  3. 握住喷管（干粉灭火器握住喷管前端，二氧化碳灭火器握住木柄或戴手套）
  4. 压下压把，对准火焰根部左右扫射
  5. 由近及远，向前推进，直至把火焰扑灭
注意事项：扑救电器火灾时，应先断电后灭火；使用二氧化碳灭火器时，应防止冻伤和窒息。
3. 防火卷帘与防火门 高频 实操
  • 防火卷帘：一步降（直接降至地面）、两步降（先降至1.8m，延时后降至地面）
  • 疏散通道上的防火卷帘：两步降，感烟探测器动作后降至1.8m，感温探测器动作后降至地面
  • 非疏散通道上的防火卷帘：一步降，直接降至地面
  • 防火门：常开式防火门（平时开启，火灾时自动关闭）、常闭式防火门（平时关闭，人员通过时开启）
  • 防火门检查：闭门器、顺序器、释放器、密封条是否完好
4. 自动喷水灭火系统组件 高频
  • 喷头类型：闭式喷头（玻璃球、易熔元件）、开式喷头
  • 喷头公称动作温度：57℃（橙）、68℃（红）、79℃（黄）、93℃（绿）、141℃（蓝）、182℃（紫红）
  • 常用喷头：68℃玻璃球喷头（红色玻璃球），适用于大多数场所
  • 湿式报警阀组：报警阀、延迟器、水力警铃、压力开关、试水阀
  • 末端试水装置：由试水阀、压力表、试水接头组成，用于检验系统可靠性

考题1

答案：冷却、窒息、隔离、化学抑制
