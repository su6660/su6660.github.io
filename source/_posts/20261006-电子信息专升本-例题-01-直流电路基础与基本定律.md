## 一、基础概念示例题

### 例题1-1 ｜ 难度：基础

【题目】
电路上、下两端分别接 E1=12V 与 E2=6V 两个电源（二者负极均接地，参考点电位为 0），上端节点电位为 +12V、下端节点电位为 +6V；两节点之间依次串联两个电阻：R1=2kΩ（在上）、R2=4kΩ（在下），节点 A 位于 R1 与 R2 之间。求：
- 回路电流 I；
- A 点电位 VA。

【解题步骤】
1. 选取参考点：两个电源的负极均接地，电位为 0。
2. 求回路两端的电压差：U = 12 - 6 = 6V。
3. 求回路总电阻：R = R1 + R2 = 2kΩ + 4kΩ = 6kΩ。
4. 求回路电流：I = U/R = 6V / 6kΩ = 1mA。
5. 沿上方路径（从上端节点经 R1 到 A 点）计算 A 点电位：
   VA = 12 - I×R1 = 12 - 1×2 = 10V。

【答案解析】
回路电流 I = 1mA，A 点电位 VA = 10V。
验算：改沿下方路径（从下端节点经 R2 到 A 点）计算，VA = 6 + I×R2 = 6 + 1×4 = 10V。两条路径结果一致，说明电位计算与参考方向选取正确。

【易错提醒】
求电位必须先明确参考点；本题若忽略"负极接地、电位为 0"这一前提，直接拿 12V 与 6V 相减会得到错误电位。

【涉及公式】
U = IR；电压 = 两点电位差，Uab = Va - Vb。

【知识点链接】
电位与电压的计算、参考方向的选取，详见《电子信息专升本 · 第1章 直流电路基础与基本定律》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-01-直流电路基础与基本定律/

### 例题1-2 ｜ 难度：基础

【题目】
一直流电源向负载供电，电路参数如下：
- 电源电动势 E = 12V，内阻 r = 1Ω；
- 负载电阻 R = 5Ω。
求电路电流 I、电源端电压 U、负载功率 P、内阻损耗功率 Pr 及电源发出的总功率 PE，并验证电路的功率守恒。

【解题步骤】
1. 列全电路欧姆定律求电路电流：I = E/(R+r) = 12/(5+1) = 2A。
2. 求电源端电压（电动势减去内阻压降）：U = E - I×r = 12 - 2×1 = 10V。
3. 求负载消耗的功率：P = U×I = 10×2 = 20W。
4. 用另一种形式校验负载功率：P = I²R = 2²×5 = 20W，与第 3 步一致。
5. 求内阻损耗功率：Pr = I²×r = 2²×1 = 4W。
6. 求电源发出的总功率：PE = E×I = 12×2 = 24W。
7. 验证功率守恒：PE = P + Pr，即 24 = 20 + 4 = 24W，守恒成立。

【答案解析】
I = 2A，U = 10V，负载功率 20W，内阻损耗 4W，电源发出总功率 24W，功率守恒成立。

【易错提醒】
功率正负要看电压、电流是否取关联参考方向：本题电源端电压与电流非关联，PE=24W 表示电源发出功率；负载两端为关联方向，P=20W 表示吸收功率。

【涉及公式】
全电路欧姆定律 I = E/(R+r)；端电压 U = E - Ir；功率 P = UI = I²R = U²/R。

【知识点链接】
全电路欧姆定律、端电压 U = E - Ir、功率公式 P = UI = I²R = U²/R，详见《电子信息专升本 · 第1章 直流电路基础与基本定律》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-01-直流电路基础与基本定律/

### 例题1-3 ｜ 难度：基础

【题目】
(1) 某节点 N 接四条支路：I1 = 4A 流入、I2 = 1A 流入、I3 = 2A 流出，求第 4 条支路电流 I4 的大小与流动方向。
(2) 由 20V 理想电压源与 R1=3Ω、R2=7Ω 串联构成的单一闭合回路，用 KVL 验证回路各段电压的代数和为 0。

【解题步骤】
(1) 用 KCL 求 I4：
1. 对节点 N 列 KCL（流入之和等于流出之和）：I1 + I2 = I3 + I4；
2. 代入已知值：4 + 1 = 2 + I4；
3. 解得：I4 = 5 - 2 = 3A，方向为流出节点。
(2) 用 KVL 验证回路：
1. 求回路电流：I = 20/(3+7) = 2A；
2. 求 R1 两端电压：U1 = I×R1 = 2×3 = 6V；
3. 求 R2 两端电压：U2 = I×R2 = 2×7 = 14V；
4. 沿回路顺时针绕行列 KVL：+20 - U1 - U2 = 20 - 6 - 14 = 0，满足 ΣU = 0。

【答案解析】
(1) I4 = 3A，方向为流出节点。
(2) 回路各段电压代数和 20 - 6 - 14 = 0，KVL 成立。

【易错提醒】
列 KCL/KVL 之前必须先标定各支路的参考方向，且符号规则全程统一；第 (2) 问中 20V 电源取正（升压）、两电阻取负（降压），方向不一致会算错。

【涉及公式】
KCL：ΣI = 0（或 ΣI入 = ΣI出）；KVL：ΣU = 0。

【知识点链接】
基尔霍夫电流定律 KCL（ΣI=0）与基尔霍夫电压定律 KVL（ΣU=0），详见《电子信息专升本 · 第1章 直流电路基础与基本定律》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-01-直流电路基础与基本定律/

## 二、综合应用题

### 例题1-4 ｜ 难度：进阶

【题目】
R1=6Ω 与 R2=3Ω 并联后，再与 R3=8Ω 串联，整体接在 U=30V 的电压源上。求：
- 并联部分的等效电阻 R12；
- 总等效电阻 Req 与总电流 I；
- 流过 R1、R2 的支路电流 I1、I2；
- R3 两端的电压 U3。

【解题步骤】
1. 求并联部分等效电阻：R12 = R1∥R2 = (R1×R2)/(R1+R2) = (6×3)/(6+3) = 18/9 = 2Ω。
2. 求总等效电阻：Req = R12 + R3 = 2 + 8 = 10Ω。
3. 求总电流：I = U/Req = 30/10 = 3A。
4. 求并联部分两端电压：U12 = I×R12 = 3×2 = 6V。
5. 求支路电流 I1：I1 = U12/R1 = 6/6 = 1A。
6. 求支路电流 I2：I2 = U12/R2 = 6/3 = 2A。
7. 求 R3 两端电压：U3 = I×R3 = 3×8 = 24V。

【答案解析】
R12 = 2Ω，Req = 10Ω，I = 3A，I1 = 1A，I2 = 2A，U3 = 24V。
校验：并联节点处 KCL 为 1A + 2A = 3A（等于总电流）；整体 KVL 为 6V + 24V = 30V（等于电源电压），均成立。

【易错提醒】
分流时务必用"对方电阻"占比例：I1 = [R2/(R1+R2)]×I；若误用 R1 作分子会得到错误分流结果。

【涉及公式】
并联 R = R1R2/(R1+R2)；分流 I1 = [R2/(R1+R2)]·I。

【知识点链接】
电阻串并联等效与分流公式 I1 = [R2/(R1+R2)]·I，详见《电子信息专升本 · 第1章 直流电路基础与基本定律》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-01-直流电路基础与基本定律/

### 例题1-5 ｜ 难度：进阶

【题目】
两个理想电压源 E1=18V、E2=9V 与三个电阻 R1=3Ω、R2=6Ω、R3=9Ω 依次串联成单一闭合回路，沿顺时针方向两个电源均提供升压。求：
- 回路电流 I；
- 各电阻两端电压 U1、U2、U3；
- 验证 KVL；
- 核算电源发出功率与电阻消耗功率，验证功率守恒。

【解题步骤】
1. 求回路总电动势：E = E1 + E2 = 18 + 9 = 27V。
2. 求回路总电阻：R = R1 + R2 + R3 = 3 + 6 + 9 = 18Ω。
3. 求回路电流：I = E/R = 27/18 = 1.5A。
4. 求各电阻电压：
   - U1 = I×R1 = 1.5×3 = 4.5V；
   - U2 = I×R2 = 1.5×6 = 9V；
   - U3 = I×R3 = 1.5×9 = 13.5V。
5. 验证 KVL：电源升压 18 + 9 = 27V，电阻降压 4.5 + 9 + 13.5 = 27V，升压等于降压，ΣU = 0 成立。
6. 核算功率：
   - 电源发出功率 PE1 = E1×I = 18×1.5 = 27W，PE2 = E2×I = 9×1.5 = 13.5W，合计 27 + 13.5 = 40.5W；
   - 电阻消耗功率 P1 = I²×R1 = 1.5²×3 = 6.75W，P2 = I²×R2 = 1.5²×6 = 13.5W，P3 = I²×R3 = 1.5²×9 = 20.25W，合计 6.75 + 13.5 + 20.25 = 40.5W；
   - 发出 40.5W = 消耗 40.5W，功率守恒成立。

【答案解析】
I = 1.5A；U1 = 4.5V，U2 = 9V，U3 = 13.5V；电源发出 40.5W，电阻消耗 40.5W，功率守恒。

【易错提醒】
两个电源同向串联时电动势相加；若题目中某个电源与回路绕行方向相反，其电动势应取负号，直接相加会算错电流。

【涉及公式】
KVL：ΣU = 0；功率 P = UI = I²R。

【知识点链接】
KVL 的综合运用与功率守恒（P = UI = I²R），详见《电子信息专升本 · 第1章 直流电路基础与基本定律》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-01-直流电路基础与基本定律/

## 三、拓展思考题

### 例题1-6 ｜ 难度：拓展

【题目】
两个理想电压源 E1 = E2 = 6V 能否直接并联向负载供电？两个理想电流源 Is1 = Is2 = 1A 能否直接串联向外供电？请从理想电源的内阻与端口特性出发进行分析，并说明实际工程中的正确处理方式。

【思路提示】
理想电压源内阻 r = 0，端口电压恒定、输出电流由外电路任意决定；理想电流源内阻 r = ∞，端口电流恒定、端电压由外电路任意决定。思考两源并联/串联时各自的端口约束是否相互冲突，以及当参数存在微小差异时会发生什么。

【参考答案要点】
理想电压源直接并联：两源电压被强制相等，若完全一致则电流分配不确定，若存在微小差异（如 6.00V 与 6.01V），因内阻为 0 会在源间形成接近无穷大的环流，足以烧毁电源，故不能简单并联。工程上常串入均压电阻，或选用允许并联输出的电源结构。理想电流源直接串联：两源电流被强制相等，若一致则端电压分配不确定，若存在差异会在断开端口处形成极高电压，故不能简单串联。用含有内阻的实际电源模型（理想源串联/并联内阻）即可解释并联/串联时的电流、电压分配。本题关键是对"理想电源内阻为 0 或 ∞"这一理想化模型的后果有清晰认识。
