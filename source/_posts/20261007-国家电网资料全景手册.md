# 国家电网资料全景手册（备考版）

> 适用对象：以国网校招为目标的电气类专业学生（专转本路线）
> 编制时间：2026年10月
> 数据基准：国网2026届招聘公告 + 2026版电工类考试大纲 + 现行电力安全标准体系
> 核心结论：所有信息以 **zhaopin.sgcc.com.cn**（国网招聘平台）和官方公告原文为准，本手册为整理与索引，引用时请回查原文

---

## 一、资料体系总览：四层结构

```
第一层 招聘政策（怎么进）→ 决定你能不能报、什么时候报
第二层 考试大纲（考什么）→ 决定你怎么备考
第三层 企业知识（认知面）→ 笔试20%的公共题 + 面试谈资
第四层 技术标准与安全规范（干什么用）→ 入职后的饭碗，备考期只需知道框架
```

**优先级建议**：在校期间主攻第一、二层；第三层考前3个月突击；第四层入职后由单位培训，个人不必提前买标准全文。

### 2.3 基本条件六项（2026/2027届口径）

1. **学历**：国家统招计划内普通高校**应届**本科及以上，毕业当年7月31日前取得毕业证+学位证
2. **专业**：主修专业为电工类（电气工程及其自动化等）/计算机类/通信类等；**不含辅修、二学位；须与学籍验证报告完全一致**
3. **年龄**：本科生一般不超过25周岁（截止毕业当年6月30日）；**退役军人可适当放宽**
4. **品行**：无刑事犯罪、无严重校纪处分
5. **身体**：公务员体检标准+电力一线要求（**恐高症、严重心血管疾病、辨色力异常不合格**）
6. **同等条件下退役军人优先录用**（每批公告明文）

### 2.4 招聘全流程（七步）

```
网申（平台填简历+传材料）→ 简历筛选（未过不通知）→ 线上测评（收到通知须限时确认）
→ 现场资格审查（发准考证）→ 统一笔试（3小时）→ 面试 → 体检+公示+录用
```

## 三、第二层：笔试大纲（2026版电工类本科）

### 3.1 卷面结构

| 模块 | 占比 | 内容 |
|---|---|---|
| 公共与行业知识 | 20% | 一般能力（言语理解、信息洞察、思维策略、资料分析）+ 企业文化/电力与能源战略 + 形势与政策（考前约14个月时事） |
| **专业知识** | **80%** | 见下表 |

### 3.2 专业课七门（本科）

| 科目 | 核心考点 | 与专转本考查重叠度 |
|---|---|---|
| **电工技术基础** | 电路定律与线性电路分析、一阶/二阶电路时域分析、正弦稳态、三相电路、二端口网络、频率响应、电力电子器件、换流/变流电路、PWM、变压器/异步/同步电机 | **电路部分≈专转本电路；电机部分为新学** |
| **电力系统分析** | 基本概念、元件模型、潮流计算、有功/频率、无功/电压调整、故障分析、静态/暂态稳定、新型电力系统构成 | 全新（本科主课） |
| **电力系统继电保护** | 基本概念、阶段式电流保护、距离保护、纵联保护、重合闸、变压器/母线保护、数字式保护基础 | 全新 |
| **电气设备及主系统** | 电气设备类型原理、主接线形式、倒闸操作、限制短路电流、配电装置 | 全新 |
| **高电压技术** | 电介质特性与放电理论、绝缘试验、过电压与防护、防雷接地 | 全新 |
| （企业战略题库） | "一体四翼"、双碳、"四个革命、一个合作"能源安全新战略 | 背诵题 |

### 3.3 大纲版本变化趋势（2023版→2026版实证）

- **新增**：新型电力系统（宽频振荡、国外大停电分析、大模型/数字孪生、"大云物移智链"）、数字式保护、电力作业现场安全风险防范（专科）
- **删除**：同步发电机组数学模型、部分电机章节
- **合并**：整流+逆变→"换流电路"；直直+交交→"变流电路"
- **趋势**：基础概念仍占主导，前沿内容逐年加码，弱化手算、侧重概念

## 五、第四层：技术标准与安全规范体系

### 5.1 安规体系全景（截至2026年10月）

| 标准 | 状态 | 说明 |
|---|---|---|
| GB 26859-2011 电力安全工作规程·电力线路部分 | 现行国标（部分强制） | 修订版（20230927-Q-624）正在批准 |
| GB 26860-2011 电力安全工作规程·发电厂和变电站电气部分 | 现行国标 | 修订版（20230928-Q-624）正在批准 |
| **DL/T 408-2023** 电力安全工作规程·发电厂和变电站电气部分 | **现行行标，2024-06-28实施** | 代替DL 408-1991 |
| **DL/T 409-2023** 电力安全工作规程·电力线路部分 | **现行行标，2024-06-28实施** | |
| DL/T 560-2022 高压试验室部分 | 现行 | |
| DL/T 5009.2/.3-2026 电力建设安全工作规程（线路/变电站） | 2026-12-26实施 | 施工基建方向 |
| 国标·热力和机械部分 | 修订中（征求意见） | |

**归口单位**：全国高压电气安全标准化技术委员会（SAC/TC 226）；主管：国家能源局
**查询入口**：全国标准信息公共服务平台 std.samr.gov.cn

### 5.2 安规核心内容框架（入职后必考必用）

- **安全组织措施**：工作票制度（一/二种工作票、带电作业票、紧急抢修单）、工作许可、工作监护、工作间断/转移/终结
- **安全技术措施**：停电、验电、装设接地线、悬挂标示牌+装设遮栏
- **作业分类**：线路运行维护、邻近带电导线工作、配电设备工作、带电作业、电力电缆工作
- **术语基准**：低压≤1000V；高压>1000V；"运用中的电气设备"=全部/部分/一经操作即带有电压

## 七、"坑"清单与注意事项（核心章节）

### 7.1 信息源类的坑

| 坑 | 表现 | 对策 |
|---|---|---|
| **第三方转载失真** | 培训机构/本地宝/营销号转载公告有删改、滞后、数字错误（如把"约1065人"写成别的） | 一切以 zhaopin.sgcc.com.cn 原文为准；打印/存档公告PDF |
| **旧版大纲当新版用** | 网上大量2023版大纲资料仍在流通，考点已变 | 认准当年版（如"2026版"字样）；对照官方平台发布 |
| **假招聘/收费骗局** | "内部渠道""培训保过""报名费" | 公告明文：不收费、不办班、不收纸质简历；唯一平台报名 |

### 7.2 报名流程类的坑

| 坑 | 表现 | 对策 |
|---|---|---|
| **简历提交后不能更改** | 网申信息一锤定音 | 填写前把学籍验证报告、成绩单备齐对照着填，检查三遍再提交 |
| **学籍验证报告有效期** | 须在毕业当年7月1日前有效 | 提前在学信网申请《教育部学籍在线验证报告》并设置最长有效期，到期前续期 |
| **各学历阶段都要传** | 专科+本科两段学籍报告缺一不可 | 专转本学生易漏专科段；两段都下载PDF |
| **沉默即拒绝** | 简历筛选未过"不再另行通知" | 一批没消息立即准备二批，不要等 |
| **线上测评限时确认** | 收到站内消息后须1-2天内确认，**逾期视为自行放弃** | 报名期间每天登录平台看"待办事项/我的消息" |
| **多通知只能选一个** | 收到多个考试通知，确认提交后无法更改 | 想清楚优先级再点确认 |
| **资格审查材料清单长** | 身份证、学生证、登记表、各阶段学籍报告、成绩单（盖章）、就业推荐表、就业协议书/未就业证明 | 提前一个月按清单逐项准备，找学院盖章要排期 |

### 7.3 条件类的坑（个人专属）

| 坑 | 说明 | 你的情况与对策 |
|---|---|---|
| **专业名称一致性** | 网申专业须与学籍验证报告完全一致，职业本科是"电气工程及自动化"（260302）≠ 普通本科"电气工程及其自动化"（080601） | **这就是选淮阴师范学院（080601）的核心理由**，门票零摩擦 |
| **年龄压线** | 本科生≤25周岁（截止当年6月30日） | 2003年7月出生→2029年6月30日恰好25周岁压线达标；万一政策收紧，退役身份有放宽条款兜底（公告原文"退役军人年龄可适当放宽"） |
| **计算机等级证书** | 江苏公告：**入职前须取得国家或省二级及以上计算机等级证书**；网申时未取得的需提供"已报名证明" | **你目前只有一级！本条是你未来两年最容易踩的隐形坑——入学后尽快考出计算机二级（建议大一就考）** |
| **体检色觉** | 辨色力不正常（色盲色弱）直接不合格 | **入学前自查一次色觉图谱**，这是唯一无法靠努力补救的硬条件 |
| **体检标准双轨** | 公务员体检通用标准+电力一线附加要求（恐高、心血管） | 装甲修理经历体能无忧；正式入职体检前规律作息 |

### 7.4 考试类的坑

| 坑 | 说明 | 对策 |
|---|---|---|
| **考试形式是"网络在线答题"** | 不是纸质卷，在机房考 | 提前适应电脑屏幕做题（刷题就用电脑刷） |
| **禁带清单极长** | 手机、AI眼镜、电子表、手环、耳机、计算器全禁 | 考试当天按"只带身份证+准考证+签字笔"准备 |
| **形势与政策有时效** | 只考考前约14个月内的时事（重点是能源电力领域） | **考前3个月再准备，提前背=白背**；重点盯能源政策文件 |
| **企业文化题库版式** | 公共题出自官方题库（企业文化、电力与能源战略） | 考前找当年版题库刷题，性价比极高（纯背诵拿分） |
| **大纲逐年微调** | 每年版大纲有增删（近年加"新型电力系统""大模型"等前沿） | 以**你参考当年**（2028年底发布的2029届大纲）为准，前一年的只做参考 |
| **研究生与本科卷不同** | 电工类研究生与本科分开考、科目侧重不同 | 你考"电工类本科"卷，别买错资料 |

### 7.5 录用落点类的坑

| 坑 | 说明 | 对策 |
|---|---|---|
| **三新公司合同主体** | 与三新供电服务公司签合同，非供电公司直签；仍属国网体系但待遇序列不同 | 作为兜底选项时要想清楚；县供电公司直签 > 三新 |
| **工作地不保证市区** | 公告写"省会、地级市、县级市和县" | 苏北县公司、常州县级市（金坛/溧阳）也是好落点，志愿梯度拉开 |
| **一批失利不是终点** | 江苏一年三批，二批三批均有机会 | 一批12月考完立即评估，无缝转二批 |

### 7.6 资料准确性验证方法论（通用）

1. **两源核对**：任何关键信息（时间、条件、名额）至少找到官方原文+一个独立来源交叉验证
2. **看日期**：公告、大纲、标准都认"发布日期"，超过一年的政策默认可能过期
3. **标准查状态**：上 std.samr.gov.cn 查"现行/废止/即将实施"，别用废止版安规
4. **存档习惯**：每年11月起把当届公告、大纲PDF存进固定文件夹，用年份命名
5. **电话核实**：各省公司公告都留咨询电话（如江苏025-85082386），拿不准直接打
