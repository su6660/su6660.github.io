# 第一套 · 基础巩固卷（5 题 × 20 分）

**1.（20 分）简答题**
(1) 写出换路定则的表达式，并说明其物理原因。
(2) 写出 RC、RL 一阶电路时间常数的计算公式，并说明 τ 的物理意义（含工程上 3~5τ 的估计）。
(3) 直流稳态下电容、电感各相当于什么？
(4) 零输入响应、零状态响应、全响应各指什么？

**2.（20 分）** RC 放电电路：t<0 时电路已稳定，uC(0−) = 12V；t=0 时开关闭合，电容 C = 5μF 经电阻 R = 2kΩ 放电。求：(1) 时间常数 τ；(2) uC(t) 和放电电流 i(t) 的表达式；(3) t = 30ms 时的 uC 值。

**3.（20 分）** RL 充电电路：Us = 20V，R = 4Ω，L = 0.2H，开关 t=0 闭合前电路无储能。求：(1) 时间常数 τ；(2) iL(t) 与 uL(t)；(3) t = 0.1s 时的 iL。

**4.（20 分）** RC 充电电路：Us = 10V，R = 5kΩ，C = 10μF，零状态下 t=0 闭合开关。求：(1) τ 与 uC(t)；(2) uC 充到 6.32V 和 9.5V 各需多少时间；(3) 充到 9.5V 时电容储存的能量。

**5.（20 分）判断下列说法是否正确，错误的请改正（每小题 5 分）**
(1) 换路瞬间，流过电容的电流不能发生跃变。
(2) 时间常数越大，过渡过程结束得越快。
(3) 一阶 RL 电路中，从电感两端看入的等效电阻越大，时间常数越大。
(4) 零输入响应随时间按指数规律增长。

## 第一套 参考答案

**1.**
(1) uC(0+) = uC(0−)，iL(0+) = iL(0−)。物理原因：电容储能为 ½CuC²（电荷 q = CuC）、电感储能为 ½LiL²，能量（及对应电荷/磁链）若突变需要无穷大功率，实际电路不允许。
(2) RC 电路 τ = RC，RL 电路 τ = L/R。物理意义：零输入响应衰减到初值 36.8%（或零状态响应上升到稳态值 63.2%）所需的时间；工程上认为经 3~5τ 后过渡过程结束。
(3) 电容相当于开路（电流为零），电感相当于短路（电压为零）。
(4) 零输入响应：换路后无外加激励，仅由初始储能产生；零状态响应：初始储能为零，仅由外加激励产生；全响应：两者共同作用（= 零输入 + 零状态）。

**2.** (1) τ = RC = 2k×5μ = **10ms**；(2) uC = 12e^(−100t) V，i = 6e^(−100t) mA（i(0+) = 12/2k = 6mA）；(3) uC(30ms) = 12e^(−3) ≈ **0.6V**（3τ 已基本放完）。

**3.** (1) τ = L/R = **0.05s**；(2) iL = 5(1−e^(−20t)) A，uL = 20e^(−20t) V；(3) iL(0.1) = 5(1−e^(−2)) ≈ **4.32A**。

**4.** (1) τ = **50ms**，uC = 10(1−e^(−20t)) V；(2) 6.32V → 0.632Us → t = τ = **50ms**；9.5V → 0.95Us → t = τ·ln20 ≈ **150ms**；(3) W = ½Cu² = 0.5×10μ×9.5² ≈ **0.45mJ**。

**5.**
(1) 错。不能跃变的是电容**电压**；电容电流可以跃变（为有限值即可）。
(2) 错。τ 越大，过渡过程越**慢**。
(3) 错。τ = L/R，等效电阻越大 τ 越**小**（与 RC 电路相反）。
(4) 错。零输入响应按指数规律**衰减**（初始储能逐渐耗尽）。

# 第二套 · 标准训练卷（5 题 × 20 分）

**1.（20 分）简答题**
(1) 写出三要素法公式，并说明各量的含义及求法。
(2) 构造 0+ 等效电路时，电容、电感各用什么替代？
(3) τ 由换路前还是换路后的电路求？独立源、受控源分别怎么处理？
(4) 全响应有哪两种分解方式？

**2.（20 分）** 电路：Us = 12V 经 R1 = 2kΩ 与 R2 = 4kΩ 分压，C = 25μF 并联在 R2 两端，开关 K 串联在电源支路。t<0 电路稳态；t=0 断开 K（此后 C 仅经 R2 放电）。求 uC(0+)、τ、uC(t) 及放电电流最大值。

**3.（20 分）** 电路：Us = 10V 经 R = 1kΩ 接 C = 20μF，电容预先充电至 uC(0−) = 2V，t=0 闭合开关接入电源。求 τ、uC(t)、iC(t) 和 iC(0+)。

**4.（20 分）** 电路：Us = 12V 经 R1 = 4kΩ 接节点 A，R2 = 8kΩ 从 A 到地；C = 15μF 原充电至 3V，t=0 时开关将 C 接入 A 与地之间。求：(1) uC(0+) 与 iC(0+)；(2) uC(∞) 与 τ；(3) uC(t)。

**5.（20 分）** 已知某电路响应 f(0+) = 2A，f(∞) = 6A，τ = 0.1s。求：(1) f(t)（并指出该响应是增长型还是衰减型）；(2) t = 0.2s 时的值；(3) 零输入分量与零状态分量。

## 第二套 参考答案

**1.**
(1) f(t) = f(∞) + [f(0+) − f(∞)]·e^(−t/τ)；f(0+) 由 0+ 等效电路求，f(∞) 由换路后稳态电路求（C 开路、L 短路），τ = R0C 或 L/R0（R0 为从储能元件两端看入的等效电阻）。
(2) 已充电电容用电压源 uC(0+) 替代；有电流的电感用电流源 iL(0+) 替代。
(3) 由换路**后**的电路求；独立源置零（电压源短路、电流源开路），受控源必须保留。
(4) 分解一：零输入响应 + 零状态响应（按能量来源）；分解二：稳态分量 + 暂态分量（按响应形式）。

**2.** uC(0+) = 12×4/6 = **8V**；τ = R2C = 4k×25μ = **100ms**；uC = 8e^(−10t) V；i max = i(0+) = 8/4k = **2mA**。

**3.** τ = 1k×20μ = **20ms**；uC = 10 + (2−10)e^(−50t) = **10−8e^(−50t) V**；iC = C·duC/dt = **8e^(−50t) mA**；iC(0+) = (10−2)/1k = **8mA**。

**4.** (1) uC(0+) = **3V**（换路定则）；0+ 时 A 点电位被钳制为 3V：iC(0+) = (12−3)/4k − 3/8k = **1.875mA**；(2) uC(∞) = 12×8/12 = **8V**；τ = (R1∥R2)·C = (8/3 kΩ)×15μF = **40ms**；(3) uC = **8−5e^(−25t) V**。
（自检：iC(t) = 15μ×5×25·e^(−25t) = 1.875e^(−25t) mA，与 iC(0+) 一致。）

**5.** (1) f(t) = 6 + (2−6)e^(−10t) = **6−4e^(−10t) A**，增长型（f(0+) < f(∞)）；(2) f(0.2) = 6−4e^(−2) ≈ **5.46A**；(3) 零输入 = 2e^(−10t) A，零状态 = 6(1−e^(−10t)) A（相加 = 全响应 ✓）。

# 第三套 · 强化提高卷（15 + 20 + 25 + 20 + 20 = 100 分）

**1.（15 分）简答题**
(1) 含受控源的一阶电路求等效电阻时，为什么不能直接用电阻串并联？应采用什么方法？
(2) 时间常数 τ 的几何意义是什么？
(3) 电阻 R 增大，对 RC 与 RL 一阶电路的 τ 影响有何不同？为什么？

**2.（20 分）** 电路：Us = 18V 经 R1 = 3kΩ 接 R2 = 6kΩ 到地；开关 K 与 C = 100μF 串联后并联在 R2 两端。t<0 K 断开且 uC(0−) = 0，t=0 闭合 K。求：(1) uC(∞)；(2) 从 C 看入的戴维南等效电阻与 τ；(3) uC(t)、iC(t) 及 iC(0+)。

**3.（25 分）** 双掷开关电路：t<0 时 L = 0.1H 接在电流源 Is = 1A 上已很久；t=0 切换到 Us = 12V 串 R = 4Ω 的支路。求：(1) iL(t) 全响应；(2) 零输入分量与零状态分量；(3) 稳态分量与暂态分量；(4) uL(t)。

**4.（20 分）** RL 放电：R = 10Ω，L = 0.2H，iL(0) = 2A，t=0 开始经 R 放电。求：(1) τ 与 iL(t)；(2) 电阻消耗的总能量；(3) 电流降到 0.1A 所需时间。

**5.（20 分）** RC 零状态充电效率推导：电压源 Us 经电阻 R 对 C 充电（初始无储能）。求：(1) uC(t) 与 iC(t)；(2) 推导整个充电过程中电源提供的总能量 Ws；(3) 电容最终储能与充电效率，并说明效率与 R 是否有关。

## 第三套 参考答案

**1.**
(1) 受控源受电路中支路电压/电流控制，不是独立激励，不能简单置零或参与串并联；应采用**加压求流法**：独立源全部置零、受控源保留，在端口加电压 U 求端口电流 I，R0 = U/I。
(2) 在响应曲线上任意一点作切线，切线与稳态值线交点的时间间隔恒等于 τ。
(3) RC 电路 τ = RC，R 增大 τ 增大；RL 电路 τ = L/R，R 增大 τ 反而减小——两种电路中 R 对充放电快慢的作用方向相反。

**2.** (1) uC(∞) = 18×6/9 = **12V**；(2) R0 = R1∥R2 = **2kΩ**，τ = R0C = **0.2s**；(3) uC = 12(1−e^(−5t)) V；iC = C·duC/dt = 6e^(−5t) mA；iC(0+) = 18/3k = **6mA**（0+ 时 C 相当于短路，R2 被短接）。

**3.** (1) iL(0+) = 1A，iL(∞) = 12/4 = 3A，τ = 0.1/4 = 25ms → **iL = 3−2e^(−40t) A**；(2) 零输入 = **e^(−40t) A**，零状态 = **3(1−e^(−40t)) A**；(3) 稳态分量 = **3A**，暂态分量 = **−2e^(−40t) A**；(4) uL = L·diL/dt = **8e^(−40t) V**（验证：uL(0+) = 12−4×1 = 8V ✓）。

**4.** (1) τ = L/R = **0.02s**，iL = 2e^(−50t) A；(2) W = ½Li₀² = 0.5×0.2×2² = **0.4J**（初始储能全部耗散于电阻）；(3) 0.1 = 2e^(−50t) → t = ln20/50 = 3τ = **60ms**。

**5.** (1) uC = Us(1−e^(−t/RC))，iC = (Us/R)·e^(−t/RC)；(2) Ws = ∫₀^∞ Us·iC dt = (Us²/R)·RC = **CUs²**；(3) WC = ½CUs²，效率 η = WC/Ws = **50%，与 R 无关**（R 只改变充电快慢，不改变能量分配——另一半在电阻上变为热）。

# 第四套 · 综合挑战卷（10 + 20 + 25 + 20 + 25 = 100 分，结合第 1、2 章）

**1.（10 分）简答/辨析**
(1) 判断一个动态电路是"一阶"的依据是什么？
(2) 若某电路 uC(0+) = uC(∞)，换路后响应如何变化？
(3) 为什么换路前后电容的电荷保持连续？
(4) 含两个不能等效合并的独立电容的电路，能否直接套三要素公式？应如何处理？

**2.（20 分）节点法求初值（综合第 2 章）**：电路：Us = 12V 经 R1 = 2kΩ 接节点 A；电流源 Is = 3mA 接在 A 与地之间（方向由 A 流向地）；R2 = 4kΩ 与 C = 30μF 均并联在 A 与地之间。t<0 电路稳态；t=0 将电流源支路断开。求：(1) uC(0+)（提示：稳态时 C 开路，对 A 列节点电流方程）；(2) uC(∞)；(3) τ 与 uC(t)。

**3.（25 分）含受控源（挑战）**：换路后电路：Us = 9V 经 R0' = 1kΩ 接节点 A；R1 = 3kΩ 与 C = 50μF 均接在 A 与地之间；另有受控电流源 0.5i₁ 并联在 A 与地之间（方向由 A 流向地），i₁ 为流过 R1 的电流（方向 A→地）。uC(0−) = 0，t=0 接入电路。求：(1) uC(∞)（对 A 列节点方程）；(2) 用加压求流法求 R0 与 τ；(3) uC(t)。

**4.（20 分）戴维南 + 初值 + 能量**：电路：Us = 20V 经 R1 = 5kΩ 接 R2 = 15kΩ 到地；C = 10μF 原已充电至 6V，t=0 开关闭合将 C 接到 R2 两端。求：(1) uC(0+)、uC(∞)、τ、uC(t)；(2) t = 0.1s 时的 uC；(3) 整个充电过程中电容储能的变化量。

**5.（25 分）分段换路（压轴）**：电路：Us = 10V 经开关 K1 串 R1 = 1kΩ 接 C = 20μF（零状态）；t=0 闭合 K1 充电；t = 0.1s 时 K2 动作，将 C 切换到 R2 = 2kΩ 单独放电（电源支路同时断开）。求：(1) 两个阶段各自的响应类型与时间常数；(2) 0 ≤ t < 0.1s 的 uC(t)；(3) t ≥ 0.1s 的 uC(t)（提示：0.1s 已达 5τ，可认为充电完毕）；(4) 电压降到 1V 的时刻。

## 第四套 参考答案

**1.**
(1) 换路后电路中独立储能元件（不能等效合并的）仅有 1 个。
(2) 响应恒等于该初值，直接进入稳态，无过渡过程（指数项系数为零）。
(3) q = CuC，uC 不能跃变（换路瞬间电容电流为有限值），故电荷连续。
(4) 不能；应先将电容串并联等效为一个，若无法合并则属于二阶电路，需列写二阶微分方程求解。

**2.** (1) 0− 稳态 C 开路，节点 A：(uA−12)/2k + 3m + uA/4k = 0 → uA = **4V** = uC(0+)；(2) 断开电流源后分压：uC(∞) = 12×4/6 = **8V**；(3) τ = (2k∥4k)×30μ = **40ms**；uC = 8+(4−8)e^(−25t) = **8−4e^(−25t) V**。

**3.** (1) ∞ 时 C 开路：(9−uA)/1k = uA/3k + 0.5·(uA/3k) → 2(9−uA) = uA → uC(∞) = **6V**；(2) 置零 Us 后加电压 U：I = U/3k + 0.5U/3k = U/2k → **R0 = 2kΩ**，τ = 2k×50μ = **100ms**；(3) uC = **6(1−e^(−10t)) V**。

**4.** (1) uC(0+) = **6V**；uC(∞) = 20×15/20 = **15V**；R0 = 5k∥15k = 3.75kΩ，τ = 3.75k×10μ = **37.5ms**；uC = 15−9e^(−t/37.5ms) V（即 15−9e^(−26.7t) V）；(2) t/τ = 0.1/0.0375 = 2.67，e^(−2.67) ≈ 0.07 → uC ≈ **14.4V**；(3) ΔW = ½C(u∞²−u₀²) = 0.5×10μ×(225−36) ≈ **0.95mJ**。

**5.** (1) 阶段 1（0 ≤ t < 0.1s）：零状态充电，τ1 = R1C = 20ms；阶段 2（t ≥ 0.1s）：零输入放电，τ2 = R2C = 40ms；(2) uC = 10(1−e^(−50t)) V；(3) 0.1s = 5τ1，uC(0.1) ≈ 10V，故 uC = 10e^(−(t−0.1)/0.04) V；(4) 10e^(−(t−0.1)/0.04) = 1 → (t−0.1) = 0.04·ln10 ≈ 0.092s → **t ≈ 0.192s**。
