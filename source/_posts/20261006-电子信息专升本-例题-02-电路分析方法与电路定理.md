## 一、基础概念示例题

### 例题2-1 ｜ 难度：基础

【题目】
R1=6Ω 与 R2=3Ω 并联后接在 U=12V 的电压源上。求：
- 并联等效电阻 R；
- 总电流 I；
- 流过 R1、R2 的支路电流 I1、I2。

【解题步骤】
1. 求并联等效电阻：R = R1∥R2 = (R1×R2)/(R1+R2) = (6×3)/(6+3) = 18/9 = 2Ω。
2. 求总电流：I = U/R = 12/2 = 6A。
3. 求支路电流 I1（用分流公式，分子取"对面"的 R2）：
   I1 = [R2/(R1+R2)]×I = (3/9)×6 = 2A。
4. 求支路电流 I2：
   I2 = [R1/(R1+R2)]×I = (6/9)×6 = 4A。

【答案解析】
R = 2Ω，I = 6A，I1 = 2A，I2 = 4A。
校验：并联节点处 KCL 为 2A + 4A = 6A（等于总电流）；两电阻两端电压分别为 2×6 = 12V 与 3×4 = 12V，与电源电压一致。

【易错提醒】
两条支路电流也可用 I1 = U/R1、I2 = U/R2 直接求；用分流公式时分子务必取"对面支路"的电阻，否则会得到错误结果。

【涉及公式】
并联 R = R1R2/(R1+R2)；分流 I1 = [R2/(R1+R2)]·I。

【知识点链接】
电阻串并联等效、分流公式 I1 = [R2/(R1+R2)]·I、分压公式 Uk = (Rk/R)U，详见《电子信息专升本 · 第2章 电路分析方法与电路定理》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-02-电路分析方法与电路定理/

### 例题2-2 ｜ 难度：基础

【题目】
线性电路中，E1=12V 与 R1=2Ω 串联构成第一条支路，E2=6V 与 R2=2Ω 串联构成第二条支路，两条支路下端共同接到公共电阻 R3=4Ω 的上端，R3 下端与两个电源的下端一并接地。用叠加定理求流过 R3 的电流 I3（方向自上而下为正）。

【解题步骤】
1. 令 E1 单独作用，E2 置零（理想电压源短路）：
   - R2 与 R3 并联：R2∥R3 = (2×4)/(2+4) = 8/6 = 4/3 Ω；
   - 总电阻 = R1 + R2∥R3 = 2 + 4/3 = 10/3 Ω；
   - 由 E1 产生的总电流 I(1) = 12/(10/3) = 3.6A；
   - R3 分得的电流 I3(1) = [R2/(R2+R3)]×I(1) = (2/6)×3.6 = 1.2A（方向自上而下）。
2. 令 E2 单独作用，E1 置零（理想电压源短路）：
   - R1 与 R3 并联：R1∥R3 = (2×4)/(2+4) = 4/3 Ω；
   - 总电阻 = R2 + R1∥R3 = 2 + 4/3 = 10/3 Ω；
   - 由 E2 产生的总电流 I(2) = 6/(10/3) = 1.8A；
   - R3 分得的电流 I3(2) = [R1/(R1+R3)]×I(2) = (2/6)×1.8 = 0.6A（方向自上而下）。
3. 叠加求和：I3 = I3(1) + I3(2) = 1.2 + 0.6 = 1.8A。

【答案解析】
I3 = 1.8A（方向自上而下）。
复核（节点电压法，弥尔曼公式）：V = (E1/R1 + E2/R2)/(1/R1 + 1/R2 + 1/R3) = (6+3)/1.25 = 9/1.25 = 7.2V，故 I3 = V/R3 = 7.2/4 = 1.8A，与叠加结果一致。

【易错提醒】
叠加定理"除源"时：恒压源短路、恒流源开路，但它们的内阻要保留；且功率不能叠加，只有电流、电压才能叠加。

【涉及公式】
叠加定理：各电源单独作用的代数和；弥尔曼公式 Va = [Σ(Ek/Rk)]/[Σ(1/Rk)]。

【知识点链接】
叠加定理（各电源单独作用、其余恒压源短路、恒流源开路）、弥尔曼公式，详见《电子信息专升本 · 第2章 电路分析方法与电路定理》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-02-电路分析方法与电路定理/

### 例题2-3 ｜ 难度：基础

【题目】
某线性含源二端网络的开路电压 Uoc = 18V，短路电流 Isc = 3A。求：
- 其戴维南等效电阻 Req；
- 外接负载 RL = 3Ω 时的负载电流 I 与负载功率 P；
- RL 取何值时获得最大功率，最大功率 Pmax 为多少。

【解题步骤】
1. 求戴维南等效电阻：Req = Uoc/Isc = 18/3 = 6Ω。
2. 求外接 RL = 3Ω 时的负载电流：I = Uoc/(Req + RL) = 18/(6+3) = 2A。
3. 求负载功率：P = I²×RL = 2²×3 = 12W。
4. 求最大功率传输条件：当 RL = Req = 6Ω 时获得最大功率。
5. 求最大功率：Pmax = Uoc²/(4Req) = 18²/(4×6) = 324/24 = 13.5W。

【答案解析】
(1) Req = 6Ω；(2) I = 2A，P = 12W；(3) RL = 6Ω 时 Pmax = 13.5W。

【易错提醒】
戴维南等效电阻可由 Req = Uoc/Isc 直接求；若用"除源法"求 Req，注意受控源必须保留、不能像独立源一样被置零。

【涉及公式】
戴维南 I = Uoc/(Req+R)；诺顿 Isc = Uoc/Req；最大功率 Pmax = Uoc²/(4Req)。

【知识点链接】
戴维南定理、诺顿定理（Isc = Uoc/Req）与最大功率传输定理 Pmax = Uoc²/(4Req)，详见《电子信息专升本 · 第2章 电路分析方法与电路定理》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-02-电路分析方法与电路定理/

## 二、综合应用题

### 例题2-4 ｜ 难度：进阶

【题目】
左网孔含 E1=20V 与 R1=5Ω，右网孔含 E2=10V 与 R2=5Ω，公共支路为 R3=10Ω。两网孔电流分别记为 Ia、Ib（均取顺时针方向），流过 R3 的电流取自上向下为正。用网孔电流法求两网孔电流 Ia、Ib 及流过 R3 的电流 I3。

【解题步骤】
1. 对左网孔列 KVL。绕行方向取网孔电流 Ia 的顺时针方向，自阻为 R1+R3，互阻为 R3（与相邻网孔电流 Ib 相反）：
   (R1+R3)×Ia - R3×Ib = E1，即 15×Ia - 10×Ib = 20 ……(1)
2. 对右网孔列 KVL。右网孔顺时针绕行时 E2 为"降压"，取负号：
   (R2+R3)×Ib - R3×Ia = -E2，即 15×Ib - 10×Ia = -10，整理为 10×Ia - 15×Ib = 10 ……(2)
3. 解方程组：
   - 式(1)×3：45×Ia - 30×Ib = 60；
   - 式(2)×2：20×Ia - 30×Ib = 20；
   - 两式相减：25×Ia = 40，得 Ia = 1.6A。
4. 代回式(1)：15×1.6 - 10×Ib = 20，即 24 - 10×Ib = 20，得 Ib = 0.4A。
5. 求流过 R3 的电流（自上向下）：I3 = Ia - Ib = 1.6 - 0.4 = 1.2A。

【答案解析】
Ia = 1.6A，Ib = 0.4A，I3 = 1.2A（自上向下）。
复核（节点电压法）：节点电压 V = (20/5 + 10/5)/(1/5 + 1/5 + 1/10) = 6/0.5 = 12V，I3 = 12/10 = 1.2A；R1 电流 (20-12)/5 = 1.6A，R2 电流 (10-12)/5 = -0.4A（实际方向向上，大小为 0.4A），与网孔法结果一致。

【易错提醒】
网孔法公式为"自阻×本网孔电流 - 互阻×邻网孔电流 = 本网孔电压源升压和"。列右网孔方程时 E2 与绕行方向相反，右边应写 -E2，符号错一处则整个结果错。

【涉及公式】
网孔电流法：自阻×本网孔电流 - 互阻×邻网孔电流 = 本网孔电压源升压和。

【知识点链接】
网孔电流法：自阻×本网孔电流 - 互阻×邻网孔电流 = 本网孔电压源升压和，详见《电子信息专升本 · 第2章 电路分析方法与电路定理》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-02-电路分析方法与电路定理/

### 例题2-5 ｜ 难度：进阶

【题目】
三条支路汇于节点 A：支路 1 为 E1=12V（正极朝 A）串联 R1=4Ω；支路 2 为 E2=8V（正极朝 A）串联 R2=4Ω；支路 3 为 R3=2Ω，一端接节点 A、另一端接参考点（接地）。用节点电压法（弥尔曼公式）求节点电压 Va，及各支路电流 I1、I2、I3（I1、I2 取流入节点 A 为正，I3 取流出为正）。

【解题步骤】
1. 写出弥尔曼公式：Va = [Σ(Ek/Rk)] / [Σ(1/Rk)]。
2. 求分子（各支路电源除以本支路电阻之和）：
   E1/R1 + E2/R2 = 12/4 + 8/4 = 3 + 2 = 5。
3. 求分母（各支路电导之和）：
   1/R1 + 1/R2 + 1/R3 = 1/4 + 1/4 + 1/2 = 0.25 + 0.25 + 0.5 = 1。
4. 求节点电压：Va = 5/1 = 5V。
5. 求支路 1 电流：I1 = (E1 - Va)/R1 = (12 - 5)/4 = 1.75A。
6. 求支路 2 电流：I2 = (E2 - Va)/R2 = (8 - 5)/4 = 0.75A。
7. 求支路 3 电流：I3 = Va/R3 = 5/2 = 2.5A。

【答案解析】
Va = 5V；I1 = 1.75A，I2 = 0.75A，I3 = 2.5A。
校验：节点 A 的 KCL 为 I1 + I2 = I3，即 1.75 + 0.75 = 2.5A，成立。

【易错提醒】
弥尔曼公式只对"所有支路都汇于同一个节点"的电路直接适用，且分子中电源的方向符号要按"正极朝该节点为正"统一定义，方向不一致会算错。

【涉及公式】
弥尔曼公式 Va = [Σ(Ek/Rk)] / [Σ(1/Rk)]。

【知识点链接】
节点电压法与弥尔曼公式（两节点/单节点电路），详见《电子信息专升本 · 第2章 电路分析方法与电路定理》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-02-电路分析方法与电路定理/

## 三、拓展思考题

### 例题2-6 ｜ 难度：拓展

【题目】
某信号源对外可等效为开路电压 Uoc = 2V、内阻 Req = 600Ω 的戴维南模型。
(1) 若要扬声器（当作纯电阻）获得最大功率，扬声器阻值应为多少？此时功率多大？
(2) 若实际扬声器只有 8Ω（远小于 600Ω），直接接入会得到多大功率？损耗主要在何处？
(3) 工程上如何用变压器实现阻抗匹配？

【思路提示】
利用最大功率传输条件 RL = Req 求匹配阻值与 Pmax = Uoc²/(4Req)；再比较小负载直接接入时的功率，理解"匹配"的意义；最后用变压器变比实现源内阻向负载的折算。

【参考答案要点】
(1) 当 RL = Req = 600Ω 时获得最大功率，Pmax = Uoc²/(4Req) = 4/2400 ≈ 1.67mW。
(2) 8Ω 直接接入时，I = 2/(600+8) ≈ 3.29mA，负载功率 P = I²×8 ≈ 86.5μW，远小于最大功率；此时绝大部分功率（约 98% 以上）消耗在 600Ω 内阻上，负载只分得极小一部分。
(3) 用理想变压器作阻抗匹配，设匝数比 n = N1/N2，则折算到一次侧的负载为 n²×RL = Req，即 n = √(Req/RL) = √(600/8) = √75 ≈ 8.66，即可把 8Ω 负载等效为 600Ω，实现最大功率传输。本题说明最大功率传输定理在功率放大器与扬声器匹配这类实际场合中的工程意义。

## 本章公式速查

- 串联等效：R = R1 + R2
- 并联等效：R = R1R2/(R1+R2)
- 分压公式：Uk = (Rk/R)U
- 分流公式：I1 = [R2/(R1+R2)]·I
- 电源等效：Is = E/r（内阻不变）
- 叠加定理：各电源单独作用的代数和（功率不可叠加）
- 戴维南：I = Uoc/(Req+R)
- 诺顿：Isc = Uoc/Req
- 最大功率传输：R = Req 时 Pmax = Uoc²/(4Req)
- 弥尔曼公式：Va = [Σ(Ek/Rk)] / [Σ(1/Rk)]
