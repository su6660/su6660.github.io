# 第 9 章 数制码制与逻辑代数

## 一、考纲考点清单

1. 数制的表示与转换（二、八、十六、十进制）
2. BCD 码（8421 码）
3. 逻辑代数的基本运算、基本定律与常用公式
4. 逻辑函数的表示方法（真值表、表达式、卡诺图、逻辑图）及相互转换
5. 逻辑函数的化简（代数法、卡诺图法）

## 二、核心知识点

### 2.1 数制与码制

- **数制转换**：
  - 其他进制 → 十进制：按权展开求和，如 (1011.01)₂ = 1×2³+0×2²+1×2¹+1×2⁰+0×2⁻¹+1×2⁻² = 11.25；
  - 十进制 → 二进制：整数部分除 2 取余（倒序），小数部分乘 2 取整（正序）；
  - 二进制 ↔ 八进制：三位一组；二进制 ↔ 十六进制：四位一组。
- **8421 BCD 码**：用四位二进制数表示一位十进制数（0000~1001）。注意与纯二进制的区别，如十进制 29 = (0010 1001)BCD。
- 格雷码：相邻两码仅一位不同（了解）。

### 2.2 逻辑代数基本运算与定律

- 三种基本运算：
  - 与：F = A·B（有 0 出 0，全 1 出 1）
  - 或：F = A + B（有 1 出 1，全 0 出 0）
  - 非：F = Ā（取反）
- 常用复合运算：与非、或非、与或非、异或（F = A⊕B，相异为 1）、同或（F = A⊙B，相同为 1）。
- **基本定律**（务必熟背）：
  - 交换律、结合律、分配律：A(B+C) = AB+AC；A+BC = (A+B)(A+C)；
  - 0-1 律、互补律：A·Ā = 0，A + Ā = 1；重叠律 A+A = A、A·A = A；
  - 吸收律：A + AB = A；A + ĀB = A + B；
  - **反演律（德·摩根）**：(A·B)' = Ā + B̄；(A+B)' = Ā·B̄。

### 2.3 逻辑函数表示与化简

- 表示方法：真值表、逻辑表达式（与或式/或与式）、卡诺图、逻辑图，四种可相互转换。
- **最小项**：包含全部变量的乘积项，n 变量共有 2ⁿ 个，编号 m0~m(2ⁿ−1)。
- **卡诺图化简**步骤：按真值表/最小项填图（格雷码顺序排列）→ 圈 1（圈大不圈小、圈数最少、2^n 个组成矩形/方形，可重复圈、可跨边界）→ 每个圈消去发生变化的变量 → 各圈乘积项相或。
- 有无关项（约束项）时圈 1 可把无关项当 1 用（×）。
- 代数法化简：反复运用吸收律、摩根定律等。

## 三、关键公式速查

| 名称 | 公式 |
| --- | --- |
| 摩根定律 | (AB)' = Ā+B̄；(A+B)' = ĀB̄ |
| 吸收律 | A+AB = A；A+ĀB = A+B |
| 互补律 | A+Ā = 1；A·Ā = 0 |
| 异或 | A⊕B = ĀB + AB̄ |

## 四、典型例题

**例 1**：用卡诺图化简 F = Σm(0, 1, 2, 3, 6, 7)（三变量 A、B、C）。

**解**：卡诺图按 BC：00/01/11/10 排列：
- 圈 1：m0、m1 相邻（ĀB̄·C̄ 与 ĀB̄·C 合并）→ **ĀB̄**；
- m2、m3、m6、m7 构成两行两列大圈 → **B**（A、C 均变化消去）；
- 结果：**F = ĀB̄ + B**。进一步吸收：F = **Ā + B**。

**例 2**：把十进制 29 分别转换为二进制、八进制、十六进制与 8421BCD 码。

**解**：
- 二进制：29/2 依次取余 → **(11101)₂**；
- 八进制：11101 → 011 101 → **(35)₈**；
- 十六进制：1 1101 → **(1D)₁₆**；
- 8421BCD：(0010 1001)BCD。

## 五、解题方法小结与易错点

- 卡诺图化简圈卡诺圈的四个原则：**圈大、圈少、不遗漏、可重叠**；边界相邻（循环码）不要漏。
- 结果不唯一但项数、变量数应最少；最后要把答案与真值表验证。
- BCD 码与二进制一定分清：BCD 每一位十进制独立编码，不能与纯二进制混算。
- 摩根定律用于求反函数和变换与非式，写反函数时"与变或、或变与、原变量与反变量互变"。
