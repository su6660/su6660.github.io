# 第 6 章 基本放大电路

## 一、考纲考点清单

1. 共发射极放大电路的组成
2. 静态工作点的设置与估算（直流通路）
3. 放大电路的动态分析（图解法、小信号等效电路法）
4. 静态工作点的稳定（分压式偏置电路）
5. 共集电极（射极输出器）与共基极放大电路
6. 多级放大电路（级间耦合方式、总增益计算）

## 二、核心知识点

### 2.1 电路组成与直流通路/交流通路

- 组成原则：发射结正偏、集电结反偏；信号能进能出；输出不失真。
- **直流通路**（求静态）：电容开路，交流源置零。**交流通路**（求动态）：电容短路，直流源置零。

### 2.2 静态工作点估算

分压式偏置共射电路：

- UB ≈ UCC·RB2/(RB1 + RB2)；
- IC ≈ IE = (UB − UBE)/RE；
- IB = IC/β；
- UCE ≈ UCC − IC·(RC + RE)。

静态工作点 Q 选择不当会失真：Q 过高→饱和失真（NPN 输出波形底部削波）；Q 过低→截止失真（顶部削波）。

### 2.3 动态指标分析——微变等效电路法

- 三极管等效：b-e 间用输入电阻 rbe，c-e 间用受控电流源 βib。rbe ≈ 300 + (1+β)·26mV/IEQ（Ω）。
- 共射放大电路（负载 RL）：
  - **电压放大倍数** Au = −β·R'L / rbe，其中 R'L = RC // RL（负号表反相）；
  - **输入电阻** Ri = RB1 // RB2 // rbe ≈ rbe；
  - **输出电阻** Ro ≈ RC。

### 2.4 三种组态比较

| 组态 | Au | Ri | Ro | 特点 |
| --- | --- | --- | --- | --- |
| 共射 | 大（反相） | 中 | 较大 | 电压电流均放大，最常用 |
| 共集（射极输出器） | ≈1（同相） | 大 | 很小 | 电压跟随，作输入级/输出级缓冲 |
| 共基 | 同相、与共射相当 | 很小 | 较大 | 高频特性好，用于宽频带电路 |

### 2.5 多级放大电路

- 耦合方式：阻容耦合（各级 Q 点独立，不能放大直流）、直接耦合（可放大缓慢信号，需解决电位配合与零点漂移）、变压器耦合。
- 总增益：Au = Au1 × Au2 × …（分贝相加）。输入电阻取第一级，输出电阻取末级。

## 三、关键公式速查

| 名称 | 公式 |
| --- | --- |
| 基极电位 | UB ≈ UCC·RB2/(RB1 + RB2) |
| 射极电流 | IE ≈ (UB − UBE)/RE |
| 输入电阻 | rbe ≈ 300 + (1+β)·26mV/IEQ |
| 共射增益 | Au = −βR'L/rbe |
| 输出电阻 | Ro ≈ RC |
| 多级总增益 | Au = Au1·Au2·… |

## 四、典型例题

**例 1**：分压偏置共射电路：UCC = 12 V，RB1 = 20 kΩ，RB2 = 10 kΩ，RC = 2 kΩ，RE = 1 kΩ，β = 50，RL = 2 kΩ，UBE = 0.7 V。求 Q 点与 Au、Ri、Ro（设 rbe 由 IE 算出）。

**解**：
- UB = 12×10/(20+10) = 4 V；IE ≈ (4−0.7)/1k = 3.3 mA；
- IC ≈ 3.3 mA → UCE ≈ 12 − 3.3×(2+1) = 2.1 V；IB = 3.3m/50 = 66 μA；
- rbe ≈ 300 + 51×26/3.3 ≈ 300 + 402 ≈ 0.7 kΩ；
- R'L = 2k//2k = 1 kΩ → Au = −50×1k/0.7k ≈ **−71**；
- Ri ≈ rbe//RB1//RB2 ≈ 0.7 kΩ//…≈ **0.65 kΩ**；Ro ≈ RC = **2 kΩ**。

## 五、解题方法小结与易错点

- 直流通路与交流通路先分清楚：直流求 Q，交流求动态指标，不要混用。
- rbe 计算中用**静态** IEQ（mA 单位换算：26mV/IE 中 IE 用 mA）。
- Au 带负号表示反相，填空常挖"相位关系"这一坑。
- 判断失真类型：看 Q 点位置，饱和失真 NPN 是底部失真，截止失真是顶部失真（PNP 相反）。
- 多级电路总 Ri 看第一级、总 Ro 看最后一级。
