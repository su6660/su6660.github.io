# 第 7 章 放大电路中的负反馈

## 一、考纲考点清单

1. 反馈的基本概念（正反馈、负反馈；直流、交流反馈）
2. 四种负反馈组态的判别（电压/电流 × 串联/并联）
3. 负反馈对放大电路性能的影响
4. 深度负反馈条件下的放大倍数估算

## 二、核心知识点

### 2.1 反馈的概念

- 将输出量（电压或电流）的一部分或全部引回输入端，与原输入量叠加。
- **正反馈**使净输入增大（用于振荡器）；**负反馈**使净输入减小（用于稳定放大器），负反馈组态：判别方法——瞬时极性法：设输入信号瞬时极性（+），沿环路标输出及反馈点极性，反馈信号使净输入减小的为负反馈。
- 直流负反馈稳定静态工作点；交流负反馈改善动态性能。

### 2.2 四种组态判别（两大维度）

1. **取样方式**：反馈信号取自输出电压 → **电压反馈**；取自输出电流（反馈支路串在输出回路）→ **电流反馈**。
   - 判断技巧：令输出电压 uo = 0（负载短路），反馈仍存在→电流反馈；反馈消失→电压反馈。
2. **比较方式**：反馈信号与输入信号以电压形式串联叠加于输入端 → **串联反馈**；以电流形式并联叠加于同一节点 → **并联反馈**。
   - 组合得出四种：电压串联、电压并联、电流串联、电流并联。

### 2.3 负反馈对性能的影响

- 稳定放大倍数（放大倍数下降为 1/(1+AF) 分之一倍）；
- 展宽通频带；
- 减小非线性失真；
- 对输入、输出电阻的影响：
  - 串联反馈 → Ri 增大；并联反馈 → Ri 减小；
  - 电压反馈 → Ro 减小；电流反馈 → Ro 增大。

### 2.4 深度负反馈估算

- 深度负反馈满足 |1 + AF| ≫ 1，闭环增益 Af ≈ 1/F。
- 估算技巧：串联负反馈用 uf ≈ ui（虚短电压）；并联负反馈用 if ≈ ii（虚断电流）；电压负反馈用"输出端虚短"，电流负反馈用"输出端虚断"。
- 例：电压串联负反馈深度时 uf = uo·R1/(R1+Rf)，Af = uo/ui ≈ (R1+Rf)/R1。

## 三、关键公式速查

| 名称 | 公式 |
| --- | --- |
| 反馈一般表达式 | Af = A/(1 + AF) |
| 深度负反馈 | Af ≈ 1/F |
| 反馈深度 | 1 + AF |
| 电压串联深反馈增益 | uo/ui ≈ (R1+Rf)/R1（分压网络） |

## 四、典型例题

**例 1**：判断反馈组态——输出电压经电阻 Rf 接回基极（与输入信号在基极节点以电流方式叠加），反馈信号取自输出电压。

**解**：
- 取自 uo → 电压反馈；
- 与输入在基极并联叠加 → 并联反馈；
- 负反馈（瞬时极性分析）→ 组态为**电压并联负反馈**。

**例 2**：电压串联深度负反馈电路，反馈网络 R1 = 10 kΩ，Rf = 40 kΩ。估算闭环增益。

**解**：Af ≈ 1/F = (R1+Rf)/R1 = (10+40)/10 = **5**。

## 五、解题方法小结与易错点

- 判别步骤固定：**取样（电压/电流）→ 比较（串联/并联）→ 极性（正/负）**，三步写全不丢分。
- "输出短路法"判电压/电流反馈、"输入端串并联观察法"判串联/并联要熟练。
- 注意区分：射极输出器是电压串联负反馈；分压式偏置的射极电阻构成直流负反馈稳定 Q 点。
- 正反馈用于正弦波振荡（如 RC/LC 振荡器），判别极性时别把正负搞反。
