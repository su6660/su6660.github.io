# 第 5 章 半导体器件基础

## 一、考纲考点清单

1. 半导体的基础知识（本征、杂质半导体，PN 结的形成）
2. 二极管（伏安特性、主要参数）
3. 特殊二极管（稳压管、发光二极管等）及应用
4. 晶体管（三极管）的结构、特性曲线与工作状态

## 二、核心知识点

### 2.1 半导体与 PN 结

- **本征半导体**：纯净单晶硅/锗，载流子为自由电子—空穴对。
- **杂质半导体**：N 型（掺五价元素，多数载流子为自由电子）；P 型（掺三价元素，多数载流子为空穴）。
- **PN 结**：P 型与 N 型半导体交界处形成，具有**单向导电性**——正向偏置（P 接正、N 接负）导通，反向偏置截止。
- 正向导通压降：硅管约 0.7 V，锗管约 0.3 V；反向击穿电压为重要极限参数。

### 2.2 二极管

- **伏安特性**：正向电压超过死区电压后电流按指数规律迅速增大；反向电流很小（反向饱和电流 Is）。
- **等效模型**：理想模型（正向短路、反向开路）；恒压降模型（正向导通压降取 0.7 V）。
- 应用电路：整流（半波、桥式）、限幅、钳位、续流。
- **稳压二极管**：工作在反向击穿区，反向电流在较大范围变化时两端电压基本不变，用于稳压；与限流电阻配合使用。
- 其它：发光二极管（正向导通发光，工作电流 5~20 mA）、光电二极管（反向电流随光照变化）。

### 2.3 三极管

- **结构**：两个 PN 结、三个区（发射区、基区、集电区）、三个电极 e、b、c；NPN 与 PNP 两类。
- **放大条件**：发射结正偏、集电结反偏（NPN：UBE ≈ 0.7 V 且 UC > UB）。
- **电流分配关系**：Ic = βIb，Ie = Ic + Ib = (1 + β)Ib。
- **三个工作区**：
  - 放大区：发射结正偏、集电结反偏，Ic = βIb（电流放大）；
  - 饱和区：两结均正偏，UCE ≈ UCES ≈ 0.3 V，受控能力消失；
  - 截止区：两结均反偏（或发射结零偏），Ib ≈ 0、Ic ≈ 0，相当于开关断开。
- 三极管可作放大元件（放大区）与开关元件（饱和、截止区）。

## 三、关键公式速查

| 名称 | 公式 |
| --- | --- |
| 电流分配 | Ic = βIb |
| 发射极电流 | Ie = (1 + β)Ib |
| 硅管导通压降 | UBE ≈ 0.6~0.7 V |
| 饱和压降 | UCES ≈ 0.3 V（硅） |

## 四、典型例题

**例 1**：二极管电路：5 V 电源正极串 R = 2 kΩ、二极管 D 到地（硅管）。求电流与二极管端电压。

**解**：
- D 正向导通，恒压降 0.7 V；
- I = (5 − 0.7) / 2k = **2.15 mA**；UD = **0.7 V**。

**例 2**：某 NPN 硅管，UCC = 12 V 经 RB = 240 kΩ 接基极，RC = 2 kΩ，β = 50。判断工作状态。

**解**：
- Ib = (UCC − UBE)/RB = (12 − 0.7)/240k ≈ 47 μA；
- Ic = βIb = 50 × 47μ ≈ 2.35 mA；
- UCE = UCC − Ic·RC = 12 − 2.35×2 = **7.3 V**；
- UCE > 0.3 V 且 Ib > 0 → 工作在**放大区**。

## 五、解题方法小结与易错点

- 判断二极管通断：先假定某状态，按假设计算，若结果矛盾（导通却算出电流反向）则反转假设。
- 三极管状态判断：先算 Ib，再算 Ic = βIb，比较 UCE 与 UCES 判断饱和还是放大（用 β 求出的 Ic 超过饱和电流即进入饱和）。
- 稳压管必须反接才稳压，且稳压时电流不能超过最大稳定电流。
- 判断管型与电极的符号题：NPN 箭头由 b 指向外（e），PNP 箭头指向内。
