## 一、基础概念示例题

### 例题3-1 ｜ 难度：基础

【题目】
电容 C=5μF 已充电至 uc(0) = 10V，t=0 时通过电阻 R=2kΩ 开始放电（零输入响应）。求：
- 时间常数 τ；
- 电容电压 uc(t) 的表达式；
- t=τ 时刻的 uc 值；
- uc 衰减到 1V 所需的放电时间。

【解题步骤】
1. 求时间常数：τ = RC = 2kΩ × 5μF = 2000 × 5×10⁻⁶ = 0.01s = 10ms。
2. 列 RC 零输入响应表达式：uc(t) = U0×e^(-t/τ) = 10×e^(-100t) V（因为 1/τ = 100）。
3. 求 t=τ 时刻的 uc 值：uc(τ) = 10×e^(-1) = 10×0.368 = 3.68V。
4. 求 uc 衰减到 1V 的时间：令 10×e^(-100t) = 1，即 e^(-100t) = 0.1；
   - 两端取自然对数：-100t = ln0.1 = -2.303；
   - 解得：t = 0.02303s ≈ 23ms。

【答案解析】
τ = 10ms；uc(t) = 10×e^(-100t) V；t=τ 时 uc = 3.68V；衰减到 1V 约需 23ms。

【易错提醒】
指数项必须带负号（放电是衰减过程，写成正指数会得到"越放越大"的错误结果）；τ 与 t 必须采用同一时间单位（本题统一用秒）。

【涉及公式】
RC 零输入 uc(t) = U0·e^(-t/τ)；时间常数 τ = RC。

【知识点链接】
RC 零输入响应 uc(t) = U0·e^(-t/τ)、时间常数 τ=RC，详见《电子信息专升本 · 第3章 一阶动态电路与暂态分析》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-03-一阶动态电路与暂态分析/

### 例题3-2 ｜ 难度：基础

【题目】
RL 电路由 Us=20V 直流源、R=4Ω、L=2H 串联构成，t=0 前电感无储能（iL(0)=0），t=0 时接通电源（零状态响应）。求：
- 时间常数 τ；
- 电流 iL(t) 表达式；
- 电感电压 uL(t) 表达式；
- t=τ 与 t=3τ 时刻的 iL 值。

【解题步骤】
1. 求时间常数：τ = L/R = 2/4 = 0.5s。
2. 求稳态电流（t→∞ 时电感相当于短路）：iL(∞) = Us/R = 20/4 = 5A。
3. 列 RL 零状态响应电流表达式：iL(t) = iL(∞)(1 - e^(-t/τ)) = 5(1 - e^(-2t)) A（因为 1/τ = 2）。
4. 列电感电压表达式：uL(t) = L×diL/dt = Us×e^(-t/τ) = 20×e^(-2t) V。
5. 求 t=τ=0.5s 时刻的 iL：iL = 5(1 - e^(-1)) = 5×0.632 = 3.16A。
6. 求 t=3τ=1.5s 时刻的 iL：iL = 5(1 - e^(-3)) = 5×0.9502 = 4.75A。

【答案解析】
τ = 0.5s；iL(t) = 5(1 - e^(-2t)) A；uL(t) = 20×e^(-2t) V；t=τ 时 iL = 3.16A，t=3τ 时 iL = 4.75A。

【易错提醒】
RL 电路的 τ = L/R；注意储能元件在稳态的等效——稳态时电感相当于短路、电容相当于开路，用此结果求稳态值才不会出错。

【涉及公式】
RL 零状态 iL(t) = I0(1 - e^(-t/τ))；τ = L/R；电感电压 u = L·di/dt。

【知识点链接】
RL 零状态响应、时间常数 τ=L/R、电感电压 u = L·di/dt，详见《电子信息专升本 · 第3章 一阶动态电路与暂态分析》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-03-一阶动态电路与暂态分析/

### 例题3-3 ｜ 难度：基础

【题目】
RC 串联电路由 Us=12V 直流源、R=1kΩ、C=10μF 构成，电容初值 uc(0) = 0，t=0 时接通电源（零状态响应）。求：
- 时间常数 τ；
- 电容电压 uc(t) 表达式；
- 充电电流 i(t) 表达式；
- t=τ 与 t=5τ 时刻的 uc 值。

【解题步骤】
1. 求时间常数：τ = RC = 1kΩ × 10μF = 1000 × 10×10⁻⁶ = 0.01s。
2. 列 RC 零状态响应电容电压表达式：uc(t) = Us(1 - e^(-t/τ)) = 12(1 - e^(-100t)) V。
3. 列充电电流表达式：i(t) = (Us/R)×e^(-t/τ) = (12/1000)×e^(-100t) = 12×e^(-100t) mA。
4. 求 t=τ=0.01s 时刻的 uc：uc = 12(1 - e^(-1)) = 12×0.632 = 7.58V。
5. 求 t=5τ=0.05s 时刻的 uc：uc = 12(1 - e^(-5)) = 12×0.9933 = 11.92V（已接近稳态值 12V）。

【答案解析】
τ = 0.01s；uc(t) = 12(1 - e^(-100t)) V；i(t) = 12×e^(-100t) mA；t=τ 时 uc = 7.58V，t=5τ 时 uc = 11.92V。

【易错提醒】
一般 t = 3τ～5τ 即可认为过渡过程结束；本题 t=5τ 时 uc 与稳态值相差不足 1%，若把 5τ 当"还没开始充电"则理解有误。

【涉及公式】
RC 零状态 uc(t) = Us(1 - e^(-t/τ))；充电电流 i = (Us/R)·e^(-t/τ)。

【知识点链接】
RC 零状态响应 uc(t) = Us(1 - e^(-t/τ))、t=5τ 过渡过程基本结束，详见《电子信息专升本 · 第3章 一阶动态电路与暂态分析》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-03-一阶动态电路与暂态分析/

## 二、综合应用题

### 例题3-4 ｜ 难度：进阶

【题目】
RC 电路中，电容初值 uc(0-) = 8V，R = 1kΩ，C = 2μF；t=0 时将其接入 Us=24V 直流源（全响应）。用三要素法求 uc(t)，并求 t=τ 时刻的 uc 值。

【解题步骤】
1. 写出三要素法公式：f(t) = f(∞) + [f(0+) - f(∞)]×e^(-t/τ)。
2. 求时间常数：τ = RC = 1kΩ × 2μF = 1000 × 2×10⁻⁶ = 2×10⁻³ s = 2ms。
3. 求初始值：由换路定律 uc(0+) = uc(0-) = 8V。
4. 求稳态值：t→∞ 时电容相当于开路，uc(∞) = Us = 24V。
5. 代入三要素法公式：
   uc(t) = 24 + (8 - 24)×e^(-t/0.002) = 24 - 16×e^(-500t) V（因为 1/τ = 500）。
6. 求 t=τ=2ms 时刻的 uc：uc = 24 - 16×e^(-1) = 24 - 5.886 = 18.11V。

【答案解析】
uc(t) = 24 - 16×e^(-500t) V；t=τ 时 uc = 18.11V。
校验：t=0 时 uc = 24 - 16 = 8V（与初值一致）；t→∞ 时 uc → 24V（与稳态一致）。

【易错提醒】
初始值、稳态值、时间常数三者缺一不可；求 τ 时 R 是从储能元件两端看进去的"除源"等效电阻，本题只有单一 R 故直接取 1kΩ。

【涉及公式】
三要素法 f(t) = f(∞) + [f(0+) - f(∞)]·e^(-t/τ)；换路定律 uc(0+) = uc(0-)。

【知识点链接】
三要素法 f(t) = f(∞) + [f(0+) - f(∞)]·e^(-t/τ)、换路定律 uc(0+) = uc(0-)，详见《电子信息专升本 · 第3章 一阶动态电路与暂态分析》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-03-一阶动态电路与暂态分析/

### 例题3-5 ｜ 难度：进阶

【题目】
RL 电路中，E=18V、R1=2Ω、R2=4Ω、L=1.5H。t=0 前开关 S 将 R2 短路，电感与 R1 串联接 E 已处稳态；t=0 时 S 断开，R2 串入回路。用三要素法求 iL(t)，并求 t=τ 与 t=3τ 时刻的 iL 值。

【解题步骤】
1. 求换路前稳态电流：t=0- 时电感相当于短路，iL(0-) = E/R1 = 18/2 = 9A。
2. 由换路定律求初始值：iL(0+) = iL(0-) = 9A。
3. 求换路后稳态电流：t→∞ 时电感相当于短路，iL(∞) = E/(R1+R2) = 18/(2+4) = 3A。
4. 求时间常数（R 为换路后从电感两端看进去的除源等效电阻）：
   τ = L/(R1+R2) = 1.5/6 = 0.25s。
5. 代入三要素法公式：
   iL(t) = 3 + (9 - 3)×e^(-t/0.25) = 3 + 6×e^(-4t) A（因为 1/τ = 4）。
6. 求 t=τ=0.25s 时刻的 iL：iL = 3 + 6×e^(-1) = 3 + 2.207 = 5.21A。
7. 求 t=3τ=0.75s 时刻的 iL：iL = 3 + 6×e^(-3) = 3 + 0.299 = 3.30A。

【答案解析】
iL(t) = 3 + 6×e^(-4t) A；t=τ 时 iL = 5.21A，t=3τ 时 iL = 3.30A。
校验：t=0 时 iL = 3 + 6 = 9A（与初值一致）；t→∞ 时 iL → 3A（与稳态一致）。

【易错提醒】
换路前后电路结构改变，时间常数 τ 必须用换路后的等效电阻计算，不能沿用换路前的电阻；换路定律只保证 iL、uc 在 0+ 时刻连续，其余量可突变。

【涉及公式】
三要素法 f(t) = f(∞) + [f(0+) - f(∞)]·e^(-t/τ)；τ = L/R；换路定律 iL(0+) = iL(0-)。

【知识点链接】
三要素法、换路定律 iL(0+) = iL(0-)、时间常数 τ=L/R 中 R 的求取，详见《电子信息专升本 · 第3章 一阶动态电路与暂态分析》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-03-一阶动态电路与暂态分析/

## 三、拓展思考题

### 例题3-6 ｜ 难度：拓展

【题目】
在继电器、接触器等电感性线圈电路中，为什么强制断电的瞬间，线圈两端会产生远高于电源电压的尖峰（可能击穿开关触点或损坏驱动管）？若某线圈 R=10Ω、L=0.5H 正常通电时稳态电流 I0=2A，突然被开关断开，理论上断开瞬间线圈电压可达多高？工程上又该如何抑制这一现象？

【思路提示】
从"电感电流不能突变"与 u = L·di/dt 入手：断电瞬间 iL 被强迫迅速下降，di/dt 趋于极大，使 uL 趋于极高。思考电感中储存的磁场能量（W = ½Li²，此处 W = ½×0.5×2² = 1J）的去路，以及续流二极管如何为该能量提供续流回路。

【参考答案要点】
电感电流 iL 不能突变，断电瞬间开关迫使电流在极短时间内降为 0，di/dt 趋于无穷大，故 uL = L·di/dt 理论上趋于无穷大（实际受线圈分布电容限制为一个有限高电压），足以击穿触点或在驱动管两端产生高压尖峰。工程上常在线圈两端反并联一只续流二极管：正常通电时二极管反偏截止、不参与工作；断电瞬间 iL 通过二极管续流，磁场能量经电阻回路释放，电流按 iL = I0·e^(-t/τ) 衰减（τ = L/R = 0.5/10 = 0.05s），从而把反压钳制在约一个二极管压降（约 0.7V）附近，保护开关与驱动器件。本题串联了"换路定律、u = L·di/dt、磁场能量 W = ½Li²、时间常数 τ = L/R"等多个知识点。

## 本章公式速查

- 电容伏安关系：i = C·du/dt
- 电感伏安关系：u = L·di/dt
- 换路定律：uc(0+) = uc(0-)、iL(0+) = iL(0-)
- 时间常数：τ = RC（RC 电路）、τ = L/R（RL 电路）
- RC 零输入：uc(t) = U0·e^(-t/τ)
- RC 零状态：uc(t) = Us(1 - e^(-t/τ))
- 三要素法：f(t) = f(∞) + [f(0+) - f(∞)]·e^(-t/τ)
- 过渡过程：约 t = 3τ～5τ 结束
