> 训练到位但体重不动，问题一定出在吃上。
> 本文把"增重"变成**可算账的事**：先算出自己的热量缺口/盈余，再拆解蛋白质、碳水、脂肪的具体克数，然后给训练前中后的吃法与加餐清单，最后附**体重监控法**、**食堂外食攻略**和**补剂证据分级表**。
> 目标场景：**170cm / 63kg，希望半年到 68~70kg，同时 1000 米成绩不下降。**

<!-- more -->

## 一、第一步：把热量算清楚

### 1.1 算基础代谢（Mifflin-St Jeor 公式）

```
男性 BMR = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄(岁) + 5
```

以 **63kg / 170cm / 23 岁** 代入：

```
BMR = 10×63 + 6.25×170 − 5×23 + 5
    = 630 + 1062.5 − 115 + 5
    ≈ 1583 kcal
```

### 1.2 乘活动系数得 TDEE（每日总消耗）

| 活动水平 | 系数 | 你的情况 |
|---|---|---|
| 久坐 | 1.2 | 仅办公/学习 |
| 轻度活动 | 1.375 | 每周 1~3 次训练 |
| **中度活动** | **1.55** | **每周 4~6 次训练（本方案）** |
| 高度活动 | 1.725 | 每天高强度训练 + 体力工作 |

```
TDEE ≈ 1583 × 1.55 ≈ 2454 kcal
```

### 1.3 加上盈余

| 目标 | 盈余 | 备注 |
|---|---|---|
| 稳增（推荐） | **+300~500 kcal** | 每月增重约 0.9~1.5kg |
| 激进 | +700~1000 kcal | 脂肪比例明显上升 |

**你的每日摄入目标 ≈ 2750~2950 kcal**（推荐从 **2800 kcal** 起）。

```
BMR 1583 kcal  →  × 活动系数 1.55  →  TDEE ≈ 2454 kcal  →  + 300~500  →  目标 2750~2950 kcal
```

> **重要**：以上是**估算起点**，必须用下面的"体重监控法"校正——公式永远不如两周的真实体重数据准。

## 二、三大营养素怎么配

### 2.1 蛋白质：1.6~2.2 g/kg

- 增肌期推荐 **1.6~2.2 g/kg**，超过 2.2 无额外增肌收益（也只是浪费，不伤肾——健康人无需担心）。
- 63kg → **每日 105~140g**，取 **120g** 为实操目标。
- **分配**：**每餐 25~35g，分 4 餐**（比"一顿猛吃 60g"利用率更高）。

| 食物 | 每 100g 蛋白 | 一份 ≈ 蛋白 |
|---|---|---|
| 鸡胸肉 | 24g | 150g ≈ 36g |
| 鸡蛋 | 13g（约 6g/个） | 3 个 ≈ 18g |
| 牛奶 | 3.3g | 500ml ≈ 16g |
| 希腊酸奶 | 10g | 200g ≈ 20g |
| 瘦牛肉 | 21g | 150g ≈ 31g |
| 乳清蛋白粉 | 80g | 1 勺 30g ≈ 24g |
| 豆制品（北豆腐） | 12g | 200g ≈ 24g |

### 2.2 碳水：4~6 g/kg（增重期偏高）

- 碳水是**训练燃料 + 胰岛素介导的合成环境**，增重期不要怕碳水。
- 63kg → **每日 250~380g**，取 **320g**。
- 优先：**米饭、面、燕麦、土豆、红薯、水果**；训练前后集中的碳水更关键。

### 2.3 脂肪：0.8~1.2 g/kg

- 63kg → **每日 50~75g**，取 **65g**。来源：坚果、橄榄油、牛油果、蛋黄、全脂奶。
- **不必低于 0.6 g/kg**——脂肪过低影响激素水平。

### 2.4 每日配比示例（2800 kcal）

| 营养素 | 目标量 | 热量 |
|---|---|---|
| 蛋白质 | 120g | 480 kcal |
| 碳水 | 320g | 1280 kcal |
| 脂肪 | 65g | 585 kcal |
| **合计** | — | **约 2345 kcal** |

> 剩余约 450 kcal 由蔬菜、水果、加餐补足（不必精确到每一克，**蛋白质和总热量是唯二必须盯住的数字**）。

## 三、训练前后怎么吃

| 时间点 | 内容 | 要点 |
|---|---|---|
| 训练前 2~3 小时 | 正餐：碳水 + 蛋白 | 如米饭 + 鸡胸 + 蔬菜 |
| 训练前 30~60 分钟 | 小份碳水（香蕉/面包） | 避免大量脂肪与纤维（易胀） |
| 训练后 1~2 小时内 | **碳水 + 蛋白**（如 30~40g 蛋白 + 60~80g 碳水） | "窗口期"没那么窄，**全天蛋白总量更重要** |
| 睡前 | 慢蛋白（希腊酸奶/牛奶/酪蛋白） | 夜间修复 |

**简化版**：把每天的蛋白按 4 餐分掉、训练后一小时内吃一顿正餐——就够好了。

## 四、增重加餐清单（缺口靠这里补）

每天差 400~500 kcal，靠加餐补最省事：

| 加餐组合 | 热量 | 蛋白 |
|---|---|---|
| 全脂奶 500ml + 燕麦 50g | ~420 | ~20g |
| 花生酱 2 勺 + 全麦面包 2 片 + 香蕉 | ~450 | ~15g |
| 乳清 1 勺 + 香蕉 + 牛奶 | ~380 | ~30g |
| 鸡蛋 3 个 + 全脂奶 300ml | ~350 | ~28g |
| 坚果 40g + 酸奶 | ~400 | ~15g |

**增重困难户的实战技巧**：
1. **喝比吃省事**：全脂奶 + 蛋白粉 + 香蕉打成奶昔，一杯 500 kcal。
2. **液体热量不占胃**：训练前后喝奶比等一顿饭快。
3. **别用"高纤维食物"填肚子**：蔬菜占体积但热量低，容易吃撑却没吃够。

## 五、体重监控法（比公式可靠）

**做法**：
1. **每周固定时间称重**（如每天早晨空腹、排便后、同一件衣服）；
2. **取 7 天平均值**，只看**周均值的变化趋势**；
3. 配合**腰围（肚脐水平）+ 每月同一角度照片**。

**判读**：

| 周均重变化 | 结论 | 调整 |
|---|---|---|
| +0.2~0.4kg/周 | **理想** | 保持 |
| < +0.1kg/周 | 吃少了 | 每日 +200 kcal |
| > +0.6kg/周 | 吃太多（脂肪多） | 每日 −200 kcal |
| 不动或下降 | 有氧过多或吃得不够 | 先查记录，再加碳水 |

## 六、食堂 / 外食怎么吃

| 场景 | 策略 |
|---|---|
| 食堂 | 主菜选肉类（鸡/牛/鱼）、主食加量、少点油炸、**多打一份鸡蛋或豆腐** |
| 快餐 | 选烤/蒸类主食加量，点双份肉，去掉含糖饮料 |
| 聚餐 | 吃完再补一勺蛋白 + 一杯奶，当天不必扣热量 |
| 时间紧 | 便利店：牛奶 + 茶叶蛋 + 饭团 + 蛋白棒 |

**原则**：**优先凑够蛋白质，其次凑够总热量**，其余细节可以粗糙。

## 七、补剂：按证据分级选择

| 等级 | 补剂 | 用法 | 说明 |
|---|---|---|---|
| **A 级（强烈推荐）** | 肌酸（一水肌酸） | 每天 3~5g，**不需要冲击期** | 增力增围度证据最充分，唯一"必吃"的 |
| **A 级** | 乳清蛋白粉 | 1~2 勺/天 | 只是**方便的食物**，不是必需品 |
| **A 级** | 维生素 D3 | 1000~2000 IU/天 | 日照不足者普遍缺乏 |
| B 级 | 咖啡因 | 训练前 3~6mg/kg | 提升表现，注意下午后别喝 |
| B 级 | β-丙氨酸 | 3.2g/天 | 对 1~4 分钟高强度（如 1000 米）有帮助，可能皮肤发麻 |
| **基本无效** | BCAA、睾酮"促泌剂"、氮泵（长用） | — | 不缺氨基酸时 BCAA 无意义 |

**每年建议体检一次**，确认无基础问题。

## 八、睡眠与酒精（被低估的两个变量）

- **睡眠 7~9 小时**：睡眠不足会降低睾酮、提高皮质醇、降低训练表现与恢复速度——**任何补剂都比不上睡眠**。
- **酒精**：抑制蛋白合成、影响睡眠质量、额外热量。**训练日尽量不喝**；喝就把热量算进预算。

## 九、常见坑

| 坑 | 真相 |
|---|---|
| 脏增重（炸鸡、奶茶堆热量） | 脂肪涨得比肌肉快，后期还得减脂 |
| 怕"蛋白伤肾" | 健康人无风险，多喝水即可 |
| 迷信"训练后 30 分钟窗口" | 全天总蛋白量远比窗口时间重要 |
| 只算热量不管蛋白 | 热量够了但蛋白不足，长的多是脂肪 |
| 每天纠结精确克数 | 盯住**总热量 + 蛋白质**两个数字即可 |
| 体重一周不动就崩溃 | 看 7 日均值趋势，至少观察两周 |

## 十、一页速查

```
热量：BMR 1583 × 1.55 ≈ 2454 → 目标 2800 kcal
蛋白：120g（4 餐 × 30g）
碳水：320g（训练前后集中）
脂肪：65g
加餐：全脂奶 + 燕麦 / 蛋白粉奶昔 / 花生酱面包
监控：每周同条件称重，取 7 日均值
补剂：肌酸 5g/天 + 乳清 + 维 D（其余可省）
底线：睡眠 ≥7h，训练日不喝酒
```
