# 电子信息专升本例题集 · 第7章 放大电路中的负反馈

本章例题聚焦「放大电路中的负反馈」的四大核心考点，覆盖考纲要求：反馈极性的判断（正 / 负、瞬时极性法）；四种组态的判别（电压 / 电流 × 串联 / 并联）；负反馈对放大倍数、输入输出电阻、通频带的影响；以及深度负反馈下闭环增益的估算。全套例题分三级难度：基础题直接套用"取样—比较—极性"三步判别法与闭环增益公式 Af=A/(1+AF)；进阶题综合组态判断与深度负反馈估算 Af≈1/F；拓展题引导你理解反馈深度与自激振荡的边界。建议先抓准"取样点决定电压 / 电流反馈、比较点决定串联 / 并联反馈"两大入口，再逐题推演。

## 一、基础概念示例题

### 例题7-1 ｜ 难度：基础

【题目】
某放大电路的反馈网络从输出电压取样（反馈网络与负载两端并联），反馈信号在输入端以电流形式与输入信号并联叠加，且经瞬时极性法判断为负反馈。试判断该电路的反馈组态，并说明该组态对输入电阻、输出电阻的影响。

【已知条件】
- 取样：取自输出电压（与负载并联）
- 比较：输入端以电流形式并联叠加
- 极性：负反馈

【待求】
- 反馈组态
- 对输入电阻与输出电阻的影响

【解题步骤】
1. 取样点落在输出电压上 → 电压反馈。
2. 输入端的反馈信号与输入信号以电流形式并联叠加 → 并联反馈。
3. 极性为负 → 综合为电压并联负反馈。
4. 影响：并联反馈使输入电阻 Ri 减小；电压反馈稳定输出电压、使输出电阻 Ro 减小。

【答案解析】
反馈组态为电压并联负反馈；它使 Ri 减小、Ro 减小，同时稳定增益、展宽频带、减小非线性失真。

【方法归纳】
组态判别的固定三步：先看取样（电压 / 电流），再看比较（串联 / 并联），最后看极性（正 / 负），三者组合命名。

【易错提醒】
- 电压 / 电流反馈看取样，不看输入端；串联 / 并联反馈看比较，不看输出端，两者别混。
- 口诀：负载短路后反馈消失为电压反馈，仍存在为电流反馈。

【知识点链接】
覆盖负反馈四种组态的判别，详见《电子信息专升本 · 第7章 放大电路中的负反馈》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-07-放大电路中的负反馈/

### 例题7-2 ｜ 难度：基础

【题目】
单级共射放大电路中，集电极输出电压经反馈电阻 Rf 引回到基极输入端。设输入信号瞬时极性为正（基极瞬时电位升高），试用瞬时极性法判断该反馈是正反馈还是负反馈，并说明其组态。

【已知条件】
- 单级共射放大，输出与输入反相
- 反馈支路：集电极输出经 Rf 引回基极
- 输入瞬时极性取 "+"

【待求】
- 反馈极性判断
- 反馈组态

【解题步骤】
1. 设基极输入瞬时极性为 "+"。
2. 共射放大反相，集电极输出瞬时极性为 "−"。
3. 该 "−" 信号经 Rf 引回基极，使基极瞬时电位下降。
4. 基极电位下降使净输入信号（be 结电压、净基极电流）减小，故为负反馈。
5. 取样点在集电极输出（电压）、输入端以电流并联比较，故组态为电压并联负反馈。

【答案解析】
该反馈为负反馈，组态为电压并联负反馈。

【方法归纳】
瞬时极性法：标出输入极性 → 沿放大级逐级确定输出极性 → 引回输入端比较净输入增减；净输入减小为负反馈，增大为正反馈。

【易错提醒】
- 共射级反相、共集级同相，极性标注时先明确各级的相移关系。
- 正反馈用于振荡器，负反馈用于改善放大性能，注意别把极性判反。

【知识点链接】
覆盖瞬时极性法与反馈极性判别，详见《电子信息专升本 · 第7章 放大电路中的负反馈》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-07-放大电路中的负反馈/

### 例题7-3 ｜ 难度：基础

【题目】
某放大电路的开环增益 A=1000，引入负反馈后闭环增益 Af=100。求反馈系数 F 与反馈深度 1+AF，并说明引入负反馈前后增益的变化关系。

【已知条件】
- 开环增益：A=1000
- 闭环增益：Af=100

【待求】
- 反馈系数 F
- 反馈深度 1+AF

【解题步骤】
1. 由闭环增益公式 Af=A/(1+AF) 反解反馈深度：1+AF=A/Af。
2. 代入数值：1+AF=1000/100=10。
3. 由 F=(（1+AF)−1)/A 求反馈系数：F=(10−1)/1000=9/1000=0.009。
4. 结论：引入负反馈后增益稳定、下降为开环的 1/10。

【答案解析】
反馈系数 F=0.009，反馈深度 1+AF=10；闭环增益为开环增益的十分之一。

【方法归纳】
闭环增益公式 Af=A/(1+AF) 是负反馈计算的核心，给定 A 与 Af 即可反解 F 与反馈深度；深度越深，增益下降越多但越稳定。

【易错提醒】
- 注意 F 的量纲与 1+AF 的区别，1+AF 是倍数、F 是反馈系数，别混用。
- Af 恒小于 A（负反馈），若算出的 Af>A 说明极性判断有误（可能是正反馈）。

【变式延伸】
若本题反馈改为正反馈，闭环增益变为 Af=A/(1−AF)，增益反而增大；当 1−AF 趋近于 0（AF→1）时 Af→∞，电路即进入自激振荡，这是负反馈与正反馈在增益上的本质差别。

【知识点链接】
覆盖负反馈闭环增益公式 Af=A/(1+AF) 与反馈深度，详见《电子信息专升本 · 第7章 放大电路中的负反馈》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-07-放大电路中的负反馈/

## 二、综合应用题

### 例题7-4 ｜ 难度：进阶

【题目】
电压串联负反馈放大电路的反馈网络由电阻 R1=10 kΩ 与 Rf=90 kΩ 组成：输出电压 uo 经 Rf、R1 分压，在 R1 上取得反馈电压引回输入端，与输入信号以电压形式串联比较，极性为负。试说明该电路为何是电压串联负反馈，并在深度负反馈条件下估算闭环电压增益 Af。

【已知条件】
- 反馈网络：R1=10 kΩ，Rf=90 kΩ
- 取样：取自输出电压 uo
- 比较：输入端以电压串联比较，极性为负

【待求】
- 组态说明
- 深度负反馈下闭环增益 Af

【解题步骤】
1. 取样自输出电压 uo → 电压反馈。
2. 反馈电压经 Rf、R1 分压后在 R1 上取得，与输入以电压串联叠加 → 串联反馈。
3. 极性为负 → 综合为电压串联负反馈。
4. 反馈系数即分压比：F=R1/(R1+Rf)=10/(10+90)=10/100=0.1。
5. 深度负反馈：Af≈1/F=(R1+Rf)/R1=(10+90)/10=10。

【答案解析】
该电路为电压串联负反馈，深度负反馈下闭环增益 Af≈1/F=(R1+Rf)/R1=10。

【方法归纳】
深度负反馈时 Af≈1/F，只需由反馈网络求分压比 F，即能直接估算闭环增益，无需知道开环增益。

【易错提醒】
- F 是反馈网络的传递关系（分压比），不是 Rf/R1；本题 F=0.1，Af=1/F=10。
- 深度负反馈近似只在 (1+AF)≫1 时成立。

【知识点链接】
覆盖深度负反馈估算与电压串联负反馈，详见《电子信息专升本 · 第7章 放大电路中的负反馈》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-07-放大电路中的负反馈/

### 例题7-5 ｜ 难度：进阶

【题目】
某放大电路的中频开环增益 A=200，上限截止频率 fH=10 kHz。现引入反馈深度为 1+AF=5 的负反馈。求闭环中频增益 Af 与闭环上限截止频率 fHf，并用增益带宽积验证结果。

【已知条件】
- 开环中频增益：A=200
- 上限截止频率：fH=10 kHz
- 反馈深度：1+AF=5

【待求】
- 闭环中频增益 Af
- 闭环上限截止频率 fHf

【解题步骤】
1. 由闭环增益公式：Af=A/(1+AF)=200/5=40。
2. 负反馈展宽频带，闭环上限频率 fHf=(1+AF)·fH=5×10 kHz=50 kHz。
3. 验证增益带宽积不变：Af·fHf=40×50 kHz=2000 kHz=2 MHz；A·fH=200×10 kHz=2 MHz，二者相等。

【答案解析】
闭环中频增益 Af=40，闭环上限截止频率 fHf=50 kHz；增益下降为开环的 1/5，频带拓宽为 5 倍，增益带宽积保持不变。

【方法归纳】
负反馈以牺牲增益为代价换取带宽：增益下降为 1/(1+AF)，带宽扩大为 (1+AF) 倍，两者乘积（增益带宽积）恒为常数。

【易错提醒】
- 带宽拓宽的倍数是反馈深度 (1+AF)，不是 F。
- 增益与带宽"一降一升"且乘积不变，这是记住结果、快速验算的要点。

【知识点链接】
覆盖负反馈对增益、通频带的影响，详见《电子信息专升本 · 第7章 放大电路中的负反馈》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-07-放大电路中的负反馈/

## 三、拓展思考题

### 例题7-6 ｜ 难度：拓展

【题目】
多级放大电路引入负反馈后，在深度负反馈或高频下可能出现自激振荡。请分析：(1) 负反馈为什么会在某些频率下变成正反馈；(2) 自激振荡的幅值与相位条件是什么；(3) 常用哪些措施来避免自激振荡。

【思路提示】
负反馈在低频、中频下相移恒定，但多级放大与耦合电容、结电容会在高频产生附加相移；当附加相移累加到 ±180° 时，反馈信号与输入同相、负反馈变正反馈，若再满足幅值条件即自激。

【参考答案要点】
(1) 每级放大电路都有相移，多级叠加及寄生电容在高频使总相移达到 −180°，负反馈变为正反馈。(2) 自激条件为幅值条件 |AF|≥1 与相位条件 φA+φF=±180°（或 ±n·360° 同相叠加）同时满足。(3) 避免措施：限制放大级数、减小反馈深度、在合适位置加频率补偿（如密勒补偿电容）、保证足够的增益裕度与相位裕度，使系统远离自激边界。
