# 第 12 章 数模与模数转换电路

## 一、考纲考点清单

1. 数模转换（D/A）的原理与典型电路
2. 模数转换（A/D）的一般过程（采样、保持、量化、编码）
3. D/A、A/D 转换器的主要技术指标（分辨率、转换精度、转换时间）

## 二、核心知识点

### 2.1 D/A 转换器（DAC）

- 作用：把数字量按权转换为模拟电压/电流输出。
- **权电阻网络 DAC**：各位权电阻不同（与二进制权成反比），各支路电流按权求和；缺点：电阻种类多、精度要求高。
- **倒 T 型电阻网络 DAC**：只有 R、2R 两种电阻，从任一节点看进去等效电阻不变，电流按 2 的幂分流，精度易保证，是最常用结构。
- 输出关系：uo = −(Uref / 2ⁿ)(d(n−1)·2^(n−1) + … + d0·2⁰)，即输出电压与数字量成正比。
- **主要指标**：
  - **分辨率**：能分辨的最小输出电压，其值 = 满量程 / (2ⁿ − 1)，也常用位数 n 表示（n 越大分辨率越高）；
  - 转换精度：实际输出与理论值的最大偏差；
  - 转换速度/时间。

### 2.2 A/D 转换器（ADC）

- 一般过程四步：**采样 → 保持 → 量化 → 编码**。根据采样定理，采样频率应不小于信号最高频率的两倍。
- **逐次逼近型 ADC**：速度快、精度较高，应用最广。
- **双积分型 ADC**：抗干扰能力强、精度高，但速度慢，用于数字仪表。
- **主要指标**：分辨率（常以位数表示，n 位可分辨 2ⁿ 个量化等级）、转换精度（误差）、转换时间。

### 2.3 典型应用与考点

- 转换关系公式：量化单位（1 LSB）= 满量程电压 / 2ⁿ。
- 已知位数与基准电压求最小分辨电压，或根据要求分辨率反推所需位数，是常见计算题。

## 三、关键公式速查

| 名称 | 公式 |
| --- | --- |
| 量化单位 | 1 LSB = UFS / 2ⁿ |
| DAC 最小分辨电压 | Umin = UFS / (2ⁿ − 1) |
| DAC 输出电压 | uo = k·D（k 为比例系数，D 为数字量） |
| 采样定理 | fs ≥ 2fmax |

## 四、典型例题

**例 1**：8 位 DAC，基准电压 Uref = 5 V。求分辨率（最小步进）与数字量 10000001 对应的输出电压。

**解**：
- 最小步进 = 5 / (2⁸ − 1) = 5/255 ≈ **19.6 mV**；
- D = (10000001)₂ = 129 → uo = 129 × 19.6 mV ≈ **2.53 V**。

**例 2**：某 ADC 输入范围 0~10 V，要求分辨率优于 0.1 V，至少需要多少位？

**解**：
- 量化单位 = 10/2ⁿ ≤ 0.1 → 2ⁿ ≥ 100 → n ≥ 7（2⁶ = 64 不够，2⁷ = 128）；
- 至少 **7 位** ADC。

## 五、解题方法小结与易错点

- "最小分辨电压 = 满量程/(2ⁿ−1)"（DAC，按台阶数）与"1 LSB = 满量程/2ⁿ"（ADC，按等分数）分母差 1，看清问的是哪种。
- 二进制数先转十进制再乘比例系数，别直接拿二进制字符串去算。
- A/D 四步（采样、保持、量化、编码）顺序与采样定理常出现在选择、填空。
