> 上一篇《科学健身知识体系》回答的是"为什么这样练"，这一篇回答"每个动作到底怎么做"。
> 本文按**胸、背、腿、肩、手臂、核心**六大肌群逐个拆解动作库：每个动作给出起始姿势、**决定成败的 2~3 个细节**、常见错误、退阶与进阶替代，末尾给一套可直接照做的动作排布。
> 全文只围绕一个标准：**目标肌群全程主导发力，其他部位只做稳定，不做代偿。**

## 通读前先记住的三条铁律

1. **全程控制**：向心（举起）1~2 秒，离心（下放）**2~3 秒**。离心阶段是肌纤维微损伤与张力刺激的主要来源，下放时"松手让它掉下去"是最常见的浪费。
2. **目标肌群主导**：判断一个动作做得对不对，不看重量，看**练完哪里最酸**。如果练胸肩膀先酸、练背手臂先酸，说明代偿，先降重量纠正。
3. **留 1~3 RIR**：RIR（Reps In Reserve，剩余次数）指一组结束时"还能再做几次"。复合动作留 2~3 次，孤立动作留 1~2 次，**不必每组都做到真力竭**——真力竭会显著拉长恢复时间，性价比反而低。

## 一、胸部：水平推 + 上斜推 + 夹胸

胸部（胸大肌）的功能是**把手臂从体侧推向身体前方**，所以动作分两类：推类（复合，上重量）和夹类（孤立，找感觉）。

| 动作 | 类型 | 建议组数×次数 | 定位 |
|---|---|---|---|
| 杠铃卧推 | 复合 | 4×6~8 | 主力增重动作 |
| 哑铃上斜卧推 | 复合 | 3×8~10 | 补上胸 |
| 双杠臂屈伸 | 复合 | 3×8~12 | 下胸+三头 |
| 器械/绳索夹胸 | 孤立 | 3×12~15 | 顶峰收缩 |
| 绳索飞鸟 | 孤立 | 3×12~15 | 拉伸位刺激 |

### 1.1 杠铃卧推（第一主力）

- **起始**：平躺在凳上，眼睛位于杠铃正下方稍后；双脚踩实地面，**臀部不离凳**。
- **关键细节**
  1. **肩胛后缩 + 下沉**：躺下后主动把两侧肩胛骨"夹起来、往下压"，像把肩胛骨塞进后裤兜。这一步决定了是胸发力还是肩前束代偿——**九成"卧推练肩不练胸"都是这里没做**。
  2. **握距约 1.5 倍肩宽**，手腕在杠铃正上方（不要向后折腕）；杠铃下放至**乳线附近**（不是锁骨，也不是肚子）。
  3. **肘部夹角约 45°~70°**，不是完全外展 90°——大角度外展是肩关节受伤的高风险姿势。
- **常见错误**：弹胸（借胸骨反弹）、臀部离凳、下放不足半程、手腕后折、起身时耸肩。
- **退阶**：哑铃卧推（轨迹自由、对肩更友好）→ 史密斯机 → 俯卧撑。
- **进阶**：加重量 → 停顿卧推（胸口停 2 秒）→ 窄距卧推。

### 1.2 哑铃上斜卧推

凳面角度 **30°~45°**（超过 60° 就变成肩推）。哑铃下放到**上臂与躯干约 45°、肘略低于肩**即可，不必刻意下探到极限——上斜位下探过深是肩前侧疼痛的常见原因。

### 1.3 双杠臂屈伸

躯干**略前倾**偏向胸，**保持直立**偏向三头。下放到上臂与地面平行即可（肩不适者到此为止）。体重较大或力量不足用**弹力带辅助**或辅助器械。

### 1.4 夹胸类（找感觉用）

夹胸的价值在于**顶峰收缩位**：双臂合拢时停顿 1 秒，主动挤压胸肌。重量不用大，动作幅度要完整，感受胸肌"从外向内收"的过程。

## 二、背部：垂直拉 + 水平拉

背部肌群（背阔肌、大圆肌、斜方肌、菱形肌）的功能有二：**把手臂从上方拉下来**（垂直拉）和**把手臂向后拉**（水平拉）。**两类都要练**，缺一不可。

| 动作 | 类型 | 建议组数×次数 | 定位 |
|---|---|---|---|
| 引体向上 | 垂直拉 | 4×6~10（或负重） | 背宽主力 |
| 高位下拉 | 垂直拉 | 3×8~12 | 引体退阶/补量 |
| 杠铃划船 | 水平拉 | 4×6~10 | 背厚主力 |
| 单臂哑铃划船 | 水平拉 | 3×10~12 | 纠左右不平衡 |
| 坐姿绳索划船 | 水平拉 | 3×10~12 | 中背收缩 |
| 直臂下压 | 孤立 | 3×12~15 | 背阔孤立 |

### 2.1 引体向上（你有 18 个基础，重点讲进阶）

- **关键细节**
  1. **肩胛先下沉再屈肘**：起始悬挂时先让肩胛"往下沉"（想象把肩膀从耳朵上拉开），再开始拉。直接靠手臂猛拽是"二头弯举"，背部刺激会少一半。
  2. **挺胸、肘往髋部方向拉**，下巴过杠或锁骨接近杠。
  3. **全程控制下放**至手臂接近伸直，不摆荡（kipping 是竞技体操动作，不是增肌动作）。
- **进阶路径（针对 18 个的水平）**：自重 4×8 → **负重 5kg 4×6** → 每 2 周加 2.5kg，目标负重 15~20kg 做 6 次 → 偏重引体（单侧辅助）。
- **退阶**：高位下拉 → 弹力带辅助引体 → 离心引体（跳上去、4 秒慢放）。
- **常见错误**：半程（下巴不到杠）、摆荡借力、耸肩启动、下放不控。

### 2.2 杠铃划船

- **躯干前倾 45°~60°**，背部**全程中立**（不弓不塌），杠铃拉向**肚脐到腹股沟之间**，顶点主动夹背 1 秒。
- **常见错误**：起身借力（重量过大）、耸肩拉（重量走到斜方上束）、低头或抬头过度。感觉"下背先累"就是重量超了。
- 力量不足用**胸托哑铃划船**替代，能完全卸掉下背压力。

### 2.3 高位下拉

握距略宽于肩，**身体后仰不超过 15°**，拉至锁骨上方，肩胛下沉再屈肘。**不要拉到胸前把杠砸向胸口**，也不要靠身体后仰甩重。

## 三、腿部：蹲 + 铰链 + 单腿 + 孤立

腿部训练同时服务于两个目标：**围度（大腿、臀部）**和**1000 米的腿部力量与抗伤能力**。动作按运动模式分四类。

| 动作 | 模式 | 建议组数×次数 |
|---|---|---|
| 深蹲（高杠/低杠） | 蹲 | 4×6~8 |
| 腿举 | 蹲（器械） | 3×10~12 |
| 罗马尼亚硬拉 | 铰链 | 4×8~10 |
| 保加利亚分腿蹲 | 单腿 | 3×8~10/腿 |
| 腿弯举 | 孤立（大腿后侧） | 3×12~15 |
| 站姿提踵 | 孤立（小腿） | 4×12~15 |

### 3.1 深蹲

- **起始**：杠铃置于斜方肌上部（高杠）或后三角肌上（低杠）；双脚与肩同宽或略宽，脚尖略外展 15°~30°。
- **关键细节**
  1. **髋膝同时启动**：先屈髋后屈膝是"鞠躬"，先屈膝后屈髋是"跪"，两者都会让重心跑偏，正确是**同步**。
  2. **膝盖方向跟随脚尖**，不要内扣（内扣是膝伤的头号诱因）。
  3. **脊柱全程中立**，核心绷紧（想象有人要打你肚子）。
- **深度**：至少**大腿平行地面**，活动度允许就到"臀低于膝"。深度不足的常见原因是**踝背屈受限**（见本系列第 4 篇）。
- **常见错误**：起身时先抬臀（变成早安式）、脚跟离地、弓腰、膝内扣、只看镜子里的"重量面子"。

### 3.2 罗马尼亚硬拉（RDL）

- 与深蹲互补：练**大腿后侧（腘绳肌）+ 臀 + 下背**，也是跑步人群最该练的动作之一。
- **关键细节**：**膝微屈并固定**，靠屈髋把杠铃沿大腿前侧下降，下放到腘绳肌有明确拉伸感的位置（约膝下）；**背部中立、杠铃贴身**，起身靠**顶髋**完成，不是靠挺腰。
- **常见错误**：屈膝太多变成深蹲、杠铃离身、弓腰下放（下背受伤风险）。

### 3.3 保加利亚分腿蹲

后脚搭凳，前脚承担主要负荷。**重心压在前脚跟**，下蹲时后膝接近地面但不触地。它同时训练单腿力量、平衡与髋部稳定性，对跑步落地缓冲能力帮助很大。**对 1000 米跑者的价值高于腿举**。

## 四、肩部：推举 + 三种平举

肩部（三角肌）分前、中、后三束，**中束决定肩宽，后束决定体态和健康**，恰恰是最多人忽略的。

| 动作 | 目标束 | 建议组数×次数 |
|---|---|---|
| 站姿/坐姿推举 | 前束+中束 | 4×6~10 |
| 哑铃侧平举 | 中束 | 4×12~15 |
| 反向飞鸟/面拉 | 后束 | 3×15 |
| 绳索前平举 | 前束（补量） | 2×12 |

### 4.1 推举

核心绷紧，**不靠腰部后仰借力**（上斜位腰椎超伸是常见伤点）。下放至下巴到锁骨附近，肘略前于身体平面。

### 4.2 侧平举

- **关键细节**：肘**微屈并固定角度**（约 10°~20°），**小指略高于拇指**（倒水式），举到**肩略高**即可；全程**不耸肩**，缓慢下放 2~3 秒。
- **重量**：这是最容易被"面子重量"毁掉的动作。能用 5~8kg 严格完成 15 次比甩 15kg 强十倍。

### 4.3 面拉（Face Pull）

绳索设于面部高度，向**面部方向**拉，肘高于腕，顶点外旋肩。**后束 + 肩袖健康**的首选动作，建议每周至少 2 次、每次 3 组 15 次。

## 五、手臂：二头 + 三头

手臂围度受基因影响大，但可以练到接近上限：**肱三头肌占上臂体积约 2/3**，所以想粗手臂，三头比二头更关键。

| 动作 | 目标 | 建议组数×次数 |
|---|---|---|
| 杠铃/哑铃弯举 | 二头 | 3×8~12 |
| 锤式弯举 | 二头+肱肌 | 3×10~12 |
| 窄距卧推 | 三头 | 3×8~10 |
| 绳索下压 | 三头 | 3×12~15 |
| 过顶臂屈伸 | 三头（长头） | 3×12 |

- **弯举要点**：**肘固定在体侧**（不前后摆）、**不靠腰甩**、下放到底做全幅度。
- **下压要点**：肘夹紧不外张、肩下沉、顶点让三头完全收缩。
- **长头**只在**手臂过顶**时被充分拉长，所以过顶臂屈伸不能省。

## 六、核心：抗伸展 + 抗旋转 + 抗侧屈

核心的功能不是"卷腹练腹肌"，而是**抵抗躯干被拉弯**。训练分三类：

| 类别 | 动作 | 要点 |
|---|---|---|
| 抗伸展 | 平板支撑、腹轮、悬垂举腿 | 骨盆后倾、不塌腰 |
| 抗旋转 | 帕洛夫推、单臂农夫行走 | 主动对抗旋转 |
| 抗侧屈 | 单侧农夫行走、侧平板 | 身体不侧倾 |

- **平板支撑**：不是撑得久就好，**臀收紧、骨盆后倾、肩胛下沉**，30~60 秒做到发抖即有效。
- **悬垂举腿**：靠**骨盆后卷**把腿抬起，不是靠髋屈肌甩腿。
- **腹轮**：跪姿起步，全程**不塌腰**，腰塌了说明超过能力。

## 七、把动作库排成一次训练

原则：**复合动作在前、孤立动作在后；大肌群在前、小肌群在后。** 以下是一套 5 天分化（推 / 拉 / 腿 / 上推+中束 / 下背+手臂）：

| 日 | 动作顺序 |
|---|---|
| 推 | 杠铃卧推 → 上斜哑铃卧推 → 双杠臂屈伸 → 侧平举 → 绳索夹胸 |
| 拉 | 引体向上 → 杠铃划船 → 高位下拉 → 坐姿划船 → 面拉 |
| 腿 | 深蹲 → 罗马尼亚硬拉 → 保加利亚分腿蹲 → 腿弯举 → 提踵 |
| 上推+中束 | 推举 → 侧平举 → 前平举 → 反向飞鸟 |
| 下背+手臂 | 硬拉/山羊挺身 → 弯举 → 窄距卧推 → 下压 |

每次训练时长控制在 **60~75 分钟**，第 3 篇《周期化》会给出每周如何加减量与何时减载。

## 八、常见错误总表（自查用）

| 现象 | 最可能的原因 |
|---|---|
| 卧推练完肩前酸、胸不酸 | 肩胛没后缩下沉 / 肘外展过大 |
| 引体练完二头酸、背没感觉 | 没先沉肩胛，直接屈肘 |
| 深蹲起来先抬臀 | 重量过大 / 臀腿力量不足 |
| 侧平举脖子先酸 | 耸肩、重量过大 |
| 练完下背酸而非目标肌群 | 动作代偿 / 重量超过组织承受力 |
| 所有动作都"没感觉" | 离心太快、行程不完整、重量偏大 |

**动作质量优先于重量**——先把每一组的"感觉"练对，再逐步加重量。下一篇讲如何系统地把重量加上去。
