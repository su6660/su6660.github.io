# 第 2 章 电路分析方法与电路定理

## 一、考纲考点清单

1. 电阻元件的联结及其等效变换（串联、并联、混联）
2. 电源的等效变换（实际电源的两种模型）
3. 支路电流法、网孔电流法、回路电流法
4. 节点电压法
5. 叠加定理
6. 戴维南定理、诺顿定理、替代定理
7. 最大功率传输定理

## 二、核心知识点

### 2.1 电阻的等效变换

- **串联**：R = R1 + R2 + …，分压公式：Uk = (Rk / R) × U。
- **并联**：1/R = 1/R1 + 1/R2 + …；两电阻并联 R = R1R2/(R1+R2)。分流公式：I1 = [R2/(R1+R2)] I。
- 混联电路：从远离端口处逐级化简。

### 2.2 电源的等效变换

- **实际电源两种模型**：恒压源 E 串内阻 r 与恒流源 Is 并内阻 r' 可互相等效。
- 等效条件：Is = E / r，内阻 r 不变（r = r'）。
- 注意：理想恒压源（r = 0）不能等效为理想恒流源，反之亦然；恒压源并联元件、恒流源串联元件对外等效时可简化。

### 2.3 电路的一般分析方法

- **支路电流法**：以各支路电流为未知量，对 (n−1) 个独立节点列 KCL，对 b−(n−1) 个网孔列 KVL，联立求解。
- **网孔电流法**：以网孔电流为未知量，对每个网孔列 KVL 方程（自阻×本网孔电流 − 互阻×相邻网孔电流 = 本网孔电压源代数和）。
- **回路电流法**：网孔电流法的推广，可任选独立回路。
- **节点电压法**：以节点电压为未知量，对 (n−1) 个独立节点列 KCL 方程；两节点电路可直接用弥尔曼公式。

### 2.4 电路定理

- **叠加定理**：多个电源共同作用 = 各电源**单独作用**结果的代数和。单独作用时其余恒压源短路、恒流源开路。只适用于线性电路，功率不可叠加。
- **戴维南定理**：任何线性含源二端网络，对外等效为恒压源（开路电压 Uoc）与电阻（除源后端口等效电阻 Req）串联。
- **诺顿定理**：对外等效为恒流源（短路电流 Isc）与 Req 并联；Isc = Uoc / Req。
- **替代定理**：已知某支路电压或电流，可用相同电压的恒压源或相同电流的恒流源替代该支路。
- **最大功率传输定理**：负载 R 等于等效内阻 Req 时获最大功率，Pmax = Uoc² / (4Req)。

## 三、关键公式速查

| 名称 | 公式 |
| --- | --- |
| 串联分压 | Uk = (Rk / R) U |
| 并联分流 | I1 = [R2/(R1+R2)] I |
| 电源等效 | Is = E / r |
| 戴维南 | I = Uoc / (Req + R) |
| 最大功率 | Pmax = Uoc² /(4Req)（R = Req 时） |

## 四、典型例题

**例 1（戴维南）**：某含源二端网络开路电压 Uoc = 12 V，除源后等效电阻 Req = 4 Ω；负载 RL = 6 Ω 接于端口。求负载电流与功率。

**解**：
- I = Uoc / (Req + RL) = 12 / (4 + 6) = **1.2 A**；
- P = I²RL = 1.44 × 6 = **8.64 W**。

**例 2（叠加定理）**：R = 2 Ω 上同时作用恒压源 E = 10 V 与恒流源 Is = 2 A（方向一致流过 R）。求 R 的电流。

**解**：
- E 单独作用（Is 开路）：I' = 10 / 2 = 5 A；
- Is 单独作用（E 短路）：I'' = 2 A；
- 叠加：I = I' + I'' = **7 A**。

## 五、解题方法小结与易错点

- 戴维南求 Req 时先"除源"（恒压源短路、恒流源开路），受控源要保留。
- 叠加时"除源"操作必须正确，且功率 P = I²R 不能直接叠加。
- 电源等效变换前后注意极性、方向对应（Is 方向由 E 的负极指向正极）。
- 网孔/节点法列方程时自阻为正、互阻为负的符号规则要统一。
