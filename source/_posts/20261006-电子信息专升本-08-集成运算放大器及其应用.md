# 第 8 章 集成运算放大器及其应用

## 一、考纲考点清单

1. 集成运放的基本组成、特点与传输特性
2. 理想运算放大器（虚短、虚断）
3. 基本线性运算电路：比例（反相/同相）、求和、求差
4. 积分、微分运算电路
5. 单门限比较器（含迟滞比较器了解）

## 二、核心知识点

### 2.1 集成运放与理想运放

- 组成：输入级（差分放大，抑制零漂）、中间级（电压放大）、输出级（功率放大，互补对称）。
- 特点：开环增益极高（10⁴~10⁷）、输入电阻大、输出电阻小；输入失调、零漂小。
- **理想运放**两大结论：
  - **虚短**：u+ = u−（开环增益无穷大，两输入端电位相等）；
  - **虚断**：i+ = i− = 0（输入电阻无穷大，输入电流为零）。
- 使用前提（线性区）：电路引入**负反馈**。

### 2.2 基本运算电路

| 电路 | 输出与输入关系 | 说明 |
| --- | --- | --- |
| 反相比例 | uo = −(Rf/R1)·ui | 反相，Ri = R1 |
| 同相比例 | uo = (1 + Rf/R1)·ui | 同相，Ri 极大 |
| 电压跟随器 | uo = ui | Rf = 0（或 R1 开路）特例 |
| 反相加法 | uo = −Rf·(ui1/R1 + ui2/R2) | 多路叠加 |
| 差分（减法） | uo = (Rf/R1)(ui2 − ui1) | 条件：电阻对称 |
| 积分 | uo = −(1/RC)∫ui dt | 输出为输入的积分 |
| 微分 | uo = −RC·dui/dt | 输出为输入的微分 |

### 2.3 单门限比较器

- 运放开环（或正反馈）工作在**非线性区**：uo 只有两个状态：+Uom 或 −Uom。
- 当 u+ > u− 时 uo = +Uom；当 u+ < u− 时 uo = −Uom。
- **阈值电压**：使输出发生跳变的输入电压。反相输入比较器（同相端接参考 UREF）：ui > UREF 时 uo = −Uom；ui < UREF 时 uo = +Uom。
- **电压传输特性**（uo–ui 关系曲线）是常考作图点。
- 迟滞比较器（正反馈）具有两个阈值，抗干扰能力强（了解）。

## 三、关键公式速查

| 名称 | 公式 |
| --- | --- |
| 反相比例 | uo = −(Rf/R1)ui |
| 同相比例 | uo = (1 + Rf/R1)ui |
| 反相加法 | uo = −Rf(ui1/R1 + ui2/R2) |
| 减法 | uo = (Rf/R1)(ui2 − ui1) |
| 积分 | uo = −(1/RC)∫ui dt |

## 四、典型例题

**例 1**：反相比例电路 R1 = 10 kΩ，Rf = 100 kΩ，ui = 0.2 V。求 uo。

**解**：uo = −(100k/10k)×0.2 = −10×0.2 = **−2 V**。

**例 2**：反相输入比较器，同相端接 UREF = 2 V，输出 ±6 V。求阈值并画传输特性。

**解**：
- 阈值 UTH = UREF = 2 V；
- ui > 2 V 时 uo = −6 V；ui < 2 V 时 uo = +6 V。特性曲线在 ui = 2 V 处跳变。

## 五、解题方法小结与易错点

- 线性应用成立前提是负反馈；无负反馈（开环/正反馈）只能当比较器，不能套"虚短"。
- 判断运放工作区先看有没有反馈回反相端的网络：有负反馈 → 线性；否则 → 非线性。
- 积分电路输出与时间成线性变化，是同相端接地、电容跨接输出与反相端的标准结构。
- 多运放级联题逐个运放求解，先把每个运放的输入输出关系写出来再联立。
