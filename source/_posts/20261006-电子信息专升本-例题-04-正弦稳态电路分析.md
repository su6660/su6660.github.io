## 一、基础概念示例题

### 例题4-1 ｜ 难度：基础

【题目】
已知正弦电压 u(t) = 311×sin(314t + 30°) V。求：
- 最大值 Um；
- 角频率 ω；
- 频率 f 与周期 T；
- 初相 φ；
- 有效值 U。

【解题步骤】
1. 求最大值：站在一般式 u(t) = Um×sin(ωt + φ) 上对照，Um = 311V。
2. 求角频率：ω = 314 rad/s。
3. 求频率：f = ω/(2π) = 314/(2×3.14) = 50Hz。
4. 求周期：T = 1/f = 1/50 = 0.02s = 20ms。
5. 求初相：φ = +30°。
6. 求有效值：U = Um/√2 = 311/1.414 = 220V。

【答案解析】
Um = 311V，ω = 314 rad/s，f = 50Hz，T = 20ms，初相 φ = +30°，有效值 U = 220V。这正是我国工频 220V 正弦电压的标准形式。

【易错提醒】
有效值与最大值的换算漏除以 √2 是高频错误；311V 正是 220×√2 ≈ 311V，两者不要混淆。

【涉及公式】
ω = 2πf；有效值 U = Um/√2；T = 1/f。

【知识点链接】
正弦量三要素（幅值、角频率、初相）与有效值换算 U = Um/√2，详见《电子信息专升本 · 第4章 正弦稳态电路分析》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-04-正弦稳态电路分析/

### 例题4-2 ｜ 难度：基础

【题目】
R=8Ω 与 XL=6Ω 的感性负载串联，接在 U=220V 的工频正弦电源上。求：
- 阻抗模 |Z|；
- 电流 I；
- 功率因数 cosφ；
- 有功功率 P、无功功率 Q、视在功率 S。

【解题步骤】
1. 求阻抗模：|Z| = √(R² + XL²) = √(8² + 6²) = √(64 + 36) = √100 = 10Ω。
2. 求电流：I = U/|Z| = 220/10 = 22A。
3. 求功率因数：cosφ = R/|Z| = 8/10 = 0.8（感性，φ = arccos0.8 ≈ 36.9°）。
4. 求有功功率：P = UI×cosφ = 220×22×0.8 = 3872W。
5. 校验有功功率：P = I²R = 22²×8 = 3872W，与第 4 步一致。
6. 求无功功率：Q = UI×sinφ = 220×22×0.6 = 2904var。
7. 求视在功率：S = UI = 220×22 = 4840VA；校验 S² = P² + Q²：4840² = 3872² + 2904²，成立。

【答案解析】
|Z| = 10Ω，I = 22A，cosφ = 0.8，P = 3872W，Q = 2904var，S = 4840VA。

【易错提醒】
串联时功率因数 cosφ = R/|Z|；不要把 |Z| 当成有功电阻去算 P = UI，那样得到的其实是视在功率 S。

【涉及公式】
|Z| = √(R² + X²)；P = UIcosφ；S² = P² + Q²。

【知识点链接】
阻抗计算 |Z| = √(R² + X²)、有功/无功/视在功率与功率因数 P = UIcosφ、S² = P² + Q²，详见《电子信息专升本 · 第4章 正弦稳态电路分析》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-04-正弦稳态电路分析/

### 例题4-3 ｜ 难度：基础

【题目】
R=30Ω、XL=50Ω、XC=10Ω 串联，接在 U=100V 的正弦电源上。求：
- 电路电抗 X 与阻抗模 |Z|；
- 电流 I；
- 功率因数 cosφ；
- 有功功率 P、无功功率 Q、视在功率 S。

【解题步骤】
1. 求串联电抗：X = XL - XC = 50 - 10 = 40Ω（感性）。
2. 求阻抗模：|Z| = √(R² + X²) = √(30² + 40²) = √(900 + 1600) = √2500 = 50Ω。
3. 求电流：I = U/|Z| = 100/50 = 2A。
4. 求功率因数：cosφ = R/|Z| = 30/50 = 0.6（感性）。
5. 求有功功率：P = UI×cosφ = 100×2×0.6 = 120W；校验 P = I²R = 2²×30 = 120W。
6. 求无功功率：Q = UI×sinφ = 100×2×0.8 = 160var；校验 Q = I²X = 2²×40 = 160var。
7. 求视在功率：S = UI = 200VA；校验 √(P² + Q²) = √(120² + 160²) = √40000 = 200VA。

【答案解析】
X = 40Ω，|Z| = 50Ω，I = 2A，cosφ = 0.6，P = 120W，Q = 160var，S = 200VA。

【易错提醒】
RLC 串联时电抗是 XL 与 XC 相减（X = XL - XC），不是相加；当 X>0 电路呈感性，X<0 呈容性。

【涉及公式】
X = XL - XC；XL = ωL；XC = 1/(ωC)；cosφ = R/|Z|。

【知识点链接】
RLC 串联阻抗（串联 X = XL - XC）与功率三角形，详见《电子信息专升本 · 第4章 正弦稳态电路分析》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-04-正弦稳态电路分析/

## 二、综合应用题

### 例题4-4 ｜ 难度：进阶

【题目】
R=10Ω、L=0.1H、C=10μF 串联，接在 U=20V 的正弦电源上，调节电源频率使电路发生串联谐振。求：
- 谐振角频率 ω0 与谐振频率 f0；
- 品质因数 Q；
- 谐振电流 I0；
- 谐振时电感电压 UL 与电容电压 UC。

【解题步骤】
1. 求谐振角频率：ω0 = 1/√(LC) = 1/√(0.1 × 10×10⁻⁶) = 1/√(10⁻⁶) = 1/10⁻³ = 1000 rad/s。
2. 求谐振频率：f0 = 1/(2π√(LC)) = 1000/(2π) = 1000/6.283 = 159.15Hz。
3. 核对谐振条件 XL = XC：
   - XL = ω0L = 1000×0.1 = 100Ω；
   - XC = 1/(ω0C) = 1/(1000×10×10⁻⁶) = 100Ω；
   - 二者相等，确实谐振。
4. 求谐振电流（谐振时阻抗最小，Z = R）：I0 = U/R = 20/10 = 2A。
5. 求品质因数：Q = ω0L/R = 1000×0.1/10 = 100/10 = 10。
6. 求电感、电容电压：
   - UL = I0×XL = 2×100 = 200V；
   - UC = I0×XC = 2×100 = 200V。

【答案解析】
ω0 = 1000 rad/s，f0 = 159.15Hz，Q = 10，I0 = 2A，UL = UC = 200V。
说明：谐振时 UL = UC = Q×U = 10×20 = 200V，远高于电源电压，这正是串联谐振（电压谐振）的特征，也是相关判断题的高频考点。

【易错提醒】
串联谐振时 UL 与 UC 可能远高于电源电压，并非"相等且等于电源电压"；二者大小相等但相位相反，互相抵消，故端口总电压等于电阻电压 U=IR。

【涉及公式】
f0 = 1/(2π√(LC))；谐振条件 XL = XC；Q = ω0L/R = UL/U。

【知识点链接】
串联谐振条件 XL = XC、谐振频率 f0 = 1/(2π√(LC))、品质因数 Q = ω0L/R = UL/U，详见《电子信息专升本 · 第4章 正弦稳态电路分析》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-04-正弦稳态电路分析/

### 例题4-5 ｜ 难度：进阶

【题目】
某感性负载接在 U=220V、f=50Hz 的电源上，有功功率 P=10kW，原功率因数 cosφ1 = 0.6。欲把功率因数提高到 cosφ2 = 0.95，问应在负载两端并联多大的电容 C？

【解题步骤】
1. 求原功率因数角的正切：cosφ1 = 0.6 → sinφ1 = 0.8 → tanφ1 = 0.8/0.6 = 1.3333。
2. 求目标功率因数角的正切：cosφ2 = 0.95 → sinφ2 = √(1 - 0.95²) = √0.0975 = 0.3122 → tanφ2 = 0.3122/0.95 = 0.3287。
3. 求需要补偿的无功功率：Qc = P(tanφ1 - tanφ2) = 10000 × (1.3333 - 0.3287) = 10000 × 1.0046 = 10046var。
4. 并联电容的无功与电容的关系：Qc = U²×2πfC，故 C = Qc/(2πf×U²)。
5. 求分母：2πf×U² = 2×3.14×50×220² = 314×48400 = 15,205,344。
6. 求电容：C = 10046/15,205,344 = 6.61×10⁻⁴ F = 661μF。

【答案解析】
需并联电容 C ≈ 661μF。
说明：并联电容提供超前无功，抵消感性负载的无功电流，使电网送来的总电流减小、功率因数由 0.6 提高到 0.95。

【易错提醒】
补偿用的是"并联"电容而非串联；并联后负载自身的有功 P 不变，减少的是电网提供的无功 Q，故 Qc 用 tanφ 之差来计算。

【涉及公式】
Qc = P(tanφ1 - tanφ2)；Qc = U²·2πfC。

【知识点链接】
感性负载并联电容提高功率因数、Qc = P(tanφ1 - tanφ2)，详见《电子信息专升本 · 第4章 正弦稳态电路分析》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-04-正弦稳态电路分析/

## 三、拓展思考题

### 例题4-6 ｜ 难度：拓展

【题目】
为什么供电部门要求用户（尤其是大功率电动机等感性负载）的功率因数不能过低？请从视在功率 S、线路电流 I、线路损耗 I²R 与供电设备容量利用率的角度加以解释。另外，串联谐振在收音机"选台"中是如何起作用的？

【思路提示】
当负载需要的有功 P 一定时，I = P/(Ucosφ)，cosφ 越低电流 I 越大；线路损耗按 I²R 增长，发电机与变压器需以更大的视在容量 S=UI 供电。串联谐振电路对不同频率呈现不同阻抗，仅在 f=f0 时阻抗最小、电流最大，从而具有频率选择性。

【参考答案要点】
功率因数过低意味着无功电流偏大：在 P=UIcosφ 中 P 一定时，cosφ 越小，线路电流 I 越大，线路上的 I²R 损耗随之增大；同时供电设备（发电机、变压器、线路）必须以更大的视在容量 S 来输送同样的有功 P，容量利用率下降、成本上升。所以供电部门对用户功率因数设定下限，并鼓励并联电容就地补偿。收音机选台用的是 RLC 串联谐振电路的选频特性：不同频率的电台信号在 LC 回路中呈现不同阻抗，只有在 f = f0 = 1/(2π√(LC)) 时回路阻抗最小、电流最大，其余频率的电流被大幅衰减，从而把目标电台从众多频率中"选出"；调节可变电容改变 f0，即可切换收听不同电台。本题把"功率与功率因数""串联谐振"两个知识点与工程实际联系起来。

## 本章公式速查

- 有效值：U = Um/√2；角频率 ω = 2πf
- 感抗：XL = 2πfL；容抗：XC = 1/(2πfC)
- 阻抗：Z = R + jX；阻抗模 |Z| = √(R² + X²)
- 串联电抗：X = XL - XC；阻抗角 φ = arctan(X/R)
- 有功/无功/视在：P = UIcosφ、Q = UIsinφ、S = UI、S² = P² + Q²
- 串联谐振：XL = XC、f0 = 1/(2π√(LC))、Q = ω0L/R = UL/U
- 功率因数补偿：Qc = P(tanφ1 - tanφ2)
