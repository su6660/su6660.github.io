高压电工证备考背题手册

特种作业操作证（高压电工作业）· 理论考试核心考点精编

考试概况

100题判断70题 + 单选30题

80分及格分数线

60分钟机考时间

6年证书有效期（3年复审）

备考策略：判断题占70%，是得分关键。单选题难度较高，需重点记忆数字类、分类类考点。易混淆概念（如保护接地vs保护接零、TT/IT/TN系统）几乎必考。

一、电工基础知识

1. 电路基本定律 高频

  • 欧姆定律：I = U/R（电流与电压成正比，与电阻成反比）
  • 基尔霍夫电流定律（KCL）：流入节点电流之和 = 流出节点电流之和
  • 基尔霍夫电压定律（KVL）：回路中各段电压代数和等于零
  • 电阻串联：R = R₁ + R₂ + R₃（分压）
  • 电阻并联：1/R = 1/R₁ + 1/R₂（分流）

2. 单相交流电路 高频

  • 正弦交流电三要素：最大值（幅值）、角频率（ω）、初相位（φ）
  • 有效值与最大值关系：U = Um/√2 ≈ 0.707Um，I = Im/√2
  • 我国工频：50Hz，周期 T = 0.02s，角频率 ω = 314 rad/s
  • 纯电阻电路：电压与电流同相位，P = UI = I²R
  • 纯电感电路：电压超前电流90°，XL = ωL = 2πfL
  • 纯电容电路：电流超前电压90°，XC = 1/(ωC) = 1/(2πfC)

功率关系速记：

有功功率 P = UIcosφ（瓦特W）

无功功率 Q = UIsinφ（乏var）

视在功率 S = UI（伏安VA）

功率三角形：S² = P² + Q²

3. 三相交流电路 高频 易错

  • 三相电动势特点：幅值相等、频率相同、相位互差120°
  • 星形（Y）连接：线电压 = √3 × 相电压，线电流 = 相电流
  • 三角形（△）连接：线电压 = 相电压，线电流 = √3 × 相电流
  • 三相功率：P = √3 × U线 × I线 × cosφ
  • 中性线作用：保证星形连接不对称负载相电压对称

易错点：星形连接中”线电压是相电压的√3倍”成立的前提是三相对称。中性线断开会导致中性点位移，造成某相电压升高烧坏设备。

4. 电磁与电磁感应

  • 右手定则（发电机定则）：判断感应电动势方向
  • 左手定则（电动机定则）：判断通电导体受力方向
  • 楞次定律：感应电流的磁场总是阻碍原磁通的变化
  • 法拉第电磁感应定律：e = -N(ΔΦ/Δt)
  • 自感与互感：自感电动势阻碍电流变化；互感是变压器工作原理

二、电力系统基本知识

1. 电力系统组成与电压等级 高频

  • 电力系统组成：发电、输电、变电、配电、用电
  • 电力网：输电线路 + 变电所（升压/降压）
  • 我国额定电压等级：220V、380V、3kV、6kV、10kV、35kV、110kV、220kV、330kV、500kV、750kV、1000kV
  • 高压与低压分界：对地电压250V以上为高压，250V及以下为低压
  • 安全电压：42V、36V、24V、12V、6V（特别潮湿环境12V）

记忆技巧：“高压看250，安全电压42起步，潮湿减半”

2. 电力系统中性点运行方式 高频 易错

运行方式 适用范围 单相接地故障特点 优缺点
中性点不接地 3-10kV系统 可继续运行2小时，非故障相电压升高√3倍 供电可靠性高，绝缘要求高
中性点经消弧线圈接地 35-66kV系统，电容电流大的10kV系统 补偿电容电流，减小接地电弧 供电可靠性高，投资大
中性点直接接地 110kV及以上系统 立即跳闸，短路电流大 绝缘要求低，供电可靠性低

必考陷阱：中性点不接地系统发生单相接地时，允许继续运行2小时，但非故障相电压会升高为线电压（√3倍）。

3. 短路及其危害

  • 短路类型：三相短路（对称）、两相短路、两相接地短路、单相接地短路（不对称）
  • 短路危害：电流急剧增大（可达额定电流几十倍）、电压骤降、设备发热、电动力破坏、系统稳定性破坏
  • 限制短路电流方法：选择适当的主接线形式和运行方式、加装限流电抗器、采用分裂低压绕组变压器

三、电力变压器

1. 变压器基本原理与结构 高频

  • 工作原理：电磁感应原理（互感），只能改变交流电压，不能改变直流电压
  • 变比：K = U₁/U₂ = N₁/N₂ = I₂/I₁
  • 核心部件：铁芯（硅钢片叠成，减少涡流损耗）、绕组（高压绕组在外，低压绕组在内）
  • 冷却方式：油浸自冷（ONAN）、油浸风冷（ONAF）、强迫油循环风冷（OFAF）、干式
  • 油的作用：绝缘、散热、灭弧

2. 变压器技术参数 高频

  • 额定容量SN：视在功率，单位kVA或MVA
  • 额定电压：一次额定电压、二次额定电压（空载时）
  • 额定电流：I₁N = SN/(√3·U₁N)，I₂N = SN/(√3·U₂N)
  • 阻抗电压（短路电压）：短路阻抗占额定电压的百分比，一般4%-10.5%
  • 空载电流：一般为额定电流的2%-10%
  • 连接组别：Yyn0、Yd11、Dyn11等（时钟表示法）

容量计算速记：

单相：S = UI

三相：S = √3 × U线 × I线

例：10/0.4kV, 100kVA变压器，高压侧电流 = 100/(√3×10) ≈ 5.77A

3. 变压器运行与维护 易错

  • 允许过负荷：正常过负荷（油浸式1.3倍2小时）、事故过负荷（1.3倍2小时，1.45倍80分钟，1.6倍45分钟）
  • 并列运行条件：①连接组别相同 ②变比相等（误差≤±0.5%）③短路阻抗相等（误差≤±10%）④容量比不超过3:1
  • 油位异常：油面过低会导致绝缘击穿，过高会造成溢油和使油枕失去作用
  • 温度计：上层油温一般不超过85℃，最高不超过95℃

高频考题：变压器并列运行时，短路阻抗电压不等会导致负载分配不合理，阻抗小的变压器先满载。

四、高压电器及成套配电装置

1. 高压断路器 高频 易错

  • 作用：正常运行时接通断开负荷电流，故障时切断短路电流
  • 灭弧介质：油（多油/少油）、真空、SF6、压缩空气
  • 真空断路器：灭弧室真空度，适用于频繁操作，35kV及以下
  • SF6断路器：灭弧能力强，适用于110kV及以上
  • 操作机构：电磁式、弹簧储能式、液压式、气动式

必考点：断路器与隔离开关的根本区别——断路器有灭弧装置，能切断负荷电流和短路电流；隔离开关无灭弧装置，只能隔离电源。

2. 隔离开关

  • 作用：隔离电源，形成明显断开点；倒闸操作；接通断开小电流电路
  • 操作顺序：停电时先拉断路器，后拉隔离开关；送电时先合隔离开关，后合断路器
  • 严禁：带负荷拉合隔离开关（会产生电弧，造成短路）

记忆口诀：“停电先断后隔离，送电先隔离后断，隔离开关无负荷”

3. 负荷开关、熔断器与互感器 高频

  • 负荷开关：能切断负荷电流，不能切断短路电流，常与熔断器配合使用
  • 高压熔断器：过载和短路保护，RN1型用于保护变压器，RN2型用于保护电压互感器
  • 电压互感器（PT/VT）：二次侧额定电压100V，严禁短路（相当于短路运行）
  • 电流互感器（CT/TA）：二次侧额定电流5A或1A，严禁开路（会产生高电压）
  • 互感器接地：二次侧必须有一点可靠接地，防止绝缘击穿时高压窜入低压侧

致命区别：PT二次侧短路会烧坏PT；CT二次侧开路会产生数千伏高压，危及人身安全，可能引发火灾。

4. 成套配电装置（开关柜）

  • “五防”功能：①防止误分误合断路器 ②防止带负荷拉合隔离开关 ③防止带电挂接地线 ④防止带接地线合断路器 ⑤防止误入带电间隔
  • 手车式开关柜：工作位置、试验位置、检修位置
  • 母线涂色：A相黄色、B相绿色、C相红色、中性线淡蓝色、保护线黄绿双色

五、高压电力线路

1. 架空线路

  • 组成：导线、避雷线（地线）、杆塔、绝缘子、金具
  • 导线排列：水平排列、三角形排列、垂直排列
  • 安全距离：10kV线路对地最小距离：居民区6.5m，非居民区5.5m
  • 杆塔类型：直线杆、耐张杆、转角杆、终端杆、跨越杆

2. 电力电缆

  • 结构：导体、绝缘层、屏蔽层、保护层
  • 敷设方式：直埋、电缆沟、电缆隧道、排管、桥架
  • 试验：绝缘电阻测量、直流耐压试验、泄漏电流测量

六、过电压保护与接地装置

1. 过电压分类 高频

  • 内部过电压：操作过电压（切合空载线路、空载变压器）、谐振过电压、工频过电压
  • 外部过电压（大气过电压）：直击雷、感应雷、雷电波侵入

2. 防雷保护设备 高频

  • 避雷针：保护建筑物和露天变配电设备，单支避雷针保护范围按滚球法计算
  • 避雷线（架空地线）：保护架空输电线路
  • 避雷器：限制雷电过电压和操作过电压，与被保护设备并联
  • 阀型避雷器：火花间隙 + 阀片电阻，用于3-10kV系统
  • 氧化锌避雷器：无间隙，残压低，保护性能好，应用广泛

记忆技巧：避雷针”引雷上身”保护周围，避雷器”限制过电压”保护设备。

3. 接地装置 高频 易错

  • 工作接地：保证系统正常运行（如变压器中性点接地），接地电阻≤4Ω
  • 保护接地：将设备金属外壳接地，防止绝缘损坏时外壳带电
  • 保护接零：将设备金属外壳接到零线上，适用于TN系统
  • 重复接地：零线上的一处或多处再次接地，降低漏电设备对地电压
  • 接地电阻要求：高压设备接地电阻≤4Ω，低压设备≤4Ω，重复接地≤10Ω，防雷接地≤10Ω

高频考题：保护接地适用于IT系统；保护接零适用于TN系统。在同一供电系统中，不允许一部分设备保护接地、另一部分设备保护接零。

七、电气安全技术

1. 触电方式与电流危害 高频

  • 触电方式：单相触电、两相触电、跨步电压触电、接触电压触电、感应电压触电
  • 两相触电：最危险，人体承受线电压（380V），危险性最大
  • 跨步电压：高压接地故障时，人在故障点周围行走，两脚之间的电压，离接地点越近越大，20米以外为零
  • 电流危害分级：感知电流（男1.1mA，女0.7mA）、摆脱电流（男16mA，女10.5mA）、室颤电流（50mA以上致命）
  • 安全电流：30mA·s（交流）

必考点：电流通过人体最危险的途径是左手到前胸（经过心脏）。

2. 触电急救 高频

  • 脱离电源：拉闸断电、用绝缘物挑开电线、单手拽触电者干燥衣服
  • 心肺复苏（CPR）：胸外按压 + 人工呼吸 = 30:2，按压频率100-120次/分，按压深度5-6cm
  • 口对口人工呼吸：每次吹气1秒以上，看到胸廓起伏
  • 抢救原则：迅速、就地、准确、坚持（”八字原则”），医生到来前不得放弃抢救

操作要点：判断意识→呼救→判断呼吸→胸外按压→开放气道→人工呼吸

3. 安全用具与标识 高频

  • 绝缘安全用具：绝缘棒（操作隔离开关）、绝缘夹钳、验电器、绝缘手套、绝缘靴、绝缘垫、绝缘台
  • 一般防护安全用具：安全带、安全帽、携带型接地线、临时遮栏、标示牌
  • 验电器使用：使用前在有电设备上试验确认良好，验电时戴绝缘手套，逐相验电
  • 安全标识：禁止合闸有人工作（红底白字）、禁止合闸线路有人工作（红底白字）、止步高压危险（白底红边黑字）、在此工作（绿底白字）
  • 安全色：红色（禁止/停止）、黄色（警告/注意）、蓝色（指令/必须遵守）、绿色（提示/安全状态）

4. 保证安全的组织措施与技术措施 高频 易错

  • 组织措施：工作票制度、工作许可制度、工作监护制度、工作间断转移和终结制度
  • 技术措施：停电、验电、装设接地线、悬挂标示牌和装设遮栏
  • 装设接地线顺序：先接接地端，后接导体端；拆除时相反
  • 工作票类型：第一种工作票（高压设备停电工作）、第二种工作票（高压设备不停电工作、低压带电作业）
  • 工作许可人：负责审查工作票所列安全措施是否正确完备

必考陷阱：装设接地线必须先接接地端，后接导体端，顺序绝对不能反！拆除时相反。

5. 电气防火防爆 高频

  • 电气火灾原因：短路、过载、接触不良、散热不良、电火花、电弧
  • 电气火灾扑救：先断电后灭火；带电灭火用二氧化碳、干粉、1211灭火器，严禁用泡沫灭火器和水
  • 爆炸危险环境：0区（连续出现爆炸性气体）、1区（可能出现）、2区（不太可能出现）
  • 防爆电气设备类型：隔爆型（d）、增安型（e）、本质安全型（i）、正压型（p）、充油型（o）、充砂型（q）、无火花型（n）

八、判断题常见陷阱

陷阱1：偷换概念

题目：“保护接地适用于TN系统。”

答案：错误。保护接地适用于IT系统，保护接零才适用于TN系统。

陷阱2：数字陷阱

题目：“我国安全电压额定值为42V、36V、24V、12V、6V，其中特别潮湿场所应使用24V。”

答案：错误。特别潮湿场所应使用12V。

陷阱3：绝对化表述

题目：“变压器油的主要作用是绝缘和冷却，因此油位越高越好。”

答案：错误。油位过高会导致溢油和使油枕失去作用。

陷阱4：顺序颠倒

题目：“装设接地线时，应先接导体端，后接接地端。”

答案：错误。必须先接接地端，后接导体端。

陷阱5：条件缺失

题目：“中性点不接地系统发生单相接地时，可以长期继续运行。”

答案：错误。只能继续运行2小时。

陷阱6：因果混淆

题目：“电流互感器二次侧开路会产生大电流，烧坏互感器。”

答案：错误。CT二次侧开路会产生高电压，危及人身和设备安全。

陷阱7：范围扩大/缩小

题目：“高压断路器只能切断负荷电流，不能切断短路电流。”

答案：错误。断路器既能切断负荷电流，也能切断短路电流。

陷阱8：张冠李戴

题目：“电压互感器二次侧严禁开路。”

答案：错误。PT二次侧严禁短路，CT二次侧严禁开路。

九、单选题速记要点

数字类考点速记

  • 安全电压：42/36/24/12/6V，潮湿环境12V
  • 高压低压分界：250V
  • 中性点不接地系统单相接地允许运行：2小时
  • 接地电阻：工作接地≤4Ω，重复接地≤10Ω，防雷接地≤10Ω
  • 感知电流：男1.1mA，女0.7mA；摆脱电流：男16mA，女10.5mA；室颤电流：50mA
  • 心肺复苏：按压30次 + 吹气2次，频率100-120次/分，深度5-6cm
  • 变压器上层油温：一般不超过85℃，最高95℃
  • 跨步电压安全距离：离接地点20米以外为零
  • 10kV线路对地距离：居民区6.5m，非居民区5.5m
  • 绝缘手套试验周期：6个月；绝缘靴：6个月；绝缘棒：1年
  • 特种作业操作证有效期：6年，每3年复审一次

分类类考点速记

  • 触电方式：单相、两相、跨步电压、接触电压、感应电压
  • 过电压：内部（操作、谐振、工频）、外部（直击雷、感应雷、雷电波侵入）
  • 短路类型：三相（对称）、两相、两相接地、单相接地（不对称）
  • 变压器并列条件：组别相同、变比相等、阻抗相等、容量比≤3:1
  • “五防”：防误分误合、防带负荷拉合、防带电挂地线、防带地线合闸、防误入带电间隔
  • 组织措施：工作票、工作许可、工作监护、工作间断转移终结
  • 技术措施：停电、验电、装设接地线、悬挂标示牌装设遮栏

公式类考点速记

  • 欧姆定律：I = U/R
  • 电阻串联：R = R₁ + R₂；并联：1/R = 1/R₁ + 1/R₂
  • 单相功率：P = UIcosφ；三相功率：P = √3·U线·I线·cosφ
  • 变压器变比：K = U₁/U₂ = N₁/N₂ = I₂/I₁
  • 星形：U线 = √3·U相，I线 = I相；三角形：U线 = U相，I线 = √3·I相

十、易混淆知识点辨析

对比项 保护接地 保护接零
适用系统 IT系统 TN系统
原理 限制设备对地电压 促使保护装置动作切断电源
接地电阻要求 ≤4Ω 重复接地≤10Ω
能否混用 同一供电系统中不允许一部分接地、一部分接零
对比项 电压互感器（PT） 电流互感器（CT）
二次侧额定值 100V 5A或1A
运行禁忌 严禁短路 严禁开路
原因 短路电流很大，烧坏PT 开路产生高电压，危及安全
二次侧接地 必须有一点可靠接地 必须有一点可靠接地
对比项 断路器 隔离开关
灭弧装置 有 无
切断负荷电流 可以 不可以
切断短路电流 可以 不可以
作用 控制+保护 隔离电源，形成明显断开点
对比项 第一种工作票 第二种工作票
适用工作 高压设备上需要全部停电或部分停电的工作 高压设备上不停电的工作、低压带电作业
安全措施 需要停电、验电、装设接地线等 不需要停电

考前冲刺建议：最后三天重点看本手册第八、九、十部分，配合刷题软件查漏补缺。考试时先做有把握的题，标记不确定的题目，做完后回头检查。判断题拿不准时，注意绝对化词汇（”一定””必须””所有””只要”）往往是错误选项。
