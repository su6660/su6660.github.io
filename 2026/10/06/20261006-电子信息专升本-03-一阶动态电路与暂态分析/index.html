第 3 章 一阶动态电路与暂态分析

一、考纲考点清单

  1. 过渡过程的基本概念
  2. 换路定律（换路定则）
  3. 一阶电路的零输入响应
  4. 一阶电路的零状态响应
  5. 一阶电路的三要素法及全响应

二、核心知识点

2.1 动态元件与过渡过程

  • 电容伏安关系：i = C·du/dt（电压不能突变）；电场储能 W = (1/2)Cu²。
  • 电感伏安关系：u = L·di/dt（电流不能突变）；磁场储能 W = (1/2)Li²。
  • 过渡过程（暂态）：电路从一种稳态到另一种稳态的过渡阶段，由储能元件引起。稳态（t→∞）时电容视为开路、电感视为短路。

2.2 换路定律与初始值

  • 换路定律：设 t = 0 换路，则 uc(0+) = uc(0−)，iL(0+) = iL(0−)，即电容电压、电感电流换路瞬间保持不变。
  • 其它量（电阻电压电流、电容电流、电感电压）在 0+ 时刻可能突变。
  • 求初始值步骤：先由换路前稳态（电容开路、电感短路）求 uc(0−)、iL(0−)；由换路定律得 0+ 值；再把 0+ 时刻电容电压作为恒压源、电感电流作为恒流源代入 0+ 电路求其它 0+ 值。

2.3 一阶电路的三种响应

  • 零输入响应（无外加电源，仅储能放电）：
    • RC：uc(t) = U0·e^(−t/τ)，i 按指数衰减；τ = RC（时间常数）。
    • RL：iL(t) = I0·e^(−t/τ)，τ = L/R。
  • 零状态响应（初始储能为零，外加激励）：
    • RC 充电：uc(t) = Us·(1 − e^(−t/τ))。
  • 全响应 = 零输入响应 + 零状态响应，也可分解为”稳态分量 + 暂态分量”。
  • 时间常数 τ：决定过渡快慢，τ 越大过程越慢；工程上认为 t = 3τ~5τ 过渡结束。

2.4 三要素法（通杀一阶电路）

统一公式：

f(t) = f(∞) + [ f(0+) − f(∞) ] · e^(−t/τ)

三要素：初始值 f(0+)、稳态值 f(∞)（t→∞ 时电容开路、电感短路）、时间常数 τ（RC 或 L/R，R 为换路后从储能元件两端看进去的等效电阻）。

三、关键公式速查

名称 公式
电容伏安 i = C·du/dt
电感伏安 u = L·di/dt
换路定律 uc(0+) = uc(0−)，iL(0+) = iL(0−)
RC 时间常数 τ = RC
RL 时间常数 τ = L/R
三要素法 f(t) = f(∞) + [f(0+) − f(∞)]·e^(−t/τ)

四、典型例题

例 1：RC 电路中 U0 = 10 V，R = 2 kΩ，C = 100 μF。求 τ 及放电至 10% 时的时间。

解：

  • τ = RC = 2000 × 100×10⁻⁶ = 0.2 s；
  • 由 10% = e^(−t/0.2) → t = −0.2·ln0.1 ≈ 0.46 s。

例 2（三要素法）：t = 0 时 RC 串联接 12 V 电源，uc(0−) = 4 V，R = 1 kΩ，C = 10 μF。求 uc(t)。

解：

  • f(0+) = uc(0+) = 4 V；f(∞) = 12 V；τ = RC = 1k × 10μ = 0.01 s；
  • uc(t) = 12 + (4 − 12)·e^(−t/0.01) = 12 − 8e^(−100t) V。

五、解题方法小结与易错点

  • 初值问题先写”0− 稳态 → 换路定律 → 0+ 电路”三步，电容电流、电感电压在 0+ 可突变。
  • 三要素法求 τ 时，R 是从储能元件两端看进去的等效电阻，且应将独立电源除源。
  • 指数式 e^(−t/τ) 的指数必须是负的，t 单位与 τ 一致。
  • 出题常混搭”换路前稳态、换路后求全响应”，务必分清换路前后的电路结构。
