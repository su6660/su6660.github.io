第 10 章 门电路与组合逻辑电路

一、考纲考点清单

  1. 基本门电路（与、或、非、与非、或非）及 TTL、CMOS 门电路特点
  2. 组合逻辑电路的分析与设计方法
  3. 编码器、译码器、数据选择器、加法器、数值比较器的功能与应用
  4. 竞争冒险现象及消除

二、核心知识点

2.1 集成门电路

  • 常用逻辑门真值表核心：与非门”有 0 出 1，全 1 出 0”；或非门”有 1 出 0，全 0 出 1”；异或门”相异出 1”。
  • TTL 与非门：输入级多发射极管 + 输出级推拉式（图腾柱）；电源 5 V；输入端悬空等效高电平 1；扇出系数大。
  • CMOS 门：由 PMOS 与 NMOS 互补对称构成；功耗极低、电源范围宽；输入悬空状态不定（不允许悬空）；易静电损坏。
  • 主要参数：传输延迟 tpd、扇出系数、噪声容限；集电极开路门（OC 门）输出需外接上拉电阻，可实现”线与”；三态门输出有 0、1、高阻（Z）三态，用于总线。

2.2 组合逻辑电路的分析与设计

  • 特点：任一时刻输出仅取决于当时的输入（无记忆）。
  • 分析步骤：写表达式 → 化简 → 列真值表 → 说明功能。
  • 设计步骤：列真值表 → 写最小项表达式 → 化简 → 画逻辑图（可用指定器件实现）。

2.3 常用中规模组合器件

器件 型号 主要功能
编码器 74LS148 8 线–3 线优先编码器
译码器 74LS138 3 线–8 线译码器（输出低有效）
数据选择器 74LS151 8 选 1 数据选择器
加法器 74LS283 4 位二进制加法器（含半加、全加原理）
比较器 74LS85 4 位数值比较器
  • 74LS138 输出为最小项取反（Y0~Y7 低有效），用于实现逻辑函数：F = Σm(i,j,k…) = (Yi·Yj·…)’（接与非门）。
  • 74LS151 的 8 选 1 输出 F = Σ(Di·mi)，数据端 Di 接 0/1 即可实现任意三变量函数。

2.4 竞争冒险

  • 同一信号经不同路径到达汇合点产生先后差异（竞争），引起输出出现不应有的尖峰（冒险）。
  • 消除：加选通脉冲、增加冗余项（如加 BC 项消除险象）、输出端加滤波电容。

三、关键公式速查

名称 要点
与非门 有 0 出 1，全 1 出 0
或非门 有 1 出 0，全 0 出 1
异或 F = A⊕B = ĀB + AB̄
138 实现函数 F = (Yi·Yj·…)′，i、j 为最小项编号
151 实现函数 数据端 Di 接常量或变量，按最小项选通

四、典型例题

例 1：用 74LS138 和与非门实现 F = Σm(1, 3, 5, 7)（三变量 A2A1A0 输入）。

解：

  • 138 输出低有效的 Y1、Y3、Y5、Y7 与最小项对应；
  • F = (Y1·Y3·Y5·Y7)’ → 将 Y1、Y3、Y5、Y7 四端接一个四输入与非门即可；
  • 检验：任一最小项为 1 时对应 Y 为 0，与非门输出去掉反号即 1。正确。

例 2：分析组合电路 F = AB + BC（A、B、C 输入）。列出真值表并说明功能。

解：

  • F = B(A + C)：B = 1 且 A 或 C 为 1 时 F = 1；
  • 真值表：F = 1 的组合为 (1,1,0)、(1,1,1)、(0,1,1)；
  • 功能：多数表决电路（B 占主导的两人及以上同意则通过）。

五、解题方法小结与易错点

  • 用 138 实现函数务必配与非门（因为其输出低有效），用 151 实现则数据端直接接 0/1/变量。
  • 组合电路分析最后一步”说明功能”别省略，是得分点。
  • TTL 悬空 = 高电平；CMOS 悬空状态不定，两类器件区别常考判断题。
  • 线与必须用 OC 门；普通 TTL 输出不能直接并联。
