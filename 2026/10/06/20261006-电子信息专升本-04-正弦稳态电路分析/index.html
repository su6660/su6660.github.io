第 4 章 正弦稳态电路分析

一、考纲考点清单

  1. 正弦量的基本概念（三要素、有效值、相位差）
  2. 正弦量的相量表示法
  3. 电阻、电感、电容元件在交流电路中的作用
  4. RLC 的串联与并联（阻抗与导纳）
  5. 正弦电路的功率与功率因数
  6. 电路中的谐振
  7. 最大功率传输定理

二、核心知识点

2.1 正弦量三要素与有效值

  • 三要素：幅值 Um（最大值）、角频率 ω（rad/s）、初相 φ。u(t) = Um·sin(ωt + φ)。
  • ω = 2πf = 2π/T。我国工频 f = 50 Hz。
  • 有效值：U = Um/√2 ≈ 0.707Um（正弦量专用）。交流仪表读数为有效值。
  • 相位差：同频率正弦量的初相之差 φ = φ1 − φ2；φ > 0 称电压超前电流，φ = 0 同相，φ = ±90° 正交，φ = 180° 反相。

2.2 相量法

  • 相量：用复数表示正弦量（模 = 有效值，辐角 = 初相）。如 u = 220√2 sin(314t + 30°) 对应相量 220∠30°。
  • 相量运算（加、减、乘、除）分别对应正弦量同频叠加及阻抗变换；正弦量对 t 求导对应相量乘 jω，积分对应除以 jω。

2.3 R、L、C 元件的伏安关系（相量形式）

元件 阻抗 相量关系 相位关系 功率
R R U = RI 同相 只耗有功 P = UI
L jXL（XL = ωL） U = jωLI 电压超前电流 90° 只吸无功 Q = UI
C −jXC（XC = 1/ωC） U = −j(1/ωC)I 电压滞后电流 90° 只发无功

2.4 阻抗、功率与功率因数

  • 阻抗：Z = R + jX = |Z|∠φ，|Z| = √(R² + X²)，φ = arctan(X/R)。RLC 串联时 X = XL − XC。
  • 功率：S = UI（视在功率，VA）；P = UIcosφ（有功，W）；Q = UIsinφ（无功，var）；S² = P² + Q²。
  • 功率因数 cosφ = P/S；感性电路并联电容可提高功率因数。

2.5 谐振与最大功率传输

  • 串联谐振条件：XL = XC，即 ω0L = 1/(ω0C)，f0 = 1/(2π√(LC))。特征：Z 最小 = R，电流最大，UL 与 UC 大小相等方向相反可远高于电源电压（品质因数 Q = UL/U = ω0L/R）。
  • 并联谐振：理想 LC 并联，阻抗最大。
  • 最大功率传输：负载阻抗为电源内阻抗的共轭复数（Z = Z0*，即 R 相等、电抗抵消）时取得最大功率 Pmax = Uoc²/(4Req)。

三、关键公式速查

名称 公式
有效值 U = Um/√2
感抗 / 容抗 XL = ωL = 2πfL；XC = 1/(ωC)
阻抗模
有功功率 P = UIcosφ
无功功率 Q = UIsinφ
串联谐振频率 f0 = 1/(2π√(LC))

四、典型例题

例 1：R = 6 Ω 与 XL = 8 Ω 串联接 220 V 交流电源，求电流、功率因数与有功功率。

解：

  • |Z| = √(6² + 8²) = 10 Ω → I = U/|Z| = 220/10 = 22 A；
  • cosφ = R/|Z| = 6/10 = 0.6；
  • P = UIcosφ = 220 × 22 × 0.6 = 2904 W ≈ 2.9 kW。

例 2：RLC 串联谐振电路 L = 0.1 H，C = 10 μF。求谐振频率。

解：

  • f0 = 1/(2π√(LC)) = 1/(2π√(0.1 × 10×10⁻⁶)) = 1/(2π × 0.001) ≈ 159 Hz。

五、解题方法小结与易错点

  • 相量运算遵循复数规则，注意 j² = −1；RLC 串联用电压三角形，并联用电流三角形。
  • 功率因数 cosφ 由阻抗角决定，cosφ = R/|Z| 只适用于串联；并联电路可用导纳对应。
  • 谐振时”电压可高于电源电压”是串联谐振的重要特征（考判断题）。
  • 最大功率传输在正弦电路为共轭匹配，与直流里的纯电阻匹配区分开。
