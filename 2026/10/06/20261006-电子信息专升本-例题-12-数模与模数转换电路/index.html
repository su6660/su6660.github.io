电子信息专升本例题集 · 第12章 数模与模数转换电路

发表于2026-10-06|更新于2026-10-06|电子信息专升本
|阅读量:

本套例题围绕第 12 章「数模与模数转换电路」的核心考点展开，覆盖以下板块：

一、D/A 转换：权电阻型与倒 T 型电阻网络 DAC 的原理对比，输出表达式 uo = Uref × D/2^n 的应用计算。
二、D/A 与 A/D 的技术指标：分辨率、量化单位 1LSB、满量程 UFS、转换时间。
三、A/D 转换：采样、保持、量化、编码四步过程，采样定理 fs ≥ 2·fmax，逐次逼近型与双积分型 ADC 的工作特点。
四、位数计算：由分辨率要求反解转换器位数（注意向上取整）。

题目按难度分三级：

  • 基础：直接套用转换公式与指标定义；
  • 进阶：综合过程分析与运算（逐次逼近过程、采样定理与量化单位联合求解）；
  • 拓展：开放思考与器件选型（位数反解、双积分与逐次逼近的取舍）。

做本章题目的第一件事是分清「D/A」还是「A/D」：两者分辨率的分母差 1（D/A 用 2^n − 1，A/D 用 2^n），这是最常考的易错点，务必先判断方向再下笔。

一、基础概念示例题

例题12-1 ｜ 难度：基础

【题目】某 8 位倒 T 型电阻网络 DAC 的参考电压 Uref=5V，输入数字量为 (10000001)₂。求该 DAC 的最小输出电压步进与此时的输出电压。

【解题步骤】

  1. 先把二进制数字量转换为十进制：(10000001)₂ = 1×2^7 + 0 + 0 + 0 + 0 + 0 + 0 + 1×2^0 = 128 + 1 = 129。
  2. DAC 的最小步进（即 1LSB 对应的模拟增量）为 UFS/(2^n − 1)，其中满量程对应全 1 输入，此处 UFS = Uref = 5V。
  3. 任一数字量 D 的输出 uo = Uref × D/(2^n − 1)，代入 D=129、n=8 计算。

【答案解析】最小步进 = 5/(2^8 − 1) = 5/255 ≈ 19.6 mV。输出电压 uo = 5 × 129/255 ≈ 2.53 V。复核：129 × 19.6mV ≈ 2.53V，与直接用公式一致。需要特别强调：DAC 的分母是 (2^n − 1) = 255 而不是 256，这是 DAC 与 ADC 计算时最容易混淆的一个「差 1」，务必看清是 D/A 还是 A/D 再下笔。

【知识点链接】倒 T 型 DAC 输出计算、最小步进与满量程，详见《电子信息专升本 · 第12章 数模与模数转换电路》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-12-数模与模数转换电路/

例题12-2 ｜ 难度：基础

【题目】对比权电阻网络 DAC 与倒 T 型电阻网络 DAC 的优缺点，并说明为什么倒 T 型网络是实际中最常用的结构。

【解题步骤】

  1. 权电阻网络：把每一位数字量按权分别通过不同阻值的电阻，然后求和得到输出。
  2. 倒 T 型网络：只用 R、2R 两种阻值，各支路电流按权分配后求和。
  3. 从电阻种类、制造精度、转换速度三方面归拢两者的优劣。

【答案解析】权电阻型 DAC 各支路电阻按 2 的幂次取值，位数越多所需电阻阻值种类越多、阻值差异越大，电阻精度难以保证，因此权电阻网络主要用于原理说明；倒 T 型电阻网络 DAC 只用 R 与 2R 两种阻值，制造精度高、电路简单、转换速度快，成为实际中最常用的 D/A 结构。两者共同的输出表达式均可写成 uo = Uref × D/2^n（按电压基准对各位逐位加权求和），其中 D 为输入数字量的十进制值。

【知识点链接】权电阻型与倒 T 型 DAC 原理对比，详见《电子信息专升本 · 第12章 数模与模数转换电路》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-12-数模与模数转换电路/

例题12-3 ｜ 难度：基础

【题目】某 A/D 转换器输入电压范围为 0~10V，要求分辨率优于 0.1V，问至少需要多少位？并写出所用到的分辨率公式。

【解题步骤】

  1. n 位 ADC 的 1LSB（量化单位）为 UFS/2^n，分辨率要求即 1LSB ≤ 0.1V。
  2. 列出不等式 10/2^n ≤ 0.1，求出满足条件的最小整数 n。

【答案解析】由 10/2^n ≤ 0.1 得 2^n ≥ 100。2^6 = 64 < 100 < 128 = 2^7，故 n = 7，即至少需要 7 位。位数必须按「优于」要求向上取整，不能取下限 6 位（2^6=64 只能满足 10/64≈0.16V，达不到 0.1V）。注意 ADC 的分母是 2^n（此处 2^7=128，1LSB=10/128≈78mV，已优于 0.1V），与 DAC 的 (2^n − 1) 不同，做题时先看清楚是 A/D 还是 D/A。

【知识点链接】分辨率与位数的关系、ADC 量化单位 1LSB，详见《电子信息专升本 · 第12章 数模与模数转换电路》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-12-数模与模数转换电路/

二、综合应用题

例题12-4 ｜ 难度：进阶

【题目】一个 3 位逐次逼近型 A/D 转换器，满量程 UFS=8V，输入电压 ui=4.2V。写出逐次比较的完整过程，给出最终输出数字量与量化误差。

【解题步骤】

  1. 先算 3 位 ADC 的量化单位：1LSB = 8/2^3 = 8/8 = 1V。
  2. 逐次逼近从最高位（D2，权 4V）开始，逐位置 1 试探，与 ui 比较后决定保留还是清零。
  3. 依次判断 D2、D1、D0 三位，得到最终数字量；量化误差 = 输入电压 − 数字量对应模拟值。

【答案解析】逐次比较过程如下表：

步骤 置位试探 对应模拟值 与 ui 比较 结果
1 D2=1 → 100 4V 4.2 > 4 保留，D2=1
2 D1=1 → 110 6V 4.2 < 6 清零，D1=0
3 D0=1 → 101 5V 4.2 < 5 清零，D0=0

最终数字量 100（对应 4V），量化误差 = 4.2 − 4 = 0.2V，小于 1LSB（1V）。逐次逼近型 ADC 每比较一次确定一位，n 位转换共需 n 次比较，速度快、精度较高，是应用最广的一类 ADC。做题时注意试探值大于输入就把该位清零、小于输入就保留，方向不要记反。

【知识点链接】逐次逼近型 A/D 工作原理、量化与量化误差，详见《电子信息专升本 · 第12章 数模与模数转换电路》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-12-数模与模数转换电路/

例题12-5 ｜ 难度：进阶

【题目】对最高频率 fmax=3kHz 的模拟信号进行 A/D 转换。求满足采样定理的最低采样频率 fs；若采用 8 位 ADC、满量程 5V，求其量化单位 1LSB，并说明 A/D 转换全过程包含哪几步。

【解题步骤】

  1. 由采样定理 fs ≥ 2·fmax 求最低采样频率。
  2. 由 1LSB = UFS/2^n（A/D 的分母是 2^n）求量化单位。
  3. 按实际转换的先后顺序叙述 A/D 的四个环节。

【答案解析】最低采样频率 fs ≥ 2×3kHz = 6kHz（采样定理：fs ≥ 2·fmax，否则发生频谱混叠，无法从采样值重建原信号）。量化单位 1LSB = 5/2^8 = 5/256 ≈ 19.5 mV。A/D 转换全过程按顺序为：采样（按 fs 对连续信号取离散瞬时值）→ 保持（把瞬时值维持到量化完成）→ 量化（把幅值归并到最接近的离散电平，产生量化误差）→ 编码（把量化结果转换为二进制数码输出）。实际工程中采样频率常取 3~5 倍 fmax 以上，以降低模拟滤波器的压力、留出余量。

【知识点链接】采样定理、A/D 四步过程、8 位 ADC 量化单位，详见《电子信息专升本 · 第12章 数模与模数转换电路》学习要点：https://su6660.github.io/2026/10/06/20261006-电子信息专升本-12-数模与模数转换电路/

三、拓展思考题

例题12-6 ｜ 难度：拓展

【题目】某测量系统要求满量程 5V、分辨率 1LSB ≤ 0.5mV，求所需 ADC 的最少位数；若被测量中混有约 50Hz 的工频干扰且要求高精度、慢速测量，应选双积分型还是逐次逼近型 ADC？请说明理由。

【思路提示】
先由不等式 2^n ≥ UFS/1LSB 反解位数（注意向上取整）；再从速度、精度、抗干扰三个维度比较两类 ADC 的适用场景，特别结合「50Hz 工频干扰」这一具体条件作答。

【参考答案要点】

  1. 位数：5/2^n ≤ 0.5×10^-3 V，即 2^n ≥ 5/0.0005 = 10000。2^13 = 8192 < 10000 < 16384 = 2^14，故至少需要 14 位。
  2. 选型：应选双积分型 ADC。理由：双积分型通过积分平均能有效抑制叠加在信号上的周期性干扰（尤其让积分时间取工频 50Hz 的整数倍时，50Hz 干扰基本被消除），抗干扰能力强、精度高，但转换速度慢，正适合慢速高精度的测量场合（如数字仪表）。逐次逼近型速度快、精度较高，但抗干扰能力弱于双积分型，更适合高速场合。
  3. 选型体会：同一分辨率要求下，位数越高则 1LSB 越小、对噪声越敏感，因此选型必须综合位数（精度）、速度、抗干扰三方面权衡，不能只看位数。
