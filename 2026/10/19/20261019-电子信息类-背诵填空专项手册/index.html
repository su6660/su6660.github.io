第一部分 电路原理 ★（专转本考纲核心）

第 1 章 电路基本概念与基本定律

【背诵填空】

  1. 电路由____、____和____三部分组成。
  2. 当一段电路的电压与电流参考方向相同（都从”+”到”−”）时，称为____参考方向。

  4. 基尔霍夫电流定律（KCL）：任一节点上，流入电流的代数和恒等于____。
  5. 基尔霍夫电压定律（KVL）的理论基础是____守恒定律。
  6. KCL 可以推广应用于电路中任一____（视为广义节点）。
  7. 两电阻串联分压：U₁ = ____________；两电阻并联分流：I₁ = ____________。
  8. n 个阻值均为 R 的电阻并联，等效电阻为____。
  9. 电压源（Us 串 Rs）与电流源（Is 并 Rs）等效变换条件：Rs 不变且 Is = ______。
  10. 理想电压源内阻为____，理想电流源内阻为____。
  11. 电路中某点的电位，就是该点到____之间的电压；电位随参考点改变而改变，具有____性，而任意两点间电压不随参考点改变，具有绝对性。
  12. 支路电流法以____为未知量；对 n 个节点、b 条支路的电路，需列 n−1 个____方程和 b−(n−1) 个____方程。
  13. 电阻元件的伏安关系服从____定律；其消耗的能量 W = ______（用 U、I、t 表示）。

【参考答案】

  1. 电源；负载；中间环节　2. 关联　3. 吸收；发出　4. 零（流出电流代数和）　5. 能量　6. 闭合面
  2. U·R₁/(R₁+R₂)；I·R₂/(R₁+R₂)　8. R/n　9. Us/Rs　10. 零；无穷大
  3. 参考点（接地点）；相对　12. 支路电流；KCL；KVL　13. 欧姆；W = UIt（= I²Rt = U²t/R）

  4. P2 口作总线时输出高 8 位____；P1 口是唯一的____功能双向口；P3 口具有____功能。
  5. P3 口第二功能：P3.0 = ____、P3.1 = ____、P3.2 = ____、P3.3 = ____、P3.4/P3.5 = T0/T1、P3.6/P3.7 = WR/RD。
  6. 时钟周期 = 振荡周期；机器周期 = ____个时钟周期；一条指令的执行时间为 1~____个机器周期。
  7. 若晶振 fosc = 12MHz，则时钟周期 = ____ns，机器周期 = ____μs。
  8. 复位条件：RST 引脚保持____电平____个机器周期以上；复位后 PC = ____H、SP = ____H、P0~P3 = ____H。
  9. 程序状态字 PSW 中的标志位：CY（____）、AC（____）、OV（____）、P（____）。
  10. 工作寄存器共 4 组 R0R7，由 PSW 中的____位选择；复位后默认第____组（地址 00H07H）。

【参考答案】

  1. 8；4；128；4；2；5　2. 哈佛（程序与数据分开）；独立（分开）
  2. 上拉；地址；数据　4. 地址；单一（无第二）；第二（复用）
  3. RXD；TXD；INT0（外部中断0）；INT1（外部中断1）　6. 12；4　7. 83.3；1
  4. 高；2；0000；07；FF　9. 进位；辅助进位（半进位）；溢出；奇偶　10. RS1、RS0；0

第 22 章 存储器组织与寻址方式

【背诵填空】

  1. 8051 片内 RAM 低 128B 中：00H1FH 为____区（4 组）；20H2FH 为____区（共____个可寻址位）；30H~7FH 为用户区（数据缓冲/堆栈）。
  2. 特殊功能寄存器 SFR 分布在____H~____H 地址空间；访问 SFR 只能用____寻址方式。
  3. 程序计数器 PC 是____位寄存器，复位后为____H；数据指针 DPTR 是____位，由 DPH 和 DPL 组成。
  4. 堆栈遵循”____”原则（后进先出）；8051 堆栈设在片内 RAM，堆栈指针 SP 复位初值为____H，通常初始化时将其改设在____区（如 60H 以上）。
  5. 七种寻址方式：____寻址、直接寻址、寄存器寻址、____寻址、变址寻址、相对寻址、位寻址。
  6. 寄存器间接寻址用 @R0、@R1 或 @DPTR；其中 @Ri 只能访问片内 RAM 和片外低 256B，@DPTR 访问____存储器。
  7. MOVC 指令用于访问____存储器（查表），MOVX 用于访问____存储器。
  8. 位寻址区的位地址范围为 00H7FH，对应字节地址____H____H。

【参考答案】

  1. 工作寄存器；位寻址；128　2. 80；FF；直接　3. 16；0000；16　4. 后进先出（LIFO）；07；用户（高地址）
  2. 立即；寄存器间接　6. 片外数据（外部 RAM）　7. 程序（ROM 查表）；外部数据（RAM）
  3. 20；2F

第 23 章 中断系统

【背诵填空】

  1. 8051 共____个中断源：外部中断____、外部中断____、定时器 T0 溢出、T1 溢出、____中断。
  2. 五个中断源的自然优先级从高到低：____＞____＞____＞____＞串行口。
  3. 各中断源的中断入口（向量）地址：INT0 = ____H、T0 = ____H、INT1 = ____H、T1 = ____H、串行口 = ____H。
  4. 中断允许寄存器 IE 中：EA 为中断____允许位；EX0/ET0/EX1/ET1/ES 分别为各中断源的允许位，置____允许。
  5. 中断优先级寄存器 IP 置 1 的为____优先级；同级中断不能互相____。
  6. 外部中断的触发方式由 TCON 的 IT0/IT1 设置：IT = 0 为____触发，IT = 1 为____触发（下降沿）。
  7. CPU 响应中断的条件：该中断源已____、CPU 开放了____、无更高级（同级正在服务则不能打断）中断正在处理。
  8. 中断服务函数返回用____指令，同时恢复断点（区别于子程序返回 RET）。
  9. 定时器溢出标志 TF0/TF1 在中断响应后由____清零（查询方式需____清零）。

【参考答案】

  1. 5；INT0；INT1；串行口（串口）　2. INT0；T0；INT1；T1　3. 0003；000B；0013；001B；0023
  2. 总（全局）；1　5. 高；嵌套（打断）　6. 电平（低电平）；边沿（脉冲）
  3. 允许（申请标志有效）；总中断（EA=1）　8. RETI　9. 硬件（自动）；软件（用指令）

第 24 章 定时器/计数器与串行口

【背诵填空】

  1. 定时器工作方式寄存器 TMOD 每半字节控制一个定时器：GATE、C/T、____、____（M1 M0）。
  2. C/T = 0 为____方式（对内部机器周期计数），C/T = 1 为____方式（对外部脉冲计数）。
  3. T0/T1 四种工作方式：方式 0 为____位计数器，方式 1 为____位，方式 2 为____位自动重装，方式 3 仅 T0 可用（分为两个 8 位）。
  4. 方式 1 的最大计数值为____（65536）；若 fosc = 12MHz，方式 1 最长定时约____ms。
  5. 定时器初值计算（方式 1）：初值 X = 65536 − ______（t 为定时时间，T机器为机器周期）。
  6. TCON 中的控制位：TR0/TR1 为启动____位（软件置 1/清 0），TF0/TF1 为____标志位。
  7. 串行口有____种工作方式；方式 0 为同步____方式，方式 1 为____位异步收发（UART）、波特率可变。
  8. 串行口方式 1 的波特率由定时器____的溢出率决定：波特率 = (2^SMOD/____)×T1 溢出率。
  9. 串行口控制寄存器 SCON 中：REN 为____允许位，TI/RI 分别为发送/接收____标志，响应后必须由____清零。
  10. 串行发送/接收数据通过____寄存器（SBUF，物理上是两个独立寄存器）进行缓冲。

【参考答案】

  1. M1；M0　2. 定时；计数　3. 13；16；8　4. 65536（2¹⁶）；65.536
  2. t/T机器（定时时间除以机器周期，即计数次数）　6. 运行（启停）；溢出（中断请求）
  3. 4；移位（串行输出）；8　8. T1（1）；32　9. 串行接收；中断；软件（编程）
  4. 串行数据缓冲（收发缓冲）

第 25 章 系统扩展与接口技术

【背诵填空】

  1. 单片机系统三总线：____总线（AB）、____总线（DB）、____总线（CB）；P0 经地址锁存器（利用 ALE 信号）分离出低 8 位地址。
  2. ALE 引脚输出地址锁存信号，频率为 fosc 的____分频（fosc/6）；PSEN 为外部____存储器读选通信号。
  3. 存储器扩展：程序存储器用____信号选通，数据存储器用____信号（WR/RD）选通，二者地址可重叠是因为控制信号不同。
  4. 8255 为可编程并行接口芯片，有____个 8 位端口（PA、PB、PC），三种工作方式（方式 0 为基本____/输出）。
  5. LED 数码管显示方式：____显示（每位独立锁存，占用口线多、亮度稳定）和____显示（分时轮询，省口线）。
  6. LED 数码管分共____和共____两种接法。
  7. 键盘按结构分____式和矩阵（行列）式；按键消抖措施有硬件滤波和软件____ms 延时再判别。
  8. ADC0809 为____通道____位逐次逼近型 ADC，与单片机连接时转换结束信号 EOC 用于____查询或中断。
  9. DAC0832 为____位 D/A 转换器，输出为____信号，工作方式分直通、单缓冲和____缓冲。
  10. 键盘扫描方式：编程扫描、____扫描和中断扫描。

【参考答案】

  1. 地址；数据；控制　2. 6（六分频）；程序（ROM）　3. PSEN（程序选通）；WR/RD（读写）
  2. 3；输入　5. 静态；动态　6. 阴（共阴极）；阳（共阳极）　7. 独立；10（约 5~10）
  3. 8；8；查询（状态判断/申请中断）　9. 8；电流；双　10. 定时
