讲座笔记：常州市退役军人创业政策解读（20261031）

发表于2026-11-16|更新于2026-11-16
|阅读量:

本文由现场速记整理，不是讲座逐字稿。政策条款以笔记记录为准，具体申报条件与时效请以常州市人社、退役军人事务部门最新文件为准。

一句话总结

常州的退役军人创业扶持主要集中在补贴、场地、孵化、税收、金融五个方向，但几乎所有补贴都有一个硬前提：企业注册之日起三年以内。

讲座信息

  • 日期：2026-10-31
  • 讲师：徐凯
  • 主题：常州市退役军人创业政策解读
  • 地点：和平假日大酒店

一、政策环境的一个重要变化

笔记第一条就点明：

区级退役军人扶持奖办法，因为国家政策调整、营商环境特别要求「全国统一大市场」，全部取消（不要违法）。

这条信息很关键：地方自行设置的、可能影响公平竞争的奖补，正在被清理。所以不能拿几年前的政策文件直接套用，必须核对现行有效文件。同时，这也提醒创业者：任何「特殊照顾」都不能突破法律边界。

二、常州本地的可用支持

笔记列出了以下方向：

  1. 常州市有专属退役军人政策：在省级政策之外，常州另有地方性支持措施。
  2. 跨境电商政策：与跨境电商相关的专项支持。
  3. 创业孵化平台：位于新北区，可提供场地与孵化服务。
  4. 创业导师：笔记写「明年有专门的创业导师创业指导」，说明导师机制按年度组织，需关注报名时间。
  5. 创业基地扶持：可申请进入创业基地，享受配套支持。
  6. 税收优惠：面向退役军人的税收减免政策。
  7. 金融优惠贷款：创业担保贷款等金融支持。

三、补贴的两类与一个前提

笔记明确记录：

补贴需要从注册之日起三年以内，有租金补贴，有创业项目补贴。

拆开看：

补贴类型 用途 关键前提
租金补贴 降低经营场地成本 注册 3 年内
创业项目补贴 支持项目启动与运营 注册 3 年内

「注册之日起三年以内」是最容易被忽略的门槛。很多人先注册公司、过两年才想起申请，结果已经超期。如果确定要走创业这条路，应该在公司注册前就把政策申报时间表排好。

四、一条建议的申报顺序

  1. 注册前：先到新北区孵化平台与退役军人事务部门咨询现行政策，确认自己符合哪些条件。
  2. 注册时：经营范围、注册地址要按申报要求写，避免后期不符合条件。
  3. 注册后 3 个月内：申请入驻孵化平台或创业基地，拿到场地支持。
  4. 3 年内：按年度申报租金补贴、项目补贴，注意每项政策的申报窗口。
  5. 同步办理：税务优惠备案、创业担保贷款申请。
  6. 持续参与：关注创业导师、创业大赛等资源型活动。

五、现场留下的疑问

笔记的待查项写的是「创新枢纽」，推测与当地创新载体或平台有关，但具体指向不明，需要补充。

可以马上做的事

  • 找到常州市退役军人创业政策的现行有效文件，核对补贴项目与条件。
  • 记录自己公司（或计划注册公司）的注册日期，倒推三年期限。
  • 实地或电话咨询新北区创业孵化平台的入驻条件。
  • 列一张申报日历：租金补贴、项目补贴、税收优惠、贷款申请的窗口期。

笔记完整度

  • 讲师姓名记录为「徐凯」，与笔记作者同名，可能是本人主讲或记录误差。
  • 各项补贴的具体金额、比例、申报材料均未记录，这是本篇最大的缺口。
  • 「区级扶持奖办法取消」的具体文件名称与时间未记录，引用前必须核实。
  • 录音缺失，建议以官方文件为准，不要仅凭笔记申报。
