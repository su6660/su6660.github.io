科技·财经·加密日报（20261127）

发表于2026-11-28|更新于2026-11-28
|阅读量:

昨天，广州车展智能化与电动化新品密集亮相，AI大模型与开源生态持续演进；央行发布金融稳定报告释放政策信号，美股存储芯片板块领涨、欧洲央行加息预期升温；加密市场比特币弱势盘整，Binance完成恢复提现，多国监管收紧隐私币与DeFi领域。

科技圈

广州车展智驾与新能源集中爆发：长安发布天枢领航Ultra 2.0，启源Q06升级支持车位到车位高阶智驾；本田冠道搭载Momenta智驾从”中国特供”升级为全球旗舰；捷途纵横R700采用华为乾崑配大梁；问界新M7换装800V平台与三联屏，30.98万元起售；奔驰纯电GLC、岚图泰山纯电版（43.99万元三腔空悬）、零跑Lafa5等车型密集登场，智能化成为核心卖点。

AI应用与开源动态：Anthropic的Claude Opus 5.6演示生成高质量PPT引发关注；微信开源电商多模态基础模型WeMM-Ecom；蚂蚁百灵发布并开源Ling-3.2-air大模型，总参数1240亿但每个token仅激活55亿；VS Code 1.148新增防止系统休眠功能以支持Agent长任务运行；华为发布全新一代巨鲸电池平台强调全生命周期安全。

其他值得关注：欧盟委员会将浏览器竞争列为DMA优先事项，确保iPhone/iPad上第三方浏览器有效竞争；IBM停止为咨询部门员工提供H-1B签证担保；旅行者1号出现信号故障，NASA无法解读数据；GTA 6被AI工具快速移植至PC平台，Take-Two通过DMCA删除逾3000个GitHub库但未能遏制进展。

经济财经

政策与宏观：央行发布《中国金融稳定报告（2026）》，提出灵活运用货币政策工具保持流动性充裕、适时推广浮动管理费率基金、营造”长钱长投”市场生态；欧洲央行管委释放鹰派信号，暗示12月可能进一步加息；《北京市民营经济促进条例》将于2027年1月1日起实施。

市场表现：美股存储芯片股集体大涨，费城半导体指数涨3.01%，闪迪涨近14%，铠侠ADR涨超15%，美光、西数、希捷涨幅均超5%；热门中概股普涨，哔哩哔哩涨近8%，蔚来、爱奇艺涨超5%；美国”黑五”线上消费预计达创纪录的129亿美元，同比增长9.2%。

行业与公司：宁德时代估值分析与建设银行相近引发热议，11倍PE处于上市以来最低分位，市占率连续下滑、排产下调引发市场对盈利拐点的博弈；美团三季度电话会透露Keeta沙特全季度盈利、预计明年AI资本支出低于今年；贵州茅台拟每股派现25.6元合计320亿元；日产10月在华销量同比骤降67.1%；双11手机销量下降17%，前五均为iPhone。

加密货币

市场行情：比特币价格在61,300美元附近徘徊，七日均线供应盈亏比降至11年新低，JPMorgan指出Strategy的NAV倍数创历史新低暗示”投降”信号；Galaxy Research撤回此前”熊市结束”判断，警告跌破58,525美元将打开下行空间；市场关注美联储鹰派立场对风险资产的压制。

技术与生态：以太坊开发者将Glamsterdam升级定于12月15日在Hoodi测试网上线，此前因Gas定价变更担忧推迟；Binance在遭遇64亿美元黑客事件四周后全面恢复提现，美国官方称已协助冻结或追回29亿美元资金；BNB Chain公布面向交易和AI的新L1区块链计划，目标2027年第一季度上线测试网。

监管与合规：西班牙通过皇家法令允许反洗钱机构Sepblac无需法院命令即可冻结加密账户最多5个工作日；日本探讨加强对DeFi和自托管钱包监管；英国FCA拟议DeFi规则遭Coinbase批评；中日韩与东盟将成立数字支付与加密监管工作组；Tether斥资约1000万美元购入Bitdeer股份；纽约检方对NovaTech创始人及其同案被告取得13.7亿美元判决。

一句话总结：科技与汽车产业智能化加速落地，宏观政策稳增长与全球紧缩预期并行，加密市场弱势盘整且监管框架持续完善。
